  1. 인스타 피드 게시 (단일): 01 또는 02 추천 (인물·시그니처)
  2. 캐러셀 5장 추천 순서: 01 → 02 → 03 → 04 → (사용자 후기·실 사진 1장)
  3. 인스타 광고 캠페인 (Meta Ads Manager):
    • Objective: Leads (또는 Traffic)
    • 광고 클릭 URL: https://jangmiji.staris.cloud/enroll
    • 위 4장을 별도 광고 세트로 A/B 테스트
    • Audience: 한국 25~45세 여성 · 뷰티/메이크업/반영구 관심사
  4. 광고 클릭 → /enroll 페이지 → 입력 → DB 저장 → 알림:
    • 사용자 입력값 → Supabase leads 테이블 자동 저장 (RLS 적용)
    • 관리자 (admin@admin.com / admin) 가 /admin 페이지에서 실시간 확인
    • 각 lead 행에 💬 문자 버튼 → 문자 템플릿 3종 (상담 안내/일정/결제) 선택 → 발송
    • SMS 발송은 Solapi REST API 사용 (가입 후 키 받으면 즉시 활성)
  5. 다음 라운드 보강 후보: 9:16 스토리 버전 · 영상(Veo 3.1) 변신 transition · 실 수강생 후기 인용 카드
