★ 현재 Higgsfield image_to_3d 의 본질적 한계 — 단일 사진 → 3D 메쉬 추정은 「뒤통수·옆얼굴·목 아래」 정보가 부족. 또 PBR (Physically Based Rendering) 재질이 단순함. 피부 = subsurface scattering (서브서피스 스캐터링) 없음. 머리카락 = 단일 메쉬 (가닥별 X). 조명 = HDR 환경 매핑 단순.

B전 직원 4인 관점별 의견

이 이서연 · 기획·마케팅 유저 경험·전환·실용

★ 입장 — "리얼리즘은 ★★★★ 면 충분. 마지막 ★ 하나로 가는 비용이 100배다. 사용자가 「내 얼굴이다」 라고 인식하면 충분."
  • 「Uncanny Valley」 한계 — ★★★ → ★★★★ 는 효과 큼. ★★★★ → ★★★★★ 는 인지 차이 미세하지만 비용 100배
  • ★★★★ 의 정의 — 「실사 + 정면」 = 인스타 사진. 회전 시 약간 어색해도 「내 얼굴」 인식 → 전환 발생
  • 마케팅 활용 — 「3D 회전 영상」 자체가 콘텐츠. 인스타 릴스 = 5~10초. 그 시간 안에 ★★★★ 면 충분
  • 중국·미국 시장 (9월 LA·SF) — 레드노트 · 틱톡 = 「리얼 + 즉시」 가 핵심. Pixel Streaming (서버 비용) = 큐 부하 시 영상 끊김 위험
  • ★ 결론 — 언리얼 ★★★★★ vs 웹 ★★★★ + AI 합성 = 후자 강력 추천. 단, MetaHuman 영상 1편은 마케팅용으로 따로
★ 추천 — 「유저 인터랙션 = 웹 (★★★★)」 + 「인스타 광고 = MetaHuman 영상 1편 외주」 분리 전략

유 유나 · 그래픽·비주얼 디자이너 리얼리즘 · 아트 디렉션

★ 입장 — "현재 ★★★ 의 가장 큰 문제 = 피부 톤이 너무 균일. 살아있는 사람은 「부분별 색 차이」가 핵심. 게임·MetaHuman 도 결국 이걸 처리한다."
  • 피부 ★★★★ 핵심 — Subsurface Scattering (SSS) + multi-layer texture (모공·잔주름·홍조). Three.js + PBR + SSS 도 ★★★★ 가능
  • 머리카락 ★★★★ 핵심 — Strand-based (가닥별) 렌더. Unreal Hair Strand = 가장 강력. Three.js 도 PolyHaven 카드형 헤어로 ★★★
  • 눈동자 ★★★★ 핵심 — Iris parallax + 각막 굴절 + 다층 반사. Three.js Shader 직접 작성 가능
  • ★ 「Stylized Realism」 전략 — 100% 실사 X. ARTbrows 시그니처 「에디토리얼 톤」 (살구톤 + 부드러운 라이트) 으로 거리감 만들기. 「약간의 양식화」 = 부담스럽지 않고 럭셔리
  • 실측 데이터 필요 — 장미지 원장님 또는 모델 1명을 실측 (사진 100장 다각도) → Gaussian Splatting 으로 「Photo-real 3D」 가능. 한 번 만들면 평생 자산
  • 레퍼런스 — Apple Vision Pro의 「Persona」, Snapchat AR Mirror, LoL Champion 모델, 카카오 라이브2D — 모두 「리얼 X 양식화」 균형
★ 추천 — 「Gaussian Splatting + Three.js + PBR」 하이브리드. Unreal MetaHuman 은 마케팅 영상 1편 외주 (자산 영구 사용). 일상 인터랙션 = 웹

민 김민서 · Face Lab 리드 AI · 3D 재구성 · 렌더링

★ 입장 — "본질적 해법은 「더 많은 입력」 또는 「더 강한 prior (사전 지식)」. 단일 사진 한계는 inherent. 다중 사진 / 비디오 / MetaHuman prior 가 답."
  • 방법 1: Multi-view (사진 5~20장) — Gaussian Splatting (2023~) · NeRF · Instant-NGP. 품질 ★★★★★. 촬영 부담 있음. 메쉬 추출 → Unreal/Unity 가능
  • 방법 2: Video → 4D — 짧은 비디오 (10초) → 동적 3D. Dust3R · DUSt3R · MultiHMR. ★★★★
  • 방법 3: Strong Prior (MetaHuman / FLAME) — 거대 모델 사전 지식 활용. 단일 사진 → MetaHuman 캐릭터 자동 생성. 품질 ★★★★★. 제어 강함
  • 방법 4: AI Image (2D) — Stable Diffusion 3 + ControlNet + InstantStyle. 「내 얼굴 + 시그니처 눈썹」 = 실사 ★★★★★. 단점 = 회전·인터랙션 X
  • 방법 5: Hybrid AI — 3D 메쉬 + AI Postprocessing. Unreal MetaHuman 의 출력에 Stable Diffusion 후처리 = 끝판왕
  • 현실적 단계 — Phase 2 = Gaussian Splatting 자체 테스트 (R&D). Phase 3 = MetaHuman 외주 1편. Phase 4 = 자체 인프라 구축
★ 추천 — 「Gaussian Splatting (단기 R&D) + MetaHuman 외주 (중기) + Stable Diffusion 3 합성 (즉시)」 3축. 언리얼 직접 채용은 인력 부담 큼

E「웹에서 ★★★★ 달성 비결」 — 8 요소 체크리스트

★ 핵심 — Three.js 만으로도 ★★★★ 도달 가능. 8 요소를 모두 ★★★★ 까지 끌어올리는 게 핵심. 다음 라운드 (P0) 후보:

  • 2. 머리카락 — PolyHaven 의 「Hair Cards」 + 알파 셰이더 · 또는 Strand Renderer (WebGPU). ★ → ★★★
  • 3. 눈동자 셰이더 — Iris parallax + 각막 굴절 (Three.js refraction shader). ★ → ★★★★
  • 4. HDR 환경 — PolyHaven `studio_small_*.hdr` (스튜디오 조명) 적용. model-viewer `environment-image` 교체. ★★★ → ★★★★★
  • 5. AO 베이크 — Substance Painter / Blender 에서 Ambient Occlusion 베이크 → 모서리 음영. ★★ → ★★★★
  • 6. Depth of Field + Film Grain — Three.js EffectComposer + BokehPass + FilmPass. 카메라 "찍은 듯". ★ → ★★★★
  • 7. 메쉬 정밀화 — Higgsfield `multi_image_to_3d` (정면+측면+45° 3장) 사용. 28K → 60K 정점. ★★★ → ★★★★
  • 8. 표정 Blendshapes — MetaHuman 또는 FaceUnity 의 ARKit blendshapes (52개) 추가. ★ → ★★★★
