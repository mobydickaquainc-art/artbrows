인스타 프로페셔널 전환 가이드

2분 만에 · 무료 · 자동화 90% 진입

Meta Business Suite 예약 게시·인사이트·인스타 샵을 여는 첫 단계. Meta Graph API 심사(2주+) 없이도 예약 게시 완전 자동화 가능.

왜 지금 전환?
① Meta Business Suite 예약 게시 사용 (심사 없이 자동화 90%) · ② 인사이트 (도달·CTR·매출) 확인 가능 · ③ 인스타 샵 연동으로 색소·굿즈 판매 준비 · ④ 전환은 언제든 되돌리기 가능 (팔로워·게시물 데이터 그대로 유지)

01전환 6단계 (2분 · 앱에서)

1

📱 설정 메뉴 진입

프로필 → 우상단 ☰ → 「설정 및 개인정보」

인스타 앱 최신 버전 확인 → 로그인 상태 확인 → 우하단 프로필 아이콘 탭 → 우상단 햄버거 메뉴

2

⚙️ 계정 유형 진입

아래로 스크롤 → 「계정 유형 및 도구」

구버전 앱에서는 「비즈니스 도구 및 컨트롤」 로 표시될 수도 있음

3

🚀 프로페셔널 전환 선택

「프로페셔널 계정으로 전환」 → 설명 스와이프 → 「다음」

설명 화면 3~4장 스와이프 · 프로페셔널 계정 소개

4

🎨 카테고리 선택 ★ 중요

검색창에 「미용」 → 「미용, 개인 관리 및 뷰티」 선택

카테고리 라벨 표시 on 권장 (프로필에 「미용」 배지 표시)

카테고리적합도
미용, 개인 관리 및 뷰티⭐⭐⭐⭐⭐ 최적
교육⭐⭐⭐⭐ 학원 강조
소매업⭐⭐⭐ 쇼핑몰 강조
미용실·살롱⭐⭐⭐⭐ 대안
5

💼 크리에이터 vs 비즈니스 ★ 핵심 결정

「비즈니스」 선택 → 다음
항목크리에이터비즈니스 (추천)
대상개인 브랜드·인플루언서회사·매장·서비스
Business Suite 예약 게시✅✅
인스타 샵 (색소·굿즈 판매)제한✅ 연동
인사이트 (매출·CTR)기본✅ 상세
페이스북 페이지 연동선택✅ 자동
DM 필터3분류2분류
ARTbrows = 학원 + 쇼핑몰 하이브리드 브랜드 → 「비즈니스」 강력 추천. 색소·굿즈 판매까지 인스타 샵으로 연동 가능.
6

📞 연락처 정보 (선택 · 스킵 가능)

이메일·전화·주소 · 「연락처 표시」 on 권장
  • 📧 이메일: 원장님 or K1 채널 이메일
  • 📞 전화번호: 학원 대표 번호 (선택)
  • 📍 주소: 선릉·봉은사 학원 주소 (선택)
  • 🎯 연락처 표시 on → 프로필에 「전화·이메일·방향」 버튼 표시 → 원장님 상담 유도 CTA
7

✅ 페이스북 페이지 연결 (완료 단계)

기존 페이지 없으면 「새 페이지 만들기」 선택 → 자동 생성

기존 ARTbrows 페이스북 페이지 있으면 연결 · 없으면 자동 생성 (같은 이름). Meta Business Suite 사용을 위해 페이지 연결은 필수.

02전환 후 확인 사항

✅ 즉시 확인 가능

  1. 프로필 → 우상단 ☰ → 「인사이트」 메뉴 새로 생김
  2. 각 게시물 하단 「인사이트 보기」 버튼 새로 생김
  3. 프로필에 카테고리 라벨 (미용) 표시 확인
  4. Business Suite 접근 가능 → business.facebook.com 로그인

📊 팔로워·게시물 데이터

  1. 팔로워 수·DM·게시물 모두 유지 (변화 없음)
  2. 팔로워한테 알림 안 감 (외부에서 모름)
  3. 되돌리기 가능: 설정 → 계정 → 개인 계정 전환 (인사이트 데이터만 손실)
