중국 세미나 영상을 올리시면 한국어 자막으로 자동 변환해드립니다.

사용법 (영상만 올려주시면 끝):
① 아래 영상 업로드 영역에 영상을 드래그하거나 클릭해서 선택
② ★ 미리 번역 (처음 60초만) 또는 전체 자동 번역 클릭
③ 잠시 기다리시면 영상 + 한국어 자막이 자동 표시됩니다 (그 동안 다른 일 하셔도 OK)

먼저 체험만 — 미리 처리해둔 데모: 우측 분홍 🎯 실제 데모 로드 클릭 → 즉시 영상 + 47줄 한국어 자막 표시. 어떻게 작동되는지 1분 안에 보실 수 있습니다.

처리 시간: 2분 영상 → 약 2분 · 30분 영상 → 약 20분 · 1시간 영상 → 약 40분 · 3시간 영상 → 약 2시간
긴 영상(수십GB·몇 시간)이 자주 있으시면 다음주 월요일(6/22) 미팅 때 원장님 PC 에 자동 처리 시스템을 설치해드립니다. 그러면 영상을 PC 폴더에 두기만 하시면 끝.
엔진: 음성 인식 = faster-whisper · 번역 = Google Gemini 2.5 Pro (실패 시 OpenAI GPT-4o 자동 fallback)

GUIDE · 3분 안내

이 번역 도구, 어떻게 쓰나요?

원장님이 영상만 올리시면 나머지는 자동입니다.
파일 크기·상황별로 알아서 최적으로 처리해 드립니다.

1 이미 올린 영상 다시 보기

위쪽 「📚 내 영상 라이브러리」에서 카드를 클릭하세요. 재업로드·재번역 없이 즉시 재생됩니다.

⚡ 자막이 이미 있는 영상은 초록 배지 · 클릭 즉시 자막 표시

2 새 영상 (500MB 이하)

파일을 드래그하거나 클릭해서 선택. 자동으로 미리 번역 (첫 60초)이 시작됩니다.

📤 청킹 업로드 → 🎙️ Whisper → 🌐 OpenAI 번역 → 자막 도착순 실시간

3 큰 영상 (500MB 이상 · 예: 세미나 12GB)

「미리 번역」은 잠기고 「전체 자동 번역」이 자동 실행됩니다. 청킹 업로드 (20MB 단위)로 안전하게 저장 후 자동 처리.

⏳ 모래시계 · 예상 시간 · 진행률 실시간 표시 · 다른 창에서 작업하셔도 계속됨

4 번역 결과 확인 · 저장

우측 자막 패널에서 도착순 자막을 실시간 확인. 자막 클릭 = 영상 해당 시점 이동. [SRT 저장] · [복사] 버튼도 있음.

완료된 영상은 다음에 라이브러리 카드로 등장 · 재번역 없음

5 삭제·취소

파일 이름 옆 [×] = 이 파일 취소 · 라이브러리 카드 위 [×] = 서버에서 완전 삭제.

💡 팁 · 12GB 세미나 영상은 예상 55분 (업로드 11분 + Whisper 44분) · 처음 자막은 15~30초 뒤 도착. 화면을 닫아도 처리는 계속되며 라이브러리에 자동 저장됩니다.
