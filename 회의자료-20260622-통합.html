ARTbrows = 단순 학원 홈페이지 가 아니라 통합 AI Agent 플랫폼 으로 재정의.
실사 톤 대전환 + 임원진·직원 vs 수강생·유저 홈페이지 완전 분리 + 새 홈페이지 1개 추가 개설 (벤치마크 = 유미코리아 1세대 13지점) — 하나의 플랫폼에 쇼핑몰·자동 콘텐츠 생산·빌링·CS AI·소상공인 지원 자동 체크까지 모두 통합.

01
실사 위주 대전환
시리즈·메인·광고 모두 실사. 일러스트는 「과거 자산」 보존. 진행 중 ✓ (4편 완료)
02
홈페이지 2분리
🔵 임원진·직원용 (운영 스테이징) ↔ 🟢 수강생·유저용 (라이브). 새 1개 추가 개설
03
통합 플랫폼
학원 + 쇼핑몰 + 콘텐츠 자동 생산 + AI Agent + 빌링 + CS 하나의 도메인
04
자체 쇼핑몰
강의(수강료) + 시술 재료(니들·색소·머신) + 학원 굿즈 · 카페24 의존 X

매일 자동 콘텐츠
인스타 + 블로그 매일 자동 생산. AI Agent 가 캡션·해시태그·이미지 한 번에

쇼츠 자동 생산
시리즈 패턴(컷1·2·3·4 + 자막 + BGM + 엔드카드) AI Agent 가 자동 합성

AI Agent 플랫폼

빌링 시스템
토스페이먼츠 + 카카오페이 · 수강료·쇼핑몰·플랫폼 구독 등 다중 결제

AI 챗봇이 인스타 DM·문의 게시판·카카오톡 1차 자동 응답 · DM 매뉴얼 v1 기반
