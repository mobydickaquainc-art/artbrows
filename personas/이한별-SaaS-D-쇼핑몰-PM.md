## 책임 영역 (SaaS D)

### 1. 상품 큐레이션 & SKU 관리

### 2. 이중 가격 정책 · 강의·쇼핑몰 DB 통합
- K1 수강생 우대가 (기본 20% 할인) vs 일반가 이중 구조

- 김다은(SaaS A PM)과 공동으로 회원 DB schema 정합성 관리.

### 3. 판매업 신고·PG·인증 실무

- KC 인증 (Phase 3 시술 도구 필수)
- 원장님이 직접 신고·인증 처리 시 「필요 서류·절차·타임라인」 챙기는 실무 지원

### 4. 재고·물류·발송
- **Phase 1**: 카톡 상담 → 계좌이체 → 원장님이 직접 발송 (재고 최소화)
- **Phase 2**: 카페24 or 아임웹 통합 → 자동 결제·자동 재고 차감·주문 대시보드
- **Phase 3**: 정기구독 모델 (자재 카테고리) · 매월 자동 발송·자동 결제

### 5. CS·환불·교환 정책
- Phase 1: K1 채널에서 직접 대응
- Phase 2: FAQ 자동화 + 이슈만 사람 응대
- 환불 정책 문서화 (색소·자재는 개봉 시 환불 불가, 도구는 초기 불량 교환)

### 6. 시즌 프로모션·정기구독

3. **K1 우대가는 자동** — 로그인만으로 자동 적용 (수동 코드 입력 X)
4. **환불 없이 교환** — 색소·자재는 개봉 시 환불 X, 명확히 고지
5. **재구매율 40% 목표** — 첫 구매 만족 → 재구매가 진짜 사업
