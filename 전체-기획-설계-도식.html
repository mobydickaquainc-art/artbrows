스택 권장

  • Frontend = Next.js 14 + React
  • Backend = Next.js API + Python 워커
  • DB = Supabase (Postgres) — 단지/소소담다와 동일
  • 인프라 = 맥미니 + Tailscale + launchd (모비딕 표준) · 대안 Vercel
  • 인증 = Supabase Auth · 관리자 IP 화이트리스트
  • 키 관리 = .env (절대 리포 X) + Vercel/launchd 환경변수

외부 AI API

  • Claude (Anthropic) — 카피·시나리오·번역
  • GPT (OpenAI) — 비교군·대안
  • Gemini (Google) — 비교군·무료 한도
  • faster-whisper — 로컬 STT (영상 번역)
  • Higgsfield MCP — 이미지·영상 생성 (극사실 프롬프트)
