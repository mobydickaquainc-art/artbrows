## 1. 💬 자유 발언 — 각 직원 관점

### 이서연 (기획·마케팅)
저는 지금 가장 걱정되는 건 **「우리가 만들 SaaS B가 모비딕 상세페이지 플랫폼과 어떻게 다른가」**에요. 모비딕은 아쿠아리움 제품 → 상세페이지였잖아요? 우리는 「사진 → 멀티 광고」니까 도메인은 다르지만 패턴은 똑같아요. 그래서 사용자 입장에서 「이거 왜 ARTbrows에서 써야 하지?」 답이 필요해요.

제 답은 「**원장님 30년 펜슬 패턴 DB**」예요. 이게 우리만의 해자. 다른 광고 자동화 도구는 일반 베스트 프랙티스만 쓰는데, 우리는 「장미지 원장이 그렸을 그 톤」으로 광고가 나와요. **「내 계정 학습」**도 마찬가지 — 사용자 자기 인스타 90일 분석해서 자기만의 패턴으로 광고 만드는 거. 이거 두 개가 우리 진짜 차별점이에요.

키워드도 좁혀야 해요. 9개 시드 중 **「반영구 실사」 + 「장미지 원장」 + 「펜슬 가이드」** 3개만 집중. 너무 넓으면 ROAS 안 나와요. AEO도 처음엔 이 3개에 올인.

타겟은 명확해요. **시술 받는 사람 (B2C) + 배우는 사람 (수강생·B2B)** — 두 그룹의 페인 포인트가 정반대라서 광고 카피·채널도 분리해야 해요. 시술 받는 사람은 「인스타·페북」, 배우는 사람은 「네이버 블로그·유튜브」.

마지막으로 — 차주 첫 주는 **데이터 수집**에 집중해야 해요. 원장님 자료실 6.5GB부터 graphify로 한 번 더 돌리고, 100 케이스 만들어서 SaaS C 시드 확보. 광고도 데이터 없으면 안 나와요.

### 유나 (그래픽·비주얼)
디자인 톤이 살구핑크에서 **Luxury Dark**로 바뀐 거, 솔직히 마음에 들어요. 살구핑크는 솔직히 너무 「뷰티 일반」 같아서 ARTbrows 「극사실 창시자」 무게감이 안 살았어요. 다크 + Champagne Gold #E0C088 = **Dior Beauty·Chanel 화장품 라인 톤**이에요. 럭셔리.

근데 한 가지 걱정 — 인스타에서 너무 어두우면 피드에서 묻혀요. 인스타 알고리즘이 밝은 이미지 선호하는 거 아시잖아요. 그래서 **「다크 메인 + 강한 액센트 라이트」** 조합이 필수에요. 눈썹 부위에 rim light 강하게 — 그게 알고리즘에 「클릭 유도하는 강한 시각 자극」이 돼요.

저는 이번 주 「Luxury Dark **디자인 시스템 v2.0**」 완성하려고 해요. 컴포넌트 라이브러리 (카드·버튼·캐러셀·캘린더) 통일. 김민서 모바일 UI랑 같이 작업.

키비주얼은 제가 직접 하고, 반복은 Claude Code + Gemini 3 Pro Image로. 매월 인스타 50+장 자동 생성될 거니까 일관성 잡는 게 제 책임이에요.

한 가지 제안 — **「장미지」 손글씨 서명**을 모든 마스터 콘텐츠에 자동 박기. 이미 작품 6점에 있어요. 그걸 SVG로 추출해서 워터마크처럼.

### 한승철 (인프라·개발)
저는 솔직히 지금 가장 큰 리스크는 **「Python 백엔드를 누가 운영하나」**입니다. 클로드 코드로 코드는 만들지만, 실제 서비스로 띄우려면 서버·DB·도메인·SSL·OAuth·결제·CDN이 다 필요해요.

다행히 모비딕 패턴이 이미 검증돼서 똑같이 갑니다:
- **FastAPI** (port 8001) + **uvicorn** 자체 호스팅
- **SQLite → PostgreSQL 마이그레이션** (사용자 100+ 되면)
- **Netlify**는 정적·갤러리만, 동적 SaaS는 별도 서버
- **맥미니 + Tailscale + launchd** = 모비딕 인프라 그대로 사용 (메모리 [[mobydick-standard]])

API 키 신청 일정:
- **네이버 검색광고 API** — 영업일 3~5일 (06-30 신청 → 07-04 발급)
- **Meta Marketing API** — 비즈니스 인증 1주 (06-30 → 07-07)
- **Google Ads API** — 즉시 (06-30)

DB schema는 다음 4개 핵심:
1. `users` — 회원 3등급
2. `class_schedules` — 강의 일정 (이미 JSON schema 만들었음)
3. `pattern_db_cases` — Face Lab v7 시술 케이스
4. `ad_campaigns` — SaaS B 광고 (ROAS·예산·게시 이력)

차주 D+1에 schema SQL 작성 + Alembic 마이그레이션 셋업.

도메인은 어떻게 할까요? `eyebrows.staris.cloud` (Vercel) 와 `jangmiji.netlify.app` (Netlify) 가 이미 있는데, **Python SaaS는 `app.eyebrows.staris.cloud` 별도 서브도메인** 추천. 가비아 DNS 설정 필요.

### 김민서 (시각·UI)
모바일 UI 책임자 입장에서, **「일반인이 쓰기 편해야 됨」**이 가장 어려운 요구입니다. 살롱 사장님들 평균 연령 40~55세, IT 익숙도 낮아요. 「3 클릭에 결과」 진짜 지켜야 해요.

A1 달력 모듈 봤는데, JSON으로 데이터 구조는 좋아요. 근데 UI는 「달력 클릭 → 일정 모달 → 추가 → 저장」 흐름이 한 화면 안에서 끝나야 해요. 페이지 이동 X. 모달도 작게.

제가 차주 만들 것:
1. **달력 UI** — 7×6 그리드, 살구톤 (기존 인스타 톤) → 다크 럭셔리로 갱신, 클릭 1회로 일정 추가
2. **사진 업로드 UI** — 드래그&드롭 + 「분석 중...」 진척률 (Gemini Vision 5초)
3. **결과 미리보기 UI** — 7~12월 6장 캐러셀, 각 월 클릭하면 편집
4. **Face Lab v7 UI** — 정면+측면 업로드 → 결과 슬라이더 BEFORE/AFTER

폰트는 큰 게 좋아요. **본문 16px, 버튼 18px**, 캘린더 날짜 24px. 작으면 안 보여요.

색 대비도 신경. Luxury Dark는 좋은데, 글자 #F5EDE3 / 배경 #0B0907 contrast ratio 15:1 이상 보장. WCAG AAA.

### 박서윤 (SaaS B PM)
저는 차주 첫 미션이 「**광고 API 3종 신청 + Gemini 카피 5종 PoC + 1편 end-to-end**」였는데, **Gemini API 정상 작동**해서 카피 PoC는 이미 완료됐어요 (06-29 16:30). 5종 카피 JSON 저장됨.

근데 솔직히 그 5종 카피, 일반적이에요. 「반영구 실사」 키워드 강하게 안 들어갔고, 「장미지 원장」 시그니처도 약해요. 차주 더 정밀하게 — **키워드 시드 9개 + 원장님 시그니처 + 다크 럭셔리 톤** 모두 프롬프트에 강제 주입.

DIY 모델로 결정됐으니까 비즈니스 모델 단순해졌어요:
- 사용자 = 자기 광고 계정 (네이버·Meta·Google) OAuth 연동
- ARTbrows = 「도구만 제공」 (월 구독 5~15만원)
- 광고비 = 사용자 직불

위탁 운영 모델 안 가서 다행. 법적 위험 적고 매출 정기적.

「내 계정 학습」 — 이게 진짜 진짜 차별점이에요. 사용자 인스타 90일 분석 → TOP 5 공통 DNA 추출 → 그 패턴으로 새 광고. 일반 도구는 「베스트 프랙티스」만 제공하는데 우리는 「당신의 최적」을 제공.

**예산 알림** (텔레그램·카카오) — 50%·80%·100%·120% 임계치. 새벽에 광고 폭주해서 예산 다 쓰는 사고 사전 차단. 이거 진짜 다른 도구엔 없어요.

광고 API 신청 우선순위:
- **Meta Marketing** (인스타·페북 = 현재 1위 채널) → 가장 먼저
- **네이버 검색광고** (네이버 = 시술 검색 1위) → 둘째
- **Google Ads** (유튜브 광고용) → 셋째

차주 끝까지 3개 다 발급 완료하는 게 목표예요.

연관 키워드 분석 엔진 — 네이버 검색광고 API 받으면 「반영구 실사」 시드 → 100+ 롱테일 자동 발굴 가능. ROAS 예측까지.

### 최예진 (SaaS C PM)
저는 가장 큰 미션이 **Unreal Engine 5.8 도입 + 「수아」 MetaHuman 1체 + v6.0 PoC 24컷**이에요.

다행히 Unreal 다운로드는 진행 중 (37.5%). 1시간 안에 완료될 거고, 그 다음 MCP plugin 활성화하면 클로드가 자동 제어 가능. **차주 07-01 (월) 첫 작업 = MCP 셋업 + 「수아」 MetaHuman Creator 디자인 시작**.

원장님 패턴 DB — JSON schema 완성됐고 (`saas-c/pattern-db-schema.json`), 마스터 작품 6점 시드 등록됨. 차주 100 케이스까지 확장:
- 원장님 자료실 (6.5GB) 시술 사진 → Gemini Flash Vision으로 자동 분류
- face_shape · treatment_type · before/after 페어 자동 추출
- 100 케이스 = SaaS C 매칭 알고리즘 기초

Face Lab v7 핵심:
1. **사진 입력** = 정면+측면 (대표님 명시)
2. **분석** = MediaPipe 478 랜드마크 + 측면 깊이
3. **매칭** = 원장님 패턴 DB → 가장 가까운 케이스 N개 선정
4. **출력** = 2D PNG 펜슬 가이드 + 3D 360° MetaHuman 모델

3D는 이전에 검증됐어요. Higgsfield image_to_3d 30크/회 + Blender MCP 자동 렌더. Unreal MetaHuman은 차원이 다른 품질.

**「장미지 디지털 분신」** — 동의 받았으니까 6번째 MetaHuman. 차주 07-08 디자인 시작. 학원 OT 영상·신규 환영·시술 안내·24/7 가상 코칭 자동 생성.

우려 1개 — **의료광고법 §5.3**. 「시뮬 결과 = 실제 시술 결과로 오해 가능」 위험. 모든 결과에 「체험용」 워터마크 + 「실제 시술 90% 재현 보장」 카피 필수. 컴플라이언스 검토 한 번 더 받아야 해요.
