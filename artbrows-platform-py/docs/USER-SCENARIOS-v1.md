## 1. 9 단계 프레임 (Awareness → Retention)

```
① 인지 (Awareness)      ← 광고·SEO·바이럴
② 관심 (Interest)       ← 인스타 프로필·홈페이지 hero
③ 검색·비교 (Research)   ← 후기·비교·가격
④ 첫 방문 (First visit) ← 랜딩·상세 페이지
⑤ 신뢰 형성 (Trust)     ← 마스터 작품·서명·클레임 0
⑥ 리드 전환 (Lead)      ← 상담 신청·회원가입
⑦ 결제 (Purchase)       ← 예약금·수강료
⑧ 완료·성공 (Success)   ← 시술·수강 완료
⑨ 재방문·확장 (Retention)← 후기·추천·업셀
```

## 2. 타겟 A · 시술받는 사람 (treatment_b2c)

### A-① 인지
- **채널:** 인스타 릴스 (「시술 전 펜슬 미리 보기」 24초) · 네이버 검색광고 · 카카오 톡채널
- **핵심 메시지:** "결과 미리 확인 후 결정" · "펜슬로 그려주니 실패 걱정 X"
- **KPI:** CTR ≥ 1.5% · CPC ≤ 1,200원

### A-② 관심
- **랜딩 요소:** hero 이미지 (persona-ref 톤 · 20~25세 · 검정 탱크탑) + "장미지 원장 30년 노하우"
- **정보 밀도:** 3초 안에 「극사실 아트 눈썹」 · 「원장 서명 마스터 작품 6점」 · 「시술 전 펜슬 미리보기」 3개 인지
- **CTA:** [Face Lab v7 무료 체험] + [상담 신청]

### A-③ 검색·비교
- **경쟁 비교:** 마스터 작품 6점 갤러리 (그 중 3점 서명본) · 비포&애프터 (원장님 직접 제공 실사만)
- **가격 투명성:** 상담 후 안내 (구체 가격은 상세 페이지 최하단)
- **FAQ 최소 12개:** 통증 · 지속 기간 · 재시술 · 클레임 이력 · 부작용 · 알러지 · 마스크 관리 등

### A-④ 첫 방문
- **경로:** `https://lab.staris.cloud/` → SaaS A 홈 → Face Lab v7 진입 (SaaS C)
- **인지 부하 제거:** 회원가입 없이 Face Lab v7 익명 체험 가능 (결과 저장 시에만 회원가입 유도)
- **디자인:** Luxury Dark (`#0B0907` + Champagne Gold) · Nanum Myeongjo hero

### A-⑤ 신뢰 형성
- **★ 결정타 3종:**
  1. 마스터 작품 6점 (원장님 서명 3점) 페이지
  2. "시술 전 펜슬로 그려드리고 확인받고 시작" 스토리 (30년 클레임 거의 0)
  3. 실제 수강생 후기 (K1 카톡방 발췌)
- **의료광고법 §5.3 정합:** 결과 이미지에 「체험용」 워터마크 자동

### A-⑥ 리드 전환
- **최소 마찰:** 이름 · 전화번호 · 관심 시술 (3 필드) · 카카오 로그인 1클릭
- **CTA 문구:** "상담 신청" (결제 아님)
- **자동 응답:** 카카오 알림톡 60초 안 발송 (템플릿 예약 완료)

### A-⑦ 결제
- **금액:** 예약금 19,000원 (Toss Payments)
- **환불 정책:** 시술 24h 전 취소 시 100% 환불 (명시)
- **결제 후:** 자동 예약 확정 + 카카오 알림톡 + 시술 전 준비물 안내

### A-⑧ 완료·성공
- **시술 당일:** 원장님 펜슬로 미리 그려드리고 고객 확인 → 시술 진행
- **시술 후:** 관리법 카카오 자동 발송 (D+0 · D+3 · D+7 · D+14)
- **만족도:** 시술 D+14 후 자동 설문 (1클릭 만족도)

### A-⑨ 재방문·확장
- **재시술 유도:** D+180 시점 자동 리마인더 (연간 유지 관리)
- **추천 이벤트:** 지인 소개 시 다음 시술 -10% (양쪽 다)
- **업셀:** 시술 → 학원 수강 전환 funnel (김다은 발견 · 신규 수익원)

## 3. 타겟 B · 배우는 사람 (student · salon)

### B-① 인지
- **채널:** 네이버 블로그 검색 「반영구 학원 추천」 · 유튜브 「극사실 눈썹 교육」 · B2B 이메일 (기존 반영구샵)
- **핵심 메시지:** "다른 학원에서 못 가르치는 30년 펜슬 노하우" · "평생 수강" · "K1 카톡방"
- **KPI:** 블로그 유입 ≥ 500/월 · 유튜브 시청 시간 ≥ 60초

### B-② 관심
- **랜딩 요소:** hero + 「장미지 원장 = 극사실눈썹 창시자」 + 강의 5 카테고리
- **차별점 3종:**
  1. 원장님 직접 강의 (조교 X)
  2. K1 카톡방 평생 접근 (수강생 락인)
  3. 마스터 작품 6점 실물 사용 교육

### B-③ 검색·비교
- **경쟁 비교:** 유미코리아 · 서울반영구아카데미 대비 매트릭스
- **가격 투명성:** 69만원 (이지클래스) · 200만원 (극사실 3일반) 명시
- **후기 15+:** 실제 수강생 사진 + 개원 성공 스토리

### B-④ 첫 방문
- **경로:** 블로그 → SaaS A 홈 → 강의 일정 캘린더 → 상세 페이지
- **정보 우선순위:** 다음 주 개강 일정 · 남은 자리 · 수강 후기 · 마스터 작품
- **모바일 최적:** 캘린더 → 상세 → 결제까지 3 스크롤

### B-⑤ 신뢰 형성
- **결정타 3종:**
  1. K1 카톡방 시연 (수강생 실시간 원장님 답변)
  2. 원장님 직강 인증 (조교 X)
  3. 「30년 클레임 거의 0」 정량 데이터
- **의료광고법:** 강의 관련 광고는 §5.3 예외 (교육 목적)

### B-⑥ 리드 전환
- **최소 마찰:** 카카오 SSO 1클릭 + 관심 강의 선택 (2 필드)
- **CTA 문구:** "상담 신청" (결제 아님 · 통일)
- **자동 응답:** 카카오 알림톡 60초 안 + 원장님 개인 답변 24h 안

### B-⑦ 결제
- **금액:** 강의별 (Toss Payments)
  - 이지클래스: 69만원 · 3일 극사실반: 200만원 · 원데이: 20~40만원
- **분할 결제:** 3개월 무이자 (Toss)
- **결제 후:** K1 카톡방 초대 링크 자동 발송 + 강의 자료 접근권

### B-⑧ 완료·성공
- **강의 당일:** 실습 시간 필수 · 원장님 1:1 피드백
- **강의 후:** 「장미지」 서명 수료증 (PDF · SaaS C 워터마크 응용)
- **K1 카톡방:** 평생 접근 · 원장님 답변 · 신규 노하우 업데이트

### B-⑨ 재방문·확장
- **재수강 유도:** 이지클래스 → 극사실 3일반 업셀 (차감 할인)
- **B2B 라이센스 (신규):** 살롱 오너에게 마스터 패턴 DB 사용권 (월 구독)
- **강사 진출:** 우수 수강생 → 조교 → 강사 (커리어 트랙)
