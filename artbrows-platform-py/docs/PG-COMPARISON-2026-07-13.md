## 0. 결론 요약 (읽기 귀찮으면 여기만)

### 우리 상황
- **판매 상품**: 이지 클래스 **69만원 1건만** (8월 말 오픈)
- **매출 규모**: 초기 예상 월 6~10건 × 69만 = 400~700만/월 → **연 1억 미만 (영세·중소가맹점 우대 대상)**
- **환경**: 카페24 쇼핑몰 · 대표님 법인 사업자

### 💡 추천 (근거는 아래 상세)
- **🥇 1순위: 토스페이먼츠** — 개발 편의성·간편결제 통합·모바일 UX 최고. 초기 소규모라 관리비 부담 감내 가치.
- **🥈 2순위: KG이니시스** — 안정성·표준. 매출 커지면 이쪽이 유리.
- **🥉 3순위: 카페24 PG 패키지 (묶음)** — 카페24가 협상해서 파는 저렴한 묶음. 여러 PG 붙일 계획이면 이 경로가 편함.

### ⚠️ 결정 전 반드시 물어봐야 할 3가지
1. **영세·중소가맹점 우대 수수료율** (실제 우리 매출 예상 구간 기준으로) — 각 PG 담당자에게 직접 문의
2. **카페24 패키지 할인율** — 카페24 관리자 페이지에서 조회
3. **간편결제(카카오·네이버·토스페이) 별도 수수료** — 카드 수수료와 별개로 붙음

## 4. 실제 견적 받는 법 (07-18 마감 전 필수)

각 PG 담당자에게 다음 정보 주고 견적 요청:
1. 사업자 형태: **법인** (박정주 대표)
2. 업종: **교육 서비스** (반영구 아카데미)
3. 예상 월 매출: **초기 500만원~1,000만원**
4. 예상 결제 수단 비중: 카드 60% · 간편결제 30% · 기타 10%
5. 결제 채널: **온라인 (모바일 우선)**

### 카페24 관리자 페이지에서 원터치 신청

1. 카페24 로그인 (계정 없으면 먼저 생성)
2. **상점관리 → 결제관리 → 통합결제(PG) → 서비스 신청**
3. 원하는 PG 선택 → 필요 서류 안내 확인
4. 서류 제출 → 심사 → 개통 (평균 3~7일)

### 필요 서류 (공통)
- 법인 사업자등록증
- 통신판매업 신고증 (없으면 지자체 신청 · 1~2주 소요)
- 법인 통장 사본 · 인감증명서
- 대표자 신분증
- 홈페이지 URL (카페24 상점 개설 후)

⚠️ **통신판매업 신고증**이 준비 안 되어 있으면 이게 병목이 됩니다. 오늘 확인 필요.
