## 3. 네비 메뉴 구조 비교

### 유미코리아 (2 사이트로 분리)
```
[아카데미] [지점안내] [오시는길] [눈썹] [아이라인] [입술] [헤어라인] [SMP] [비포애프터] [시술가격]
```

### ARTbrows 제안 (1 사이트 통합 · 5 메뉴)
```
[홈] [시술] [아카데미] [갤러리] [지점·오시는길] · CTA: [상담 신청]
```

**차이점**:
- 유미코리아는 카테고리별 페이지 다수 → **정보량 많음** · **선택 피로 있음**
- ARTbrows는 5 메뉴로 압축 → **미니멀 럭셔리 톤** · **CTA 집중**

## 5. 유미코리아에서 「따올 것」 vs 「버릴 것」

### ✅ 차용 강력 추천 (5개)
1. **실시간 예약자·상담 접수 롤링** — 사회적 증거로 신뢰 형성
2. **모바일 하단 플로팅 3버튼** (전화·카톡·상담) — 모바일 컨버전 필수
3. **각 시술 페이지 하단 「이 시술 상담 신청」 CTA** — 페이지별 컨버전
4. **비포&애프터 갤러리 카테고리별 분리** — 눈썹·아이라인 등
5. **푸터에 명확한 사업자 정보·연락처** — 신뢰·법적 요건

### 🔀 우리 톤으로 변형
- 상담요청 폼 즉시 노출 → **CTA 버튼 → 상담 페이지** (럭셔리 톤 유지)
- 가격 리스트 노출 → **가격은 상담 후 공개** (프리미엄 포지셔닝)

### ❌ 버릴 것 (3개)
1. **프로모션 배너·할인 광고** — 럭셔리 톤 훼손
2. **너무 많은 시술 카테고리** — 미니멀 유지
3. **화이트 배경** — 우리 브랜드 아님

## 6. 예약·구매·상담 흐름 비교

### 유미코리아 (즉시 폼)
```
방문 → 히어로 폼 즉시 입력 → 전화·카톡 확정
```

### ARTbrows 제안 (럭셔리 funnel)
```
방문 → 브랜드 스토리 → 신뢰 형성 → CTA → 폼·예약 → SMS·카톡 확정
```

**차이 이유**: 유미코리아는 「대중 프리미엄·빠른 결정」 vs ARTbrows는 「럭셔리·신중한 결정」

## 7. 회의에서 확인받을 것

1. **톤 유지 vs 벤치마크 화이트로 순화** — 원장님 선호 확인
2. **가격 노출 여부** — 상담 후만 / 부분 공개 / 전체 공개
3. **프로모션·할인 사용 여부** — 럭셔리 유지 원칙 확인
4. **비포&애프터 저작권** — 원장님이 사용 가능한 사진 몇 장 있는지
5. **모바일 하단 플로팅** — 원장님 카톡·전화 노출 OK 여부
