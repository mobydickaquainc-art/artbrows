## 1. 4개 기능 상세 스펙 (어드민·LMS 제외)

### ① 홍보 페이지

**대상**: 브랜드 신뢰 형성 · 상담·수강 리드 유입

**페이지 구조 (7섹션 원페이지 + 하위 4페이지)**
1. 히어로 — "극사실 눈썹 창시자, 장미지 원장" + CTA 2개 (상담 신청 / 강의 보기)
2. 브랜드 스토리 — 30년 노하우 · 클레임 0 · 펜슬 미리 그리기 기법
3. 시술 소개 (하위 페이지) — 극사실 눈썹 / 아이라인 / 두피 SMP / 리터치
4. 아카데미 소개 (하위 페이지) — 3 강의 카테고리 · 「소수정예」 강조
5. 갤러리 (하위 페이지) — 마스터 작품 6점 + 수강생 작품 (원장님 큐레이션)
6. 지점 안내 (하위 페이지) — 선릉·봉은사 본진 + 지도 + 오시는 길
7. CTA 하단 — 상담 신청 폼 + 카톡 채널

**핵심 컴포넌트**: Nav / Hero / 시술 카드 / 원장 소개 / 후기 슬라이더 / Footer

**러프 견적**: **3~4일** (유나 무드보드 1일 + 이서연 카피 1일 + 개발 2일)

---

### ② 예약 페이지

**대상**: 시술 예약 · 방문 상담 예약

**핵심 기능**
- 예약 종류 선택 (극사실 시술 / 리터치 / 방문 상담)
- 지점 선택 (선릉 / 봉은사)
- 날짜·시간 선택 (기존 강의 달력 컴포넌트 재활용)
- 개인정보 (이름·연락처·요청사항)
- SMS 확인 발송 (알림톡 or SMS)
- 예약 확인·취소 페이지 (예약번호 + 연락처)

**기존 자산 재활용**
- `web/static/calendar.html` 달력 UI → 예약 캘린더로 변형
- `web/db.py` 확장 → `bookings` 테이블 신설

**러프 견적**: **4~5일** (달력 재활용 2일 + 예약 DB·SMS 연동 2~3일)

**결정 대기**: SMS 발송 채널 = 카카오 알림톡 / 문자 / 이메일 (원장님 선택)

---

### ③ 오프라인 강의 구매

**대상**: 강의 결제 · 수강권 발급

**핵심 기능**
- 강의 상품 3종 (극사실 3일반 200만 / 이지클래스 69만 / 원데이 20~40만)
- 상품 상세 (커리큘럼·강사·후기·일정)
- 결제 (PG 연동)
- 결제 완료 후 → K1 카톡방 초대 + SMS 확인
- 수강권 마이페이지 (예약번호로 조회)

**PG 연동 후보**
- **토스페이먼츠** (개발 2일 · 심사 3~5일)
- **카카오페이** (개발 2일 · 심사 5~7일)
- **네이버페이** (개발 2일 · 심사 7일+)

**러프 견적**: **5~7일** (실개발) + **PG 심사 별도 3~7일**

**결정 대기**:
1. PG 선택 (토스 추천)
2. 결제 후 자동 K1 초대 방법 (수동 링크 발송 vs API)
3. 환불 정책 (수강 3일 전 100%·1일 전 50% 등)

---

### ④ 상담 기능

**대상**: 문의 폼·상담 신청 (구매 전 리드)

**핵심 기능**
- 상담 카테고리 (시술 / 강의 / 기타)
- 개인정보 (이름·연락처·문의 내용)
- 첨부 사진 (선택 · 눈썹 현재 상태 등)
- 접수 → 원장님·운영진 카톡·이메일 알림
- 접수 확인 페이지 + SMS 확인
- (선택) 자주 묻는 질문 FAQ 20개

**러프 견적**: **1~2일** (폼 1일 + 알림 연동 1일)
