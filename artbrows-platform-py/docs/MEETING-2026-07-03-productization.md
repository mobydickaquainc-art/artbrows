# 전직원 상품화 회의 (2026-07-03 D+3)

> 대표님 안건:
> > "총 3개의 플랫폼을 발전시켜서 상품화 해야 되는데,
> > 전직원 회의 해서 좋은 아이디어 및 개발 기획을 더 보강하자"
>
> 형식: 8 직원이 각 SaaS 별로 상품화 관점 발언 → 대표님이 발전시킬 것 선택 → 개발 기획서 v1.1 반영

## 0. 현재 상품화 상태

| SaaS | 상품 정의 | 현재 진척 | 상품화 성숙도 |
|---|---|---|---|
| **A · 학원·강의·홈페이지** | 강의 상품 3종 + 홈 + 상담 funnel | ✅ 5/5 LIVE (표면) · 결제·SSO 아직 | 30% |
| **B · 광고 마케팅** | DIY 광고 SaaS (반영구 원장·살롱 대상) | ⏳ 0/4 · 구독 모델 미정 | 5% |
| **C · Face Lab v7** | 시술 전 시뮬 (무료 체험 · 상담 전환) | ⏳ 0/3 · API 라이센스 미정 | 10% |

**상품화 = 「이거 어떻게 팔 것인가」** 관점 · 개발 완성도가 아니라 **거래 발생 조건**

## 1. SaaS A · 학원·강의·홈페이지 상품화

### 이서연 (기획·마케팅) 발언

**A1. ⭐⭐⭐ 「극사실 3일반」 을 프리미엄 앵커 상품으로**
- 현재 3종 (69만·200만·20~40만) → 200만원 극사실 3일반을 히어로로 노출
- 이지클래스 69만원 = 앵커링 후 「사실 극사실이 진짜」 프리셀
- 원데이 = 리드 매그넷 (첫 진입용)
- **왜:** 럭셔리 브랜드는 최고가 상품을 먼저 노출, 나머지가 「합리적」으로 느껴짐

**A2. ⭐⭐ 「대기자 명단」 기능**
- 극사실 3일반은 정원 소규모 (5~7명?) · 매 기수 대기자 명단으로 희소성 강화
- 대기자에게 자동 알림 (다음 기수 D-30 · D-14)
- SMS · 카카오 알림톡

**A3. ⭐ 강의 「후기 인터뷰」 콘텐츠 시리즈 (월 2편)**
- 수강 후 개원한 원장님 인터뷰 → 유튜브 · 블로그
- SEO + 신뢰 형성 동시 · SaaS B (광고) 예비 고객 발굴 시너지

### 유나 (그래픽) 발언

**A4. ⭐⭐ 「장미지」 서명 굿즈 상품군**
- 수료증만 아니라: 서명 자수 앞치마 · 시술용 펜 세트 · 명함 (수강생 개원 지원)
- 수료 시 기본 세트 무료 · 추가 굿즈 별매 (30~50만원)
- **왜:** 학원 매출 외 굿즈 매출 축 신설 · 브랜드 락인

**A5. ⭐⭐⭐ Luxury Dark 「강의 브로셔 PDF」 판매용 자산**
- 오프라인 · 이메일 상담 시 발송할 40페이지 강의 소개 PDF
- 마스터 작품 6점 · 원장님 스토리 · 커리큘럼 · 후기 · 가격
- 유나가 매 분기 리뉴얼 · 필요하면 인쇄본 유료 (택배비만)

### 김다은 (SaaS A PM) 발언

**A6. ⭐⭐⭐ 「B2B 살롱 파트너 프로그램」 신설**
- 기존 반영구샵 원장이 → 자기 살롱 인테리어 유지하며 ARTbrows 브랜드 가입 (프랜차이즈 아님, 「인증 파트너」)
- 파트너 가입비 300만원 · 월 라이센스 20만원
- 혜택: 마스터 작품 6점 실습 소재 · K1 카톡방 접근 · Face Lab v7 화이트라벨 · 광고 SaaS B 할인
- **수익 모델 v2 신규** (2026-06-30 메모리 정합)

**A7. ⭐ 「시술 → 수강 전환 funnel」 자동화**
- Face Lab 이용 → 상담 예약 → 시술 만족 → 「배우고 싶으시면?」 카톡 자동 발송 (D+30)
- 시술 고객 중 살롱 오너 감지 → B2B 파트너 프로그램 소개

**A8. ⭐ 「강의 만족도 자동 설문 → 다음 기수 카피 자동 생성」**
- 설문 답변 → Gemini 로 후기 카피 자동 초안 → 유나 검수 → SaaS B 광고 소재 재활용

### 김민서 (UI) 발언

**A9. ⭐⭐ 「상담 신청 → 결제 30초 흐름」**
- 상담 신청 성공 화면에서 즉시 「예약금 19,000원 결제」 CTA
- 신청만 하고 결제 안 하면 D+1 · D+3 리마인더
- **왜:** 결제 전환율 2~3배 상승 (모비딕 통계 참조)

**A10. ⭐ 「학원 캘린더 iCal 구독」**
- 관심 강의 → 캘린더 앱에 자동 등록 · D-3 알림
- 앱 다운 없이 사용자 접점 유지

### 한승철 (백엔드) 발언

**A11. ⭐⭐ 「강의 신청→결제→K1 초대→알림톡→수료증」 파이프라인 자동화**
- 5 단계 완전 자동 · 사람 개입 없음
- 파이프라인 실패 시 대표님 텔레그램 알림 (0.1% 결제 실패 등)
- **왜:** 원장님 시술 시간 확보 · 학원 매출 무인 가동

**A12. ⭐ 「구독 결제」 지원 (Toss 정기결제)**
- 이지클래스 3개월 무이자 → 나중에 「K1 프리미엄」 월 구독 실험 (심화 콘텐츠 · 월 2만원)

### 박서윤 (SaaS B PM) 발언

**A13. ⭐⭐ 「강의 개강 D-14 광고 자동」**
- 캘린더에 등록된 강의 → D-14 시점 SaaS B 가 자동으로 인스타·페북·네이버 광고 3세트 생성 → 승인 대기
- 대표님 or 김다은 확인만 → 자동 게시
- **왜:** 강의별 마케팅 부담 제거 · 정원 채우기 확률 상승

### 최예진 (SaaS C PM) 발언

**A14. ⭐ 「강의 안에서 Face Lab 실습」**
- 극사실 3일반 D2 실습 시간에 수강생들이 실제 모델 얼굴로 Face Lab 매칭 → 원장님이 「이 매칭 왜 이렇게 나왔는지」 강의
- SaaS C 를 교육 도구로 재활용 · 라이센스 매출 대신 학원 매출 강화

### 클로드 (총괄) 발언

**A15. ⭐⭐ 「이지클래스 → 극사실 3일반 자동 업셀」**
- 이지클래스 수강 D+14 시점 만족도 조사 → 만족 10점자 → 극사실 3일반 「기존 수강생 30% 할인」 자동 오퍼
- **왜:** 수강생 1명당 LTV 69만 → 200만+수강생 시너지

## 2. SaaS B · 광고 마케팅 상품화 (가장 미개척)

### 박서윤 (B PM) 발언

**B1. ⭐⭐⭐ 요금 모델 3안 비교**
- ① **정액 구독** 월 9.9만원 (광고비 별도 · 무제한 캠페인)
- ② **광고비 % 수수료** 10~15% (Facebook Ads Manager 스타일)
- ③ **하이브리드** 월 4.9만원 + 광고비 5%
- **추천 ③** — 진입 장벽 낮고 성장 시 함께 매출 증가

**B2. ⭐⭐ 「반영구 원장 특화」 3 팩 (프리셋 캠페인)**
- 팩1: 신규 시술 유치 (인스타 릴스 + 네이버 검색)
- 팩2: 학원 수강생 모집 (블로그 SEO + 유튜브)
- 팩3: 재시술 리마인더 (카카오 채널 + LMS)
- **각 팩 = 30초 안 시작** · 초보 원장 대상 UX

**B3. ⭐ 「AI 카피 자동 A/B」**
- Gemini 3.1 Pro 로 카피 10 안 자동 생성 → 광고 3일 돌린 후 CTR 낮은 것 자동 폐기
- 원장은 「그냥 켜두면 광고비 최적화」

### 이서연 발언

**B4. ⭐⭐⭐ 「고객사 = 반영구 원장」 = 원장님 K1 카톡방이 첫 100 고객**
- SaaS B 첫 GTM = K1 안에서 「원장님 살롱에도 광고 자동으로 돌려드릴게요」
- 무료 3개월 파일럿 → 성공 사례로 유료 전환
- **왜:** CAC 사실상 0 · 신뢰도 이미 형성

**B5. ⭐⭐ 「의료광고법 자동 검열」 = 상품의 방어선**
- 광고 소재 게시 전 §5.3 위반 표현 자동 감지 (Gemini)
- 위반 시 즉시 대체 표현 제안
- **왜:** 반영구 원장은 광고 규제 두려워함 · 이거 하나로 락인

### 유나 발언

**B6. ⭐ 「살롱별 브랜드 톤」 자동 감지**
- 살롱 인스타 최근 20 게시물 스캔 → 브랜드 톤 (럭셔리/친근/네이처) 자동 분류
- 광고 소재 자동 생성 시 해당 톤 적용
- **왜:** 「이 광고 우리 살롱 같지 않아」 불만 해결

### 한승철 발언

**B7. ⭐⭐ 「예산 초과 방지 = 상품 안전선」**
- 이미 ad_budget_alerts 테이블 존재 · 50·80·100·120% 알림
- ⭐ 추가: 120% 넘으면 「강제 캠페인 정지 후 텔레그램 알림」 = 대표님 하한선 안전 장치

**B8. ⭐ 「매출 인식 자동」 = 광고 → 시술 매칭**
- 광고 클릭 사용자 → 상담 신청 → 시술 결제 → 3자 매칭 자동
- 「이 캠페인 실 매출 얼마 냈나」 대시보드 (ROAS)

### 김민서 발언

**B9. ⭐⭐ 「3분 온보딩」 = 첫 캠페인 발송까지**
- SSO → 살롱 정보 5필드 → 카피 톤 선택 → 팩 선택 → 게시
- 3분 안 완료 = SaaS B 진입 마찰 최소

### 김다은 발언

**B10. ⭐⭐⭐ 「원장 대시보드 = 매출 + 광고비 통합」**
- 이번 달 매출 · 광고비 · ROAS · 신규 상담 · 재시술 4 KPI
- 광고 SaaS 를 「경영 도구」로 격상 · 지속 사용 이유 형성

### 최예진 발언

**B11. ⭐ 「Face Lab 결과 자체가 광고 소재」**
- 수강생 · 시술 고객이 Face Lab 결과 SNS 공유 시 워터마크 = 자연 광고
- 공유당 크레딧 지급 (다음 시뮬 5회 무료) → 바이럴 유도

### 클로드 발언

**B12. ⭐⭐ 「경쟁사 벤치마크 자동 모니터링」**
- 매주 상위 10 경쟁 살롱 광고 스캔 (Meta Ad Library 크롤) → 트렌드 리포트 자동
- 「경쟁사가 이런 광고 돌리고 있어요」 인사이트 = 유료 가치 정당화

## 3. SaaS C · Face Lab v7 상품화 (가장 IP 무거움)

### 최예진 (C PM) 발언

**C1. ⭐⭐⭐ 「무료 시뮬 → 상담 예약 19,000원」 = 리드 매그넷 위주**
- Face Lab 자체는 판매 상품 아님 · SaaS A 로 리드 흘리는 깔때기
- 시뮬 100건 → 상담 예약 10건 → 실 시술 3건 (예상 전환율)
- **왜:** 30년 IP 무료로 뿌리는 게 아니라 「신뢰 형성」 관문

**C2. ⭐⭐⭐ 「Face Lab API 화이트라벨 라이센스」 = 진짜 상품**
- 개별 살롱 · 병원이 자기 홈페이지에 Face Lab 을 내장 (iframe · API)
- 월 라이센스 20~50만원 · 사용 건수당 크레딧
- **왜:** 원장님 30년 패턴 DB 를 IP 로 팔 수 있음

**C3. ⭐ 「원장님 패턴 DB 100 케이스 확장 로드맵」**
- 현재 6 시드 → 100 케이스까지 원장님 시술 후 자동 등록
- Face Lab 정확도 = 케이스 수 비례
- **월 8~10 케이스 자동 등록 파이프라인** 필요 (원장님 시술 사진 자동 분석)

### 이서연 발언

**C4. ⭐⭐ 「비포/애프터 시뮬 콘테스트」**
- Face Lab 사용자가 결과 인스타 공유 시 이벤트 응모
- 월 1명 무료 시술권 지급 = 사용자 참여 + 콘텐츠 재생산
- 「체험용」 워터마크가 오히려 「이건 시뮬」 재밌는 것으로 재프레임

**C5. ⭐⭐ 「Face Lab 결과 → 소셜 카드 자동」**
- 결과 화면에 「이 결과 인스타 카드로 만들기」 → 자동 디자인 (Luxury Dark 톤)
- 공유하면 브랜드 노출 · 다음 사용자 유입

### 유나 발언

**C6. ⭐⭐ 「3D 뷰어 시그니처」 UX**
- `<model-viewer>` 배경에 Luxury Dark 스튜디오 HDR 로드 · 회전 시 warm rim light
- 「이 뷰어 다른 데는 못 봄」 시각 차별화 · 브랜드 인상 형성

**C7. ⭐ 「원장님 노트 = 캘리그래피 오버레이」**
- 결과 뷰어 하단 원장님 노트에 손글씨 폰트 사용 (유나 서명체 개발) → 사람이 쓴 느낌

### 한승철 발언

**C8. ⭐⭐⭐ 「MediaPipe 로컬 처리 vs 서버 처리 선택제」**
- 초경량: 브라우저 MediaPipe 로 랜드마크만 → 서버는 case_id 매칭만
- **왜:** 서버 비용 90% 절감 · 개인정보 우려 회피 · 오프라인 반응 3초 → 0.5초
- 3D GLB 만 서버 (Higgsfield)

**C9. ⭐ 「사진 대신 실시간 카메라 매칭」**
- 모바일 카메라 → 실시간 랜드마크 트래킹 → 실시간 오버레이
- Phase 3 실험적 · WebAR 급 UX

### 김민서 발언

**C10. ⭐⭐ 「사진 업로드 실패 방지 UI」**
- 정면 필터 (얼굴 정중앙 · 90% 이상 노출 시에만 촬영 버튼 활성)
- 측면 필터 (귀 45~90도 · 눈코입 라인 명확)
- **왜:** 잘못 찍은 사진으로 시뮬 실패 시 이탈률 60%+

### 김다은 발언

**C11. ⭐⭐ 「Face Lab 결과 = 상담 시 원장님 참고 자료」**
- 시뮬 결과가 원장님 태블릿에 자동 표시 (예약 완료 시)
- 원장님이 실 시술 전 미리 매칭 결과 확인 → 시술 시간 20% 단축

### 박서윤 발언

**C12. ⭐⭐ 「Face Lab 사용자 = 재타겟팅 최적 시드」**
- 시뮬 이용 사용자 = 반영구에 진짜 관심 있음 (강도 3배)
