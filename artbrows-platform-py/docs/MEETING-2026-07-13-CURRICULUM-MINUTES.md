## 1. 이지 클래스 커리큘럼·강사 구조 ★★★

### 확정 사항

| 항목 | 결정 |
|------|------|
| **총 시간** | **5일 × 3시간 = 15시간** (마지막 날 실습이라 3시간 초과 가능) |
| **수강료** | **69만원** (99만원 롤백) |
| **정원** | **10명** (강사 2명 투입 시 최적) |
| **강사** | 강사 1명당 최대 6명 (4명이 가장 좋음) → **강사 2명 배치** |
| **원장님 역할** | 15시간 중 **3~4시간만 직강** (개요·결과 리뷰) · 실습 중 잠깐 봐주기 |
| **수료 산출물** | **수료증(디플로마) 발급** ✅ |
| **홍보 메시지** | "20 클래스 수료 → **30만원 수준 시술 가능**" |

### 원장님 시간 활용 원칙

- **원장 직강 = 극사실 소묘·눈썹만 (프리미엄)** — 화·수·목
- 나머지 요일(금·토·일·월) = 강사들이 이지 클래스 진행
- 원장님은 이지 클래스에는 **컨셉 잡아주기 + 퍼포먼스 시연 + 창업 스토리텔링** 중심

### 커리큘럼 재정의 (중요)

- 기존: 이지 클래스도 "극사실" push → 초보가 어려워서 이탈
- 신규: **이지 클래스 = 진짜 「이지」** = 편하게 입문 + 재미 + 30만원짜리 시술 가능 수준
- 극사실은 **다음 단계(소묘+눈썹 235만)**에서 push

## 2. 이지 클래스 가격 확정 ★★★

### 결론: **69만원 롤백 확정**

| 시점 | 가격 | 결과 |
|------|------|------|
| 07-06 이전 | 69만원 | 매월 6~10명 모집 (정상) |
| 07-06 결정 | **99만원 인상** | 이번달 **0명** (홍보 부재 + 인상 겹침) |
| 07-13 회의 | **69만원 롤백** | 파트너 5개 방과 금액 통일 필수 |

### 왜 롤백인가

1. **파트너 계약과 금액 통일 필수** — 파트너들에게 이지 클래스 판권 팔았고 그 금액이 69만원. 본점만 99만원이면 구조 붕괴
2. **99만원 인상 후 파트너 문의 늘어난 것 관찰** — 소비자가 실제로 조사·비교 중이라는 신호
3. **회장님 판단**: "새끼 강사들 시키고 원장님 프리미엄으로 계속 끌고 올라가는 게 원래 취지" — 취지대로 유지

### 온라인 할인 아이디어 (부수)

- 링크에서 5만원 즉시 할인
- 타임 세일 (30분마다 할인율 변동)
- 이지 → 소묘·눈썹 업셀 할인 (등록 흐름 이어질 때)

## 3. 수강생 타겟·유입 분석

### 실제 수강생 프로파일 (원장님 관찰)

| 축 | 비중 | 특징 |
|----|------|------|
| **직장인 초보** | 60~70% | 월급 2천만~ · 부업/전직 희망 · 30~40대 · 경력단절 여성 다수 |
| **다른 뷰티 종사자 (헤어·피부)** | 30~40% | 부가가치 확장 목적 · 저렴하니 한번 배워봄 |
| 20대 | ~1~2% | 국비 지원 안 됨 · 부담 |

### 왜 20대 유입 안 되는지 (원장님)

- 반영구 시장 진입 = **5~700만원** 부담 (경락+장비 포함)
- 미용은 국비 지원 되지만 **반영구는 국비 대상 X**
- 20대는 대부분 국비로 미용·메이크업 배운 뒤 반영구로 유도되는 구조
- 회장님·본부장 결론: **국비 지원 학원(MBC 아카데미 등)과 조인 커리큘럼** 검토 가능

### 인스타 광고 타겟 미스매치

- 광고는 30~40대 여성 반응 좋음
- 실제 수강생은 40대가 더 많음
- **광고 타겟 조정 필요**: 나이·지역 필터 추가 (지금까지 안 하고 있었음)

## 4. 극사실 소묘·눈썹 세트

### 확정 사항

| 상품 | 가격 | 구조 |
|------|------|------|
| **소묘 단품** | 66만원 | 3일 연속 · 그림만 · 눈썹 시술 사전 필수 |
| **눈썹 단품** | 169만원 | 7시간 · 실습 · 소묘 이후 진행 |
| **★★ 세트** | **235만원** | 소묘 + 눈썹 = **커리큘럼 1개로 통합** · 할인 없음 |
| **★★★ 종합** | **660만원** | 세트를 **3번 수강** (반복 학습) · 할인 포함 |

### 세트 판매 방식 (원장님 현재 대응)

- 이지 클래스 문의로 들어오는 초보에게 **세트로 유도**
- 설명: "이지 클래스는 바늘 끼우기부터 시작 → 재미없음 · 나중에 세트 배우면 이지가 그냥 껌"
- 반응: 6일 등록으로 넘어가는 경우 다수

### 다른 학원 비교 (원장님 조사)

- 대부분 "1:1 수업 · 주 1회 · 9~12주" 라고 광고
- 실제 강의 시간은 **강사가 20분 설명 → 나머지 시간 자습(그리기 연습)**
- 원장님 강사는 시술도 함께 → 수업 5~10분 후 시술실로 들어감
- 마지막 주에만 시술 실습 (졸업 직전)
- **원장님 시스템은 여기와 완전히 다름** → 마케팅 포인트로 활용 가능

## 5. 강사반(제자반) 신설 ★★

### 확정 사항

- **강사반 개설 확정** (파트너십 신설은 나중)
- 대상: 1년 제자반 졸업 예정자들 · 「강사 시켜달라」 로비 중인 인원 존재
- 절차: **한 달~두 달 트레이닝 (유료)** → 수업 서브 참여 → 페이 지급
- **동시 진행**: 강사반 트레이닝 병행하며 이지 클래스 모집 계속 → 인원 많이 모이면 강사 즉시 투입

### 왜 강사반이 필요한가 (원장님)

- 1년 제자반이 끝나가는 시점 → 졸업생은 갈 곳이 없음
- **강사라는 타이틀** = "붙어 있을 곳" = 안정감
- 이들이 나가서 시술 열면 마케팅·모객 부담 → 대부분 500~600 정도 벌기 어려움 → 여기 있는 게 이득
- **강사 리텐션 설계 필수**: 강사가 매월 500~600 안정적 수익 → 나가지 않음

### 회장님 통찰 (강사가 나갈까 안 나갈까)

- 30만원 × 시술 15명 = 450만원 (강사 개인 매출) → 나가면 천만원 벌 것 같음 (계산)
- 하지만 나가면 **영업·마케팅** 부담 → 실제 200~300으로 급락
- 다시 들어오려 함 = 이런 시행착오 반복 발생
- **설계 핵심**: 여기서 5~600 안정적으로 벌 수 있으면 강사는 안 나감

### 파트너십과 강사반 관계

- **파트너십**: 지역 살롱 대상 · 이지 클래스 판권 판매 (기존)
- **강사반**: 본점 강사로 남을 사람 (신규)
- 서로 다른 트랙 · 파트너십 확장은 강사반 안정 후 검토

## 6. 요일별 강의 구조

### 원장님 이상적 스케줄

| 요일 | 담당 | 강의 |
|------|------|------|
| 화·수·목 | **원장님 직강** | 극사실 소묘 · 극사실 눈썹 (프리미엄) |
| 금·토·일·월 | **강사** | 이지 클래스 (평일반 · 주말반) |

### 평일반 vs 주말반

- **주말반 (일요일)** — 수요 더 많음 (직장인 · 주 5일 근무자)
- **평일반 (월·화)** — 미용업계 종사자 (월·화 휴무 많음 · 백화점 등)
- 결론: **둘 다 열어야** = 이지 클래스 최대 월 4개 반 가능

### 클래스 확장 시나리오

- **1차**: 이지 클래스 1개 반 (10명 정원 · 강사 2명)
- **2차**: 평일 + 주말 각 1반 = 2개 반 = **월 20명**
- **3차**: 요일별 확장 시 **월 40명까지 이지 클래스 가능** (회장님 계산)

## 7. 국비 지원 관련

### 현재 상태

- 반영구는 **국비 지원 대상 X**
- 미용·메이크업·피부는 국비 지원 됨 → 그쪽으로 20대 흡수됨
- 학원 요건(소방·설비) 갖추기 까다로움 → 원장님 이전에 신청했다가 접음

### 대안

- **MBC 아카데미 등 국비 학원과 조인 커리큘럼** 검토 가능
- 유미코리아 방식: 다른 과정으로 국비 요건 충족 → 반영구는 추가 등록 유도
