## 일일 브리핑 (모비딕 패턴)

### 자동 생성
```bash
# 오늘
python scripts/generate_daily_briefing.py

# 특정 날짜
python scripts/generate_daily_briefing.py 2026-07-01
```

산출:
- `reports/briefing_YYYY-MM-DD.pdf` (대표님 PDF)
- `reports/briefing_YYYY-MM-DD_p1.png` (페이지 1)
- `reports/briefing_YYYY-MM-DD_p2.png` (페이지 2)

### 데이터 입력 (각 직원이 작업 끝낼 때마다)

```bash
# data/logs/saas_a_YYYY-MM-DD.jsonl 에 한 줄 추가
echo '{"staff":"김다은","task":"강의 일정 생성","status":"done","time":"14:30"}' >> data/logs/saas_a_2026-07-01.jsonl
```

`status` 값: `done` · `in_progress` · `blocked`

### 매일 자동 실행 (Windows 작업 스케줄러)

`schtasks` 명령으로 매일 17:00 자동:
```powershell
schtasks /create /tn "ARTbrows-Daily-Briefing" /tr "D:\work\jangmi\artbrows-project\artbrows-platform-py\.venv\Scripts\python.exe D:\work\jangmi\artbrows-project\artbrows-platform-py\scripts\generate_daily_briefing.py" /sc daily /st 17:00
```

## 트러블슈팅

### Q. FastAPI 서버 안 떠요
A. `.venv\Scripts\activate` 먼저 했나요? `python -m uvicorn web.app:app --host 0.0.0.0 --port 8001`

### Q. Quick Tunnel URL이 바뀌어요
A. 개발 모드 정상. 영구 도메인 (`app.eyebrows.staris.cloud`) 은 베타 직전 셋업.

### Q. 브리핑 PNG에 한글이 깨져요
A. `C:\Windows\Fonts\malgun.ttf` 있나요? 없으면 `Nanum Gothic` 다운로드.

### Q. 일일 로그 어디에 써요?
A. `data/logs/{saas_a|saas_b|saas_c|team}_YYYY-MM-DD.jsonl` 한 줄씩.
