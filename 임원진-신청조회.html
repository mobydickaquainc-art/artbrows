임원진 결정 요청 사항

  • 광고 4종 UTM 분리 — 위 표처럼 「광고 ID 별 전환율」 보려면 광고 클릭 URL 에 UTM 파라미터 추가 필요. 5분 작업.
  • 이 페이지 라이브 배포 — 운영진 방으로 영구 사용하려면 Next.js 에 `/admin/inquiry` 신설 + Supabase 조회. 약 1시간.
  • Google Sheet 자동 동기화 — Supabase → Sheet Webhook + Service Account JSON 필요. 약 30분 + 자격증명.
  • 알림 자동화 — 새 신청 들어오면 카카오톡/이메일/슬랙 자동 알림. Supabase Edge Function 1~2시간.
  • 운영진 권한 분리 — 「조회만」 / 「상담 상태 변경」 / 「전체 관리」 3 단계 권한. 약 1시간.
