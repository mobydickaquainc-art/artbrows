기능 (MVP)

① 자동 일정 생성

원장님 가용 시간 + 수업 종류 + 수강생 신청 → AI가 한 달 전체 스케줄 자동 배치

② 달력 시각화

원장님 기존 달력 패턴 그대로 (대표님이 사진 보여줄 예정 → 1:1 재현)

③ 수강생 자동 매칭

신청서 입력 → 적합 수업 자동 추천 → 카카오 채널 자동 알림

④ 자동 게시

스케줄 완성 → 인스타·블로그·홈페이지 자동 게시 (SaaS A 연결)

⑤ 변경 알림

수업 시간 변경·취소 시 수강생 자동 알림 (카카오·SMS·이메일)

⑥ 통계 자동

월 강의 수·수강생 수·수익 자동 계산 → 원장님께 매월 1일 요약 보고
