이서연 기획·마케팅 PLANNER

오늘 정리된 5축 — 일일 자동 포스팅·다채널 AI 응답·중국·미국·웹앱 — 이걸 한 페이지에 5장 카드로 보여주는 신규 진입점이 필요해요. 기존 포털과 시각적으로 살짝 차이를 두되 (살구핑크 베이스는 유지) 같은 브랜드 안에서 "오늘부터" 라는 신호만 명확하게.

"포지셔닝은 그대로. 다만 오늘부터의 흐름은 시청자가 한눈에 알게."
유나 그래픽·비주얼 VISUAL

비주얼 톤 리얼 극사실 박혔으니, 신규 5축 카드 이미지는 모두 极致写实 + 자연광 + 셀카 톤으로 갈게요. 코믹 톤 ✗ — 다 빼고 정리. 신규 진입 페이지 hero 컷은 어두운 배경 + 자연광 한 컷으로 잡으면 기존 톤과 매끄럽게 이어집니다.

"코믹 다 뺐어요. 이제 진짜 사진 같은 결로만."
한승철 풀스택 · CTO급 · 신규 CTO

안녕하세요, 한승철입니다. 들어와서 보니 PoC 가 이미 돌고 있고 (Flask + faster-whisper + 영상 업로드 UI), 그 자체는 잘 만들었습니다. 다만 운영급으로 가려면 결정해야 할 게 있습니다.

  • DB: 지금은 파일(JSON) 기반. 5축 다 붙으면 잡 큐·세션·결과물 메타데이터가 필요 → SQLite → PostgreSQL 단계적 권장.
  • 인증: 외부 노출 전 단순 패스워드 게이트라도. 키(.env)는 절대 리포에 안 올라가게.
  • 인프라: 모비딕 표준 따라 맥미니 + Tailscale + launchd. Docker 안 씀.
  • 잡 큐: 영상 STT·번역·렌더링이 분 단위로 길어지면 동기 응답 안 됨 → 비동기 잡 큐(BullMQ 또는 RQ).
  • 비용: API 3종(Claude·GPT·Gemini) 동시 호출은 비용 3배. 일반은 1엔진, "비교 모드"만 3엔진.
"화려한 거 없이 단단하게. '이게 정말 지금 필요한가요'를 늘 묻겠습니다."
클로드 코드 진행·기록 CC

  • 라운드 4+: 다채널 AI 응답 · 위챗 · LA 진출 — 각각 별 루프
