A전 직원 4인 관점별 의견

이 이서연 · 기획·마케팅 유저 경험·전환·CTA

★ 입장 — "리얼하게 보여줄수록 「상담 신청」 전환이 높아진다. 다만 90초 이상 기다리게 하면 다 떠난다."
  • 전환 가설 — 2D 사진 대비 3D 시뮬레이션 = 「시술 결정」 까지의 심리적 거리 단축. 인스타·중국 SNS 에서 「3D 시뮬레이션」 자체가 콘텐츠 (바이럴)
  • 최대 허용 대기 시간 — 30초. 60초 이상이면 50% 이탈. 「로딩 동안 8 스타일 진단 결과 보여주기」로 체감 시간 단축
  • 레퍼런스 — 레드노트의 「얼굴 미학 / 성형 시뮬레이션」 인기 영상 = 모두 「프리뷰 3초 안에 결과」 패턴
  • UX 핵심 — 「슬라이더」(전/후) 가 「3D 회전」보다 전환 강함. 회전은 「내 얼굴이 그대로다」 라는 신뢰 + 슬라이더는 「변화량」 강조
  • 마케팅 활용 — 3D 모델 회전 영상 = 인스타 릴스 자동 생성. 한 시술 케이스 × 5 각도 영상 = 즉시 사용 가능 콘텐츠
★ 추천 — 「2D 시뮬레이션 (즉시) → 3D 모델 (백그라운드 로딩)」 2단계 UX. 3D 는 「추가 보너스」로 보여줘서 대기 부담 ↓

유 유나 · 그래픽·비주얼 디자이너 리얼리즘 · 아트 디렉션 · 톤

★ 입장 — "AI 3D 는 「Uncanny Valley」 문제가 가장 크다. 어색한 3D = 브랜드 손상. 리얼리즘 90점 이상 아니면 안 보이는 게 낫다."
  • 퀄리티 기준 — Apple MetaHuman / Pixar 급 = 90+ · 일반 3D 아바타 = 50~70 (Uncanny Valley) · Higgsfield generate_3d / TripoSR = 40~60 (시연용 OK, 마케팅엔 부족)
  • 해법 A — 「얼굴은 실사 + 눈썹 영역만 3D 합성」 (가장 안전). InstantStyle / DragGAN 으로 눈썹만 변형 → 실사 유지
  • 해법 B — 「Stylized 3D」 (일러스트 스타일로 거리감 만들기). 사실주의 추구 X. 「ARTbrows 시그니처 스케치 톤」 으로 카메라 / 광대뼈 디자인 톤 통일
  • 해법 C — 「NeRF / Gaussian Splatting」 (사진 5~10장 → 실사 3D). 신기술. 품질 80+, 단점 = 촬영 부담
  • 아트 디렉션 — 살구톤 + 명조 디자인 시스템 유지 필수. 3D 뷰어 배경 = 크림 화이트 (#FFFBF5) + 핫핑크 액센트
★ 추천 — 「얼굴 = 실사 (2D) + 눈썹 = 3D 변형」 하이브리드. Uncanny Valley 회피 + 시그니처 라인 강조 가능

민 김민서 · Face Lab 리드 AI · 3D 재구성 · 정확도

★ 입장 — "단일 사진 → 3D 얼굴 재구성은 오픈소스로 90% 가능. 본질은 「얼굴 메쉬 + 눈썹 변형 알고리즘」 결합이다."
  • FLAME / DECA / EMOCA — 학술 표준. 단일 사진 → FLAME 5023 vertex 메쉬. Python 환경 필요. CPU 5~15초 · GPU 1~3초. 정확도 ★★★★
  • SMPL-X + FLAME — 전신 + 얼굴. 학원용 오버스펙. 얼굴만이면 FLAME 충분
  • TripoSR / Hunyuan3D — 최신 (2024) 단일 이미지 → 3D 메쉬. 5초 내. 정확도 ★★★ (얼굴 디테일 부족)
  • Gaussian Splatting — 사진 다중 (5~20장) → 실사 3D 렌더. 정확도 ★★★★★, 단점 = 촬영 부담 + 메쉬 추출 어려움 (직접 변형 X)
  • Higgsfield generate_3d — image_to_3d 모델. 즉시 사용 가능 (지금 보유). 정확도 ★★★ (시연용)
  • ★ 눈썹 변형 — DragDiffusion / InstantStyle 로 2D 단계에서 「내 얼굴」 + 「추천 눈썹 8 형」 합성. 메쉬는 부수적
  • 실시간 AR (라이브 카메라) — MediaPipe Face Mesh + Three.js. 실시간 시연 = 「오프라인 살롱 데모」 강력
★ 추천 — 즉시: Higgsfield generate_3d → Three.js viewer (오늘 PoC) · 정밀: FLAME + DragDiffusion (Phase 2, 2주) · 데모: MediaPipe + Three.js 실시간 AR (Phase 1.7, 3일)

한 한승철 · 풀스택 (인프라·성능) 로딩 시간 · CDN · 비용

★ 입장 — "웹에서 3D 뷰어 자체는 5KB. 진짜 문제는 「3D 모델 파일 크기 (5~50MB)」 와 「추론 서버 비용」 이다."
  • Three.js / Babylon.js / model-viewer — 라이브러리 자체는 가벼움. `<model-viewer>` (Google) = 코드 3줄로 GLB 임베드. 5KB 학습 곡선
  • GLB 파일 크기 — Higgsfield generate_3d 출력 ~ 3~10MB. 모바일 4G 에서 3~10초 다운로드. Draco 압축 시 ~ 1~3MB
  • FLAME / DECA — Python 서버 필요. AWS g4dn.xlarge GPU = 시간당 $0.50. 동시 사용자 10명 → 월 $300+. 학원 규모엔 비쌈
  • 대안 — Modal / Replicate / RunPod 등 서버리스 GPU (요청당 과금). 사용자당 ~$0.02. 10명/일 = 월 $6 정도
  • Higgsfield 옵션 — 우리 보유 크레딧. image_to_3d ~ 5~10 크/장. 월 100명 시연 = 500~1000 크 (Plus 플랜 충분)
  • CDN — Cloudflare R2 / Netlify CDN. 한국·미국·중국 모두 100ms 이하. 추가 비용 거의 없음
  • 성능 함정 — 클라이언트 추론 (TensorFlow.js · onnx.js) = 폰에서 30초+ 멈춤. 반드시 서버 추론
★ 추천 — 시연·소량: Higgsfield generate_3d (지금 보유) + `<model-viewer>` 임베드 (가장 쉬움). 본격 라이브: Replicate FLAME API + R2 CDN (월 $20 안쪽)

C카테고리별 방법 상세 — 「웹 / 데스크탑 / 모바일」

C-1. 웹 (브라우저 안, 설치 없음)

  • <model-viewer> (Google · 오픈소스 · 가장 쉬움) — GLB / GLTF 파일을 HTML 3줄로 임베드. 회전·줌·AR 모드 자동. iOS Quick Look 지원. → Phase 2 PoC 1차 후보
  • Three.js (오픈소스 · WebGL 표준) — 자유도 최고. 라이트닝·재질·애니메이션 직접 제어. 학습 곡선 보통
  • Babylon.js (Microsoft · 오픈소스) — Three.js 대안. 게임 / 인터랙티브 강함. 학원용엔 Three.js 가 더 가벼움
  • Spline (노코드 3D 에디터 · 임베드) — 디자이너 친화. 학원 메인 페이지 히어로 영상으로 가능
  • Banuba / DeepAR / 8thWall (상용 WebAR SDK) — 인스타 필터 수준의 실시간 얼굴 트래킹 + 메이크업·눈썹 변형. 월 라이선스 $200~$2000
  • MediaPipe Face Mesh + Three.js (자체 구현) — 실시간 카메라 → 478 랜드마크 → 3D 메쉬 오버레이. 김민서 추천 = 살롱 데모용 강력
  • WebXR / WebAR (네이티브 표준) — iPhone/Android 브라우저에서 AR. 아직 호환성 제한적

C-2. 데스크탑 / 프로그램 툴

  • Blender (무료 · 오픈소스) — 정밀 3D 모델링 + 렌더링. 학원 캐릭터 모델 제작 + 영상 굽기
  • Unreal Engine 5 + MetaHuman (무료, Epic) — 영화급 실사 얼굴. 「장미지 원장님 가상 아바타」 제작 + 인스타 광고 영상 굽기
  • Unity + ARFoundation (무료) — 모바일 앱 출시 시 사용. 웹은 WebGL 빌드
  • Character Creator 4 + iClone (Reallusion · 유료 $300~) — 빠른 캐릭터 제작 + 애니메이션
  • Pinscreen / Avatar SDK (상용 API · 단일 사진 → 3D 아바타) — 가격 협상, 학원 규모엔 ROI 애매
  • FLAME / DECA / EMOCA (학술 오픈소스, Python) — 단일 사진 → FLAME 메쉬. 정밀 + 자유 변형 가능. 김민서 Phase 2 본격
  • Higgsfield generate_3d (현재 보유 · MCP) — image_to_3d / multi_image_to_3d / sam_3_3d / 3d_rigging. 오늘 즉시 PoC 가능
  • Hunyuan3D / TripoSR / SF3D (오픈소스 · Replicate) — 5초 내 image-to-3D. 서버리스 GPU

C-3. 모바일 SDK / 네이티브

  • Apple ARKit (Face Tracking) — iPhone X+ 전용. TrueDepth 카메라 사용 시 정밀. Snapchat / Instagram 수준
  • Google ARCore (Augmented Faces) — Android 호환. 468 메쉬 + 메이크업 오버레이
  • Banuba SDK (iOS/Android/Web) — 상용 라이선스. 인스타 필터급 즉시 효과
  • DeepAR — Banuba 대안. 가격 더 저렴, 품질 약간 낮음

C-4. 하이브리드 / 신기술 R&D

  • Gaussian Splatting (2023~) — NeRF 후속. 사진 5~20장 → 실사 3D. 「장미지 원장님 가상 아바타」 영구 자산화에 적합 (1번 촬영 → 평생 사용)
  • Stable Diffusion + ControlNet (InstantStyle / IP-Adapter) — 2D 단계에서 「얼굴 유지 + 눈썹·메이크업 변형」. 유나 추천 = Uncanny Valley 회피
  • DragDiffusion / DragGAN — 정밀 점 제어로 「눈썹 모양」 만 변형. 시그니처 라인 매칭에 최적
  • Higgsfield Soul + generate_3d 결합 — Soul = 가상 아바타 생성 + 3D 변환. 학원용 「8 스타일 진단 카드」 자동화
