Face Lab — 얼굴 종합 미학·성형 시뮬레이션 툴 (대폭 확장)

ARTbrows 통합 플랫폼 신규 메뉴 (06/22 대표님 결정 · 확장).
「내 얼굴은 어떻게 하면 어려 보이고, 어떻게 하면 이쁜가?」 — 눈썹 진단을 넘어 얼굴 종합 미학 + 어림 보임 시뮬레이션 + 이상적 라인 변환 + 부분별 성형 가이드 + 실사 3D 얼굴 재구성 까지 한 메뉴에 통합.
★ 단계적 출시 — Phase 1 안전한 눈썹 진단부터 → Phase 2 종합 미학 → Phase 3 3D 시뮬레이션 (법적 검토 단계마다 필수)

메뉴 위치eyebrows.staris.cloud/face-lab (예정)
개발 트랙학원·쇼핑몰과 별도 R 라운드

  • 미성년자 보호 — 만 14세 미만 사용 차단 + 보호자 동의 절차.

04-X★ Phase 2·3 — 종합 얼굴 미학·성형 시뮬레이션 (06/22 확장)

06/22 대표님 결정 — 얼굴에 대한 모든 미학·성형 시뮬레이션 통합 툴. Phase 1 (눈썹 진단) 출시 후 단계적 확장.

P2-1
실사급 3D 얼굴 재구성
2D 셀카 → 실제와 거의 똑같은 3D 메시. 360° 회전 가능. 기술: FLAME / DECA / EMOCA / Higgsfield generate_3d
P2-2
「어리게 보이기」 시뮬레이션
동일 인물의 -5/-10/-15세 모습 미리보기. 피부·라인·볼륨 분석 + 안티에이징 가이드 (성형 권유 X)
P2-3
「이쁘게 보이기」 미적 분석
황금비 + 페이스 라인 + 표정 분석 → 8가지 미적 캐릭터 (지적·발랄·우아·강인 등) 中 가장 가까운 매칭 + 메이크업·표정 가이드
P2-4
부분별 성형 시뮬레이션
코·턱·눈·이마·광대 등 부분별 「변화 정도」 슬라이더 → 실시간 미리보기. 「가이드」 한정 · 의료 진단 표현 X
P2-5
전체 얼굴 미학 코칭
눈썹·메이크업·헤어·옷차림 종합 추천. 「장미지 원장 직강 + 협력 클리닉 연계」 (R4~)
P2-6
3D 가상 캐릭터 (실사급)
자기 얼굴 안 쓰고도 가상 캐릭터로 시뮬레이션 가능 (CLAUDE.md §4 준수)

⚠️ Phase 2·3 추가 법적 위험 (Phase 1 룰 + 강화)

  • 의료법 위반 → 최대 5년 이하 징역 — 「성형 권유」 「수술 효과」 「의료 행위 묘사」 절대 X. 「엔터테인먼트·미적 가이드 한정」 명시 의무.
  • 외모 차별·미적 강요 비판 — 「어리게」 「이쁘게」 표현 시 「개인의 선호 · 다양성 존중」 문구 항상 노출.
  • 미성년자 보호 강화 — 「성형 시뮬레이션」 부분은 만 19세 이상 본인 인증 필수.
  • 가상 캐릭터 풀 활용 우선 — 본인 얼굴 변환 보다 가상 캐릭터 시뮬레이션 우선 (CLAUDE.md §4).
  • 본인 얼굴 변환 시 동의 절차 — 모든 변환 결과는 「예측 모델 결과 · 실제 효과 보장 안 함」 면책.
  • 변호사 검토 단계별 필수 — Phase 2 진입 전 + Phase 3 진입 전 각각.
  • 협력 의료 기관 연계 시 — 광고법상 「병원 추천」 표시 의무.
