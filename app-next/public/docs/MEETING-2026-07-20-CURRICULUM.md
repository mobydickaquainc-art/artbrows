## 1. AI 사용 원칙 · 협업 구조 재정립 (00:00~15:00) ★★★

### 상황
- 대표님: 「AI가 다 해준다고 하다가 방향성 못 잡고 늦어지고 있다」
- 본부장: 「방향성 필요 · 전문가가 있어야 AI 뽑아냄」
- 개발 담당(박대표): 「기본은 다 구현해놨음 · 세부 항목은 함께 정해야」

### 결정 · 원칙

**1) AI가 사람 완전히 대체 불가 (본부장 논거)**
- 저커버그 발표: 실리콘밸리 AI 에이전트 대량 실업 후 산업 붕괴 시작
- 이유: AI 에이전트가 원하는 답 못 냄 · 판단 필요한 일 처리 불가
- **YK 법무법인 사례**: AI 변론 거짓말 → 검토 변호사 52명 채용 → 랭킹 4위
- 기획자 10명 → 5명 가능 (0명은 X) · 디자이너 10명 → 시니어 2명 가능

**2) 역할 분담**
| 역할 | 담당 | 도구 |
|---|---|---|
| 방향성·기획·컨셉 | **본부장 (이서연)** | AI 활용해서 정제 |
| 디자인 감각·톤 | **본부장 + 원장님 (첨삭)** | 명품 브랜드 톤 |
| 개발·구현·코딩 | **박대표 (개발 담당)** | Claude Code + AI |
| 콘텐츠 결정·검수 | **원장님** | 최종 결재 |

**3) 워크플로우**
1. 본부장이 AI로 방향성/자료 정제 (예: 어제 국문·영문 소개서 4시간 → 옛날 3~4일)
2. 박대표가 그걸 홈피로 구현
3. 원장님·본부장 함께 첨삭 · 다시 반영
4. 방향성 없이 앞서 나가지 않음 (하네스 공법 재확인)

**4) 톤·컬러 확인 (이미 확정)**
- Maison Noir 로즈 브론즈 다크 (부쉐론·불가리 골드/로즈골드 + 블랙 결합)

## 3. 커리큘럼 재구조화 · 4대 단과 확정 (20:00~40:00) ★★★★

### 3-1. 단과 4대 과정 (확정)

| # | 과정 | 기간 | 가격 | 대상 | 비고 |
|---|---|---|---|---|---|
| 1 | **이지 클래스** | 5주 · 15시간 | 69만 | 완전 초보 · 입문 | **극사실눈썹 아님** (기초 훈련 · 시술 개념 이해) |
| 2 | **소묘 (Drawing)** | 3일 | 66만 | 초·중급 (드로잉 감각) | 이지 클래스 미수강도 OK |
| 3 | **극사실눈썹** | 3일 · 21시간 | 169만 | **경력자** (초보는 어려움) | 반 안 끼움 · 원장 직강 |
| 4 | **제거** | — | 55만 | 경력자 (준·전문) | **홈피 홍보 X** (합법화 전 · 2027-10 대비) |

**중요**:
- **이지 클래스 수료자에게 「극사실눈썹」 표기 금지** (원장님 강력 원칙)
- 초보가 극사실눈썹 3일 바로 들으면 어려움 → 이지 → 소묘 → 극사실 순 권장
- 지방 수강생 많음 (지방엔 가르치는 곳 없음) · 3일 집중 편성 이유
- 4일 이상 되면 「가게 못 비워서 못 옴」 (지방 원장 특히)

### 3-2. 창업반 · 660만원 · 4개월 통합 과정 (확정)

**구성**:
```
이지 클래스 × 1  +  소묘 × 2 (→3 검토)  +  극사실눈썹 × 3  +  제거 × 1  +  창업 컨설팅
= 660만원
```

**대상**: 완전 초보 · 30~40대 · **전직 지원자** (경력 단절 여성 등)

**원장님 검토 방향**:
- 소묘 2회 → **3회로 늘리기** (실습 부족 해소)
- 극사실 연습 3회 유지 · 시술은 대부분 졸업 후에도 부족
- **1년 재수강 옵션**: 660 부족한 사람에게 50% 할인으로 재수강 → 990만원 = 1년 수강생 급
- 5개월 과정으로 재조정 (제거 1회 포함 시)

**미술 배경 우대 (원장님 지도 경험)**:
- 미대 졸업 후 결혼·경단 여성 = 6개월에 실습 4~5회로 급성장
- 미술 안 한 사람 = 1년 해도 안 늘어남 (감각 문제)
- **포커스 타겟**: 미대 졸업 + 30대+ + 프리미엄 커리어 전환

### 3-3. 강사반 (원장님 계획 · 별도)

| 항목 | 확정 내용 |
|---|---|
| **자격** | 창업반 마쳐야 지원 가능 |
| **일정** | 격주 2회 (1개월 총 2회로 완료) |
| **내용** | **이지 클래스 강사 자격 부여** (다른 수업 강사 X) |
| **비용** | 미정 (원장님 논의 중 · 초안 220만원) |
| **파트너 기간** | 정해야 함 (강사로 뛸 수 있는 기간) |
| **호칭** | 「강사」 (부원장 X · 원장 다음 급) |

**정체성**: 실력 완성보다 「자격 부여」가 핵심 · 내용은 이지 클래스 티칭 기법

## 4. 핵심 딜레마 · 창업반 vs 시술 (39:00~46:00) ★★★

### 원장님 딜레마
- 시술 비용 낮으면 → 창업반 몰아넣기가 이득 (예전 다른 학원에서 30명 660만원 채운 경험)
- 시술 비용 높아지면 → 창업반 시간 뺏김 → 시술 코스트 대비 손해
- **결론: 원장 시술은 프리미엄으로 가야 · 창업반 스케줄과 시술 스케줄 분리 필요**

### 창업반 운영 모델 (원장님 제안)
```
매달 신규 창업반 5~10명 유입 (졸업 로테이션)
→ 4개월 후 대부분 졸업
→ 강사반으로 이동 or 종료
→ 반복 수강 거의 없음 (졸업 후 딴 데 재수강 하는 경우 많음)
```

### 이지 클래스 = 신규 유입 채널
- **매달 최대한 많이 개설** (이지 = 창업반 예선)
- 이지 클래스에서 창업반으로 전환 유도
- 이지 클래스 자체는 「극사실눈썹 미리보기」 포지셔닝
- 이지 클래스 → 창업반 전환율이 KPI

### 자리 남는 단과 활용
- 창업반 스케줄에 소묘/극사실 수업 진행 시
- **자리 남으면 단과 추가 접수** (수익 최대화)

## 10. 회의 시사점 · 대표님 방향성

**대표님 종합 판단**:
- AI 협업 = 「방향성 → AI 정제 → 구현 → 첨삭」 사이클 확립
- 커리큘럼 = 「이지 (미끼) → 창업반 (본상품) → 강사반 (파트너)」 3단계 확정
- 홈피 = 아카데미 우세 (70:30) · 창업반이 매출 핵심 · 매달 5~10명 목표

**본부장 종합 판단**:
- 방향성 없이 AI만 돌리면 시간만 걸림 · 전문가 필수
- 홈피 완성도 강화하면 원장님 시장 인지도(80%)로 즉시 매출 전환

**원장님 종합 판단**:
