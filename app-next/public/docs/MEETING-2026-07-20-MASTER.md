## 4. 3차 회의 · 커리큘럼 재구조화 + AI 사용 원칙 (약 54분)

### 4-1. AI 협업 원칙 재정립 ★★★
| 역할 | 담당 | 도구 |
|---|---|---|
| 방향성·기획·컨셉 | **이서연 본부장** | AI로 정제 (예: 국문·영문 소개서 4시간) |
| 디자인 감각·톤 | **본부장 + 원장님 첨삭** | Maison Noir 톤 |
| 개발·구현 | **박대표** | Claude Code + AI |
| 최종 결재 | **원장님** | 콘텐츠·시술·수업 최종 |

**본부장 논거**: 「AI가 사람 완전히 대체 못함 · 방향성 있어야 뽑아냄」
**사례**: YK 법무법인 = AI 변론 거짓말 → 검토 변호사 52명 → 랭킹 4위 · 저커버그 = 실리콘밸리 AI 에이전트 실업 후 산업 붕괴

### 4-2. 커리큘럼 확정 ★★★★

**단과 4대**
| 과정 | 기간 | 가격 | 대상 |
|---|---|---|---|
| 이지 클래스 | 5주·15h | **69만** | 완전 초보 (극사실 아님 · 기초) |
| 소묘 | 3일 | **66만** | 초·중급 (드로잉) |
| 극사실눈썹 | 3일·21h | **169만** | **경력자** (원장 직강) |
| 제거 | — | 55만 | 경력자 · **홈피 홍보 X** (2027-10 합법화 전) |

**창업반 660만 · 4개월 (매출 축)**
```
이지 × 1  +  소묘 × 2 (→3 검토)  +  극사실 × 3  +  제거 × 1  +  창업 컨설팅
```

**강사반 (원장님 계획)**
- 격주 2회 · 1개월 완료 · 창업반 수료 필수 · **이지 강사 자격 부여** · 비용 미정 (초안 220)

**재수강 옵션**
- **990만 · 50% 할인** = 1년 수강생 급 · 실력 완성 원하는 사람 대상

### 4-3. 3단 매출 구조 (원장님 확정)
```
이지 (69, 미끼) → 창업반 (660, 본상품) → 강사반 (파트너) → 재수강 (990, 실력 완성)
매달 이지 최대 개설 · 창업반 신규 5~10명 유입 = 매출 KPI
```

### 4-4. 핵심 원칙
- **이지 클래스 수료자 → 「극사실눈썹」 표기 금지** (원장님 강력 원칙)
- **극사실은 경력자용** (초보는 어려움 · 순서 = 이지 → 소묘 → 극사실)
- **미술 배경 우대**: 미대 졸업 6개월 = 급성장 · 마케팅 카피 반영
- **지방 배려**: 3일 집중 (4일+ = 지방 원장 못 옴)
