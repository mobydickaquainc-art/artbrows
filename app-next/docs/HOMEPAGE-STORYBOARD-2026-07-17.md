### GNB 2단 (딥 브라운/블랙 + 골드 텍스트) ★ 첫 페이지 우선 적용
- 좌: **`장미지 EYEBROWS MAIN`** (좌측 원형 하이라이트 · 골드)
- 중: **`철학 · 시그니처 · 메뉴 · 새 트랙 · 글로벌 · 운영진↗`** 6개 서브 메뉴
- 우: **[KO][EN][中]** 언어 스위처 · **[상담 신청]** 골드 CTA 버튼

### Hero 섹션 좌측 카피
- 얇은 핑크 스트립 (액센트) — ※ 원장님 톤 확정 시 골드/아이보리로 대체 검토
- 골드 얇은 대문자 라벨: `SINCE THE ORIGINAL · SEONLEUNG-BONGEUNSA ATELIER`
- 초대형 명조 헤드라인: **「극사실눈썹, 그 원본의 손에서.」** (「**원본**」만 골드 강조)
- 본문 2줄 서브카피: `사람의 얼굴을 가장 사람답게 — 그것이 우리가 매일 찾는 한 줄의 결입니다. 선릉의 무게로, 손끝의 깊이로, 다시 정의합니다.`
- CTA 버튼 2개: **[수강 상담 신청]** 진한 브라운 + **[철학 읽기]** 검정 outline
- 하단 색상 팔레트 힌트 사각 2개: 다크 자주 · 핫핑크 (※ 본부장이 팔레트 결정 대기 위해 참고 표시)

### Hero 섹션 우측 인물 이미지
- 검정 스튜디오 배경
- 실사 여성 (아시아 · 자연 눈썹 · 화이트 니트)

## 2페이지 · 컬러 팔레트 (본부장 「퍼스널색상톤 결정필요」)

Airbnb 디자인 시스템 스타일을 참고 (링크: https://getdesign.md/airbnb/design-md).

Airbnb 팔레트 예시 (참고용):

### Brand
| 이름 | 컬러 | 용도 |
|------|------|------|
| primary (Rausch) | `#ff385c` | 모든 primary CTA · search orb · heart save · brand wordmark |
| primary-active | `#e00b41` | Rausch CTA 의 press state |
| primary-disabled | `#f1d1da` | Disabled CTA tint |
| luxe | `#460479` | Sub-brand accent — Airbnb Luxe 전용 |
| plus | `#92174d` | Sub-brand accent — Airbnb Plus 전용 |

### Surface
| 이름 | 컬러 | 용도 |
|------|------|------|
| canvas | `#ffffff` | 기본 페이지 표면 (모든 public page) |
| surface-soft | `#f7f7f7` | Disabled fields · sub-nav hover · filter band |
| surface-strong | `#f2f2f2` | Circular icon button surface |

### Hairlines & Borders
| 이름 | 컬러 | 용도 |
|------|------|------|
| hairline | `#dddddd` | 기본 1px divider (Search bar · footer · tables) |
| hairline-soft | `#ebebeb` | Editorial body 용 더 옅은 divider |
| border-strong | `#c1c1c1` | Disabled outline buttons · focused input outlines |

### Text
| 이름 | 컬러 | 용도 |
|------|------|------|
| ink | `#222222` | Display · body · primary nav links |
| body | `#3f3f3f` | Long-form review · amenity copy |
| muted | `#6a6a6a` | Sub-titles · footer sub-labels · "View all" links |
| muted-soft | `#929292` | Disabled link text |

> **본 팔레트는 Airbnb 참고용. ARTbrows 는 원장님 톤 정본 (블랙 + 골드 + 아이보리) 기반으로 별도 팔레트 확정 필요.**
