## §1. 12종 슬라이드 레이아웃 (본부장 지시 = 각 슬라이드 다른 레이아웃)

## §2. 자동 생성 파이프라인 (🪄 마법 지팡이 버튼)

**진입**: 대시보드 → **[🪄 자동 생성]** 버튼 → 4-스텝 위저드 시작.

### 스텝 1. Setup (설정)

| 입력 | 예 | 설명 |
|---|---|---|
| **목적 · 시리즈명** | "15기 이지클래스 모집" | 자유 텍스트 · 프로젝트 이름 |
| **언어** | KO / EN / ZH | 3언어 선택 |
| **슬라이드 수** | 4·5·6·7·8·10·12 | 기본 6 |
| **스타일** | 10종 중 선택 (기본 = ARTbrows 정본) | §3 참조 |
| **모델** | Gemini · OpenAI · (Claude) | 최대 2개 병렬 |
| **옵션 1** | Gemini Vision 벤치마크 분석 | 참고 이미지 5장 자동 분석 |
| **옵션 2** | 실시간 트렌드 조사 | Live 프리셋과 별개 옵션 |

### 스텝 2. Preparing (준비 · 약 30~60초)

- 트렌드 조사 (선택 시) → 스타일리스트 → skeleton (뼈대) N장 완성
- "준비 중…" 프로그레스 표시. 사용자 개입 없음.

### 스텝 3. Slide (슬라이드별 팝업 · 20초 카운트다운)

- **한 장씩** 나오는 팝업.
- 좌우 2안 (Gemini 안 · OpenAI 안) 나란히 표시.
- 사용자가 클릭 = 골드 테두리로 선택.
- 3 버튼:
  - **[여기까지 저장]** — 지금까지 확정된 슬라이드만 저장 후 편집기 이동
  - **[다음 → (Xs)]** — 다음 슬라이드로 (20초 자동 카운트다운)
  - **[닫기]** — 전체 취소
- 답 없으면 20초 후 자동 진행.

### 스텝 4. Saving (저장)

- 확정된 슬라이드를 JSON 프로젝트로 저장 (`content/cardnews/{id}.json`)
- **모든 안 (autoVariants)** 도 함께 저장 → 편집기에서 나중에 대안 안으로 교체 가능
- 저장 완료 시 편집기 (`/cardnews/edit/{id}`) 자동 이동

## §3. 10 스타일 프리셋 (2026-07-17 원장님 요구)

| # | 프리셋 | 톤 | 언제 |

| 1 | **artbrows** (기본) | 딥 블랙 + 골드 + 아이보리 · 명조 · 「결·손끝·무게」 | **디폴트 · 원장님 정본** |
| 2 | minimal-editorial | 여백 · 세리프 · 잡지 편집자 톤 | 조용한 시리즈 |

| 6 | before-after | 시술 전 → 시술 후 | 결과 대비 (실사 사진) |
| 7 | data-card | 「12년 · 30기 · 690만원」 큰 숫자 | 신뢰 자산 |
