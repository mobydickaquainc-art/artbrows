## 2. 참고 이미지 5장 분석 (대표님 07-17 공유)

### 참고 1. 서울쇼룸 서포터즈 3기 (검정 + 옐로우)
- **톤**: 딥 블랙 배경 + 형광 옐로우 강조 (하지만 우리 톤 아님 · 구조만 참고)
- **레이아웃 패턴**:
  1. **Cover** — 육각형 shape + 제목 큰 헤드 + 부제
  2. **Number-Big** — 상단 큰 「1」 넘버 태그 + 항목 리스트 (모집내용·활동내용)
  3. **Multi-Section** — 상단 「2」 넘버 + 지원방법(번호 리스트) + 지원혜택(bullet 리스트)
  4. **Checklist-Bullet** — 상단 「3」 넘버 + 큰 헤드라인 + 11개 bullet 조건 리스트

### 참고 2. Borcelle "4 Easy Steps" (크림 + 오렌지)
- **톤**: 아이보리 크림 + 오렌지 스텝 태그 + 검정 세리프 이탤릭 헤드 (우리 톤 유사)
- **레이아웃 패턴**:
  1. **Cover** — 상단 오렌지 태그 「4 Easy Steps to」 + 큰 세리프 헤드 「Improve Productivity」 + 하단 Explore Now
  2. **Step-Text** — 상단 스텝 태그 「STEP 1」 + 세리프 이탤릭 헤드 + 서브 텍스트
  3. **Icon-Duo** — 상단 스텝 + 헤드 + 아이콘 2개 (원형) 좌우 배치 + 캡션
  4. **Time-Segment** — 상단 스텝 + 헤드 + Morning/Midday/Evening 3구간 텍스트
  5. **Checklist** — 상단 스텝 + 헤드 + ✔ 체크리스트 3~5개
  6. **Closing-CTA** — 상단 오렌지 태그 「Try it for one week」 + 큰 세리프 헤드 + 인물 원형 + 팔로우 안내

### 참고 3. Plastic Waste 캠페인 (그린 + 크림)
- **톤**: 그린 + 크림 (우리는 톤 다름 · 구조만 참고)
- **레이아웃 패턴**:
  1. **Product-Hero** — 큰 제품 사진 (백) + 좌측 헤드 + 하단 CTA 태그
  2. **Portrait-Frame** — 라운드 프레임 안 인물 + 하단 CTA 태그
  3. **Product-Detail** — 제품 사진 + 우측 상세 텍스트
  4. **Big-Text-Icon** — 큰 텍스트 + 배경 아이콘 + CTA 태그
  5. **Person-Half** — 인물 하반신 클로즈업 + 헤드 오버레이
  6. **Nature-Photo** — 자연/환경 사진 + 텍스트

### 참고 4. milk T 여름방학 (블루 · 인물 강조)
- **레이아웃 패턴**:
  1. **Person-Cover** — 학생 인물 사진 + 큰 헤드 + 서브
  2. **Step-Box** — 헤드 + 2개 스텝 박스 (1학기·2학기)
  3. **Category-3** — 헤드 + 국어·영어·수학 3구간 각 팁 (아이콘/색 tag 있음)
  4. **Interview-Card** — 인물 + 큰 카드 (진단평가 예약 등)
  5. **Product-Person** — 인물 + 제품 (사전 · 태블릿 등) + 헤드
  6. **Closing-Device** — 큰 헤드 「1등 주인공은 바로 나」 + 태블릿/제품 사진

### 참고 5. Kalima Arabic Course (다크 그린 + 크림 + 골드 · 우리 톤 매우 유사)
- **톤**: 다크 그린 + 크림 + 골드 — **우리 정본 블랙+골드+아이보리 톤과 컨셉 매우 흡사**
- **레이아웃 패턴**:
  1. **Portrait-Diagonal** — 인물 좌측 + 우측 위에서 흘러내리는 큰 세리프 헤드 "Yangi formatdagi guruh"
  2. **Badge-Cluster** — 3개 뱃지 (A1·A2·B1) 흩뿌린 + 하단 CTA
  3. **Phone-Hand** — 폰 든 손 사진 + 옆에 헤드
  4. **Laptop-Chat** — 노트북 + 채팅 말풍선 오버레이 + 이탤릭 텍스트
  5. **Announcement** — 큰 헤드 「A2 DARAJA UCHUN QABUL BOSHLANDI」 + 노트북 사진 + 화살표
  6. **Person-Table** — 인물 + 우측 강의 상세 카드 (기간·정원·가격)

**콘텐츠 필러 배분 (원장님 정본 · 주간)**: Before/After 40% · 교육 20% · 브랜드 무드 15% · 후기 15% · 릴스 10%

**비주얼 통일 규칙**: 사진 = 웜톤/세미매트/동일채도 · 텍스트카드 = 폰트·컬러 고정 템플릿 · 릴스커버 = 피드 동일 톤

각 슬라이드 = **`kind`(레이아웃 12종 중 1개) × `category`(6톤 중 1개) 조합**. 톤은 원장님 정본 팔레트만.

| # | 레이아웃 명 | 용도 | 구조 |
|---|-------------|------|------|
| **01** | Cover-Founder | 시리즈 커버 · 제목 페이지 | 좌 큰 인물 (원장님) + 우 골드 라벨 + 대형 명조 헤드 + 인용문 |
| **02** | Number-Big | 스텝/회차 소개 | 상단 골드 큰 넘버 (「01」·「STEP 1」) + 명조 헤드 + 서브 |
| **03** | Icon-Duo | 2가지 특징 비교 | 상단 태그 + 명조 헤드 + 좌우 아이콘·이미지 2개 + 캡션 |
| **04** | Icon-Trio | 3가지 원칙 | 상단 태그 + 명조 헤드 + 아이콘 3개 세로 나열 |
| **05** | Checklist | 조건·혜택·체크리스트 | 상단 태그 + 헤드 + 골드 체크 아이콘 리스트 (5~10개) |
| **06** | Portrait-Frame | 인물 강조 (원장님·수강생) | 라운드/사각 프레임 안 인물 + 하단 오버레이 텍스트 · 골드 라벨 |
| **07** | Product-Hero | 시술 결과 · 눈썹 클로즈업 | 좌 큰 사진 + 우 골드 라벨 + 짧은 캡션 · 「HYPER REALISTIC EYEBROW」 오버레이 |
| **08** | Quote-Bold | 원장님 어록 · 인용 | 아이보리 블록 배경 + 큰 세리프 이탤릭 인용 + 하단 「— 장미지」 골드 시그니처 |
| **09** | Signature-Style | Brand Concept · Signature Style | 원장님 이미지처럼 좌 딥 블랙 (예술+기술+철학) + 우 아이보리 (HAIR/OUTFIT/MAKEUP/ACCESSORY) |
| **10** | Curriculum-Row | 커리큘럼 회차별 | 각 회차 가로 row (넘버 + 제목 + 시간 + 강사) 5~6줄 |
| **11** | Price-Table | 시술가격·수강료 | 골드 태그 + 상품명·가격 큰 명조 + 조건 리스트 |
| **12** | Closing-CTA | 마무리 · 상담 유도 | 큰 헤드 「극사실눈썹, 그 원본의 손에서.」 + Miji Jang 필기체 시그니처 + CTA 「상담 신청」 |

### 조합 규칙
- **인스타 캐러셀 6장** = Cover-Founder → Quote-Bold → Number-Big × 4 (커리큘럼) → Closing-CTA 등 자유 조합
- **홍보 목적**에 따라 순서·개수 다름 (신규 기수 모집 vs 특강 · 시술 후기)
- **톤은 반드시 원장님 정본 유지** — 색·폰트 override 금지
