ASTEP A — ARTbrows-Blender-템플릿 라이브러리 v1

위치: tools/blender-templates/artbrows_studio.py · 한승철 권고 「표준 라이브러리」 권고 실현. Claude Code에서 exec(open(path).read()) 한 줄로 주입해서 매번 0초 셋업.

함수역할
setup_cycles(samples, res, denoise)Cycles 엔진 + GPU + 샘플 + 해상도 한 줄 셋업
apply_hdr(hdr_image_name, strength)HDR 환경맵 적용 — 이미 로드된 .hdr 또는 fallback 자동 선택
position_camera(angle_name)4 각도 프리셋 (Front · Front_45 · Right_Profile · Macro_Close) 자동 track-to
apply_artbrows_skin_shader(obj, color, sss_weight, roughness)함정 가드: Subsurface 신/구 입력명 호환 (if 'Subsurface Weight' in inputs:) — 한승철 권고
add_brow_decal_plane(location, rotation)이마 데칼 평면 추가 (텍스처 스왑 슬롯)
apply_brow_decal_texture(plane, image, alpha_mode)눈썹 텍스처 + Invert→Alpha (흰 배경 자동 컷아웃)
hide_decal(plane, hide)0크 토글: 같은 GLB · 같은 조명에서 「전/후」 전환
setup_artbrows_studio(hdr, angle, samples, ...)위 4개를 묶은 「한 줄 스튜디오」 — Cycles + HDR + 카메라 + 셰이더 일괄
render_to(output_path)PNG 저장 + 자동 디렉토리 생성
artbrows_handshake()씬 검증 한 줄 리포트 (engine·samples·UV·HDR·camera)
사용 예시 — 어제 PoC 16컷이 「8줄」 로 줄어듦:
# 어제: 약 80줄 코드 + 함정 디버깅 3회 # 오늘: 8줄, 함정 가드 영구 내장 exec(open('tools/blender-templates/artbrows_studio.py').read()) setup_artbrows_studio(hdr_image_name='brown_photostudio_02.hdr', angle_name='Front_45') add_brow_decal_plane(location=(0, -0.50, 0.555)) apply_brow_decal_texture('BrowDecal', 'brow-decal-pair.png', alpha_mode=True) hide_decal('BrowDecal', hide=True); render_to('before.png') # 전 hide_decal('BrowDecal', hide=False); render_to('after.png') # 후
