## 🥇 A · 一人一眉 (일인일미)

> **한 사람에게, 하나의 눈썹** — 결정 트리로 「극사실 4대 카테고리」 매핑

### 컨셉
中 四七美学 「一人一眉」 슬로건은 ARTbrows 「극사실 = 1인 맞춤」과 100% 정합. 사용자가 스와이프하며 「자신의 카테고리」를 찾도록 유도 → 저장률 최상.

### 슬라이드 시퀀스 (7장)
1. **magazine-cover** — 「一人一眉」 대형 세리프 (Cormorant + 思源宋体 이중) · 원장 배경 페이드
2. **hero-portrait** — 매크로 브로우 클로즈업 (털 하나하나 보이는 결)
3. **case-study-detail** — 결정 트리 「극사실 4대 카테고리」 (눈썹·아이라인·입술·헤어라인) 각 정의
4. **umbrella-4cats** — 4대 카테고리 그리드 (기존 kind 활용)
5. **pullquote-editorial** — 「고객이 원하는 것은 그린 눈썹이 아니라 털 같은 눈썹이다.」 원장 원문
6. **atelier-scene** — 선릉 본원 원장 시술 장면 (실제 이미지)
7. **cta-editorial** — 「당신의 극사실을 찾으세요 · 상담 신청」

### 시각 특징
- 컬러 : Maison Noir + Champagne Gold hairline 유지
- 폰트 : Cormorant Garamond (라틴) + Nanum Myeongjo (한글) + Source Han Serif (한자 · 이중언어)
- 헤드라인 : 7자 이내 · 컬러 하이라이터 강조 X (골드만)
- 오버레이 : 얇은 골드 라인만
- **인스타 chrome** : ON (브랜드 강화)

### 예상 리스크
- 결정 트리가 정보 밀도 높음 → 원장 승인 시 「너무 복잡」 우려 → 4장으로 압축 가능

### 슬라이드 시퀀스 (7장)
1. **magazine-cover** — 「NUMBERS DON'T LIE」 (또는 「팩트만 남긴다」) · 원장 배경
2. **case-study-detail** — 큰 「**20년+**」 세리프 · 얇은 라벨 「경력」 · 「반영구 초창기부터 지금까지」
3. **case-study-detail** — 큰 「**8,000+**」 · 「누적 시술」 · 「2026-06 자체 집계 정본」

## 🥉 C · Golden Grid Portrait (골든 그리드 인물)

> **정면+측면 스택 + 골드 격자 오버레이** — 극사실 정확성의 시각적 증명

### 컨셉
中 도우인 상업 광고의 「정면+측면 90° 스택 + 노란 페이스 격자」 문법. 노란 격자를 Champagne Gold hairline 으로 리스킨 → 상업체 티 제거 · 럭셔리 유지. 원장 「결의 법칙 1234321」 방법론 특허 시각화.

### 슬라이드 시퀀스 (6장)
1. **magazine-cover** — 「1234321 · THE RULE OF FLOW」 · 정면+측면 원장 스택 배경
2. **hero-portrait** — 정면 클로즈업 + Champagne Gold hairline 격자 (얇은 3분할 · 눈썹 앵글 표시)
3. **hero-portrait** — 측면 90° 클로즈업 + Champagne Gold hairline 격자
4. **pullquote-editorial** — 「결은 계산된 손끝에서만 남는다.」 원장 어록
5. **case-study-detail** — 「1234321」 방법론 5단계 라벨 리스트
6. **cta-editorial** — 「결의 법칙을 배우세요 · 창업반 15기 상담」

### 시각 특징
- 격자 오버레이 = Champagne Gold #E0C088 · opacity 30% · stroke-width 0.5px (극도로 얇게)
- 인물 사진 = 다크 배경 · rim light
- 상단 흑판 캡션 = Cormorant Regular 세리프 · 「1234321」 라벨
- **인스타 chrome** : OFF (미니멀 · Silhouette 처럼)

### 예상 리스크
- 골드 격자가 「너무 이과적」으로 보일 수 있음 → opacity 낮게 유지
- 「1234321」 방법론이 대중에게 이해될지 → 짧은 부제 필요
