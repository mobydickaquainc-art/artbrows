## 2. 회사 및 원장 소개 (공식 팩트)

### 2.1 장미지 원장
- **극사실눈썹 창시자** — "털 같은 눈썹"으로 대표되는 극사실 기법의 원조

- 아카데미 수강생 **900여 명** 배출, 그중 **수백여 명 창업 성공**
- 고객 평점 **4.5★**
- **특허 3건** 보유 + 반영구 머신 특허 (등록번호 10-2863985)

### 2.2 기술 방법론 (26년 강의자료 117p 체계화 완료)
- **결의 법칙 1234321** — 눈썹결 배열의 수학적 원리
- **디자인 4단계** / **단선 3구간** / **색소 체계 A0–A3** / **표피 3층·5층 이론**
- **8스타일 진단** — 고객 얼굴형별 스타일 매칭
- **시술 전 펜슬 미리 그리기** — 고객이 결과를 시술 전에 눈으로 확인 → **클레임 거의 0**. 업계에서 따라오기 힘든 실질 차별점.

## 3. 비전 — 왜 3영역인가

### 3.1 전략 논리
```
극사실 기술 철학 (검증 완료 · 특허)
        │
  ┌─────┼─────────┐
  ▼     ▼         ▼
눈썹   입술    헤어라인
(본진) (확장1)  (확장2)
```
- **눈썹** = 이미 창시자 지위. 1위 '등극'이 아니라 **1위 '공표·공고화'** 단계.
- **입술 · 헤어라인** = 눈썹과 고객·기술·장비·색소학이 겹치는 인접 시장. 동일한 극사실 방법론(자연스러움 = 시술 티 안 나는 결과)이 그대로 먹히는 영역.
- 3영역을 한 브랜드가 다 잡으면 → 고객 생애가치(LTV) 극대화: 눈썹 고객이 입술·헤어라인으로 재방문, 아카데미도 3과목 체계로 확장.

### 3.2 1위의 정의 (측정 가능 목표)
| 지표 | 눈썹 | 입술 | 헤어라인 |
|---|---|---|---|
| 검색 브랜드 인지 (네이버 "극사실 ○○" 연관) | 1위 유지 | 12개월 내 Top 3 | 12개월 내 Top 3 |
| 아카데미 수강생 누적 | 900+ → 1,200 | 과목 신설 → 첫 기수 완판 | 과목 신설 → 첫 기수 완판 |
| 특허·방법론 체계 | 완료 (3건) | 눈썹 방법론 이식 · 체계 문서화 | 눈썹 방법론 이식 · 체계 문서화 |

## 6. 3영역별 1위 전략

### 6.1 눈썹 — 본진 공고화
- 메시지 단일화: **"극사실 눈썹은 창시자에게"** · "털 같은 눈썹"
- 근거 자산 전면 배치: 특허증 3장 · 20년 · 5,000 시술 · 900명 배출
- 아카데미(창업반 890)로 기술 표준을 '가르치는 쪽'이 됨 → 시장의 기준점 지위

### 6.2 입술 — 확장 1호
- 포지셔닝: **"극사실 입술"** — 바른 티 안 나는, 본래 입술이 좋은 것처럼
- 눈썹 고객 → 입술 교차 판매 (기존 고객 DB가 초기 수요)
- 색소학 A0–A3 체계를 입술 색소 체계로 확장 문서화
- 아카데미 입술 과목 신설 → 기존 수료생 900명이 1차 수강 타겟 (재수강·업셀)

### 6.3 헤어라인 — 확장 2호
- 포지셔닝: **"극사실 헤어라인"** — 모근에서 난 것 같은 한 올 표현 (눈썹 결 기술과 동일 원리)
- 타겟: 30대+ 여성(이마 라인 교정) 중심 — 기존 홈페이지 타겟(30대+)과 일치
- 남성 SMP 시장과는 톤 분리 (프리미엄 여성 뷰티 문법 유지)
- 아카데미 헤어라인 과목 신설 — 동일 업셀 구조

### 6.4 공통 실행 축
1. **시술** — 본원(선릉·삼성)에서 3영역 시술 라인업 완성
2. **교육** — 3과목 아카데미 체계 (창업반 → 3영역 마스터 트랙으로 확장 여지)
3. **콘텐츠** — 영역별 카드뉴스·쇼츠 자동 생산 (기존 자동화 파이프라인 재사용)
4. **플랫폼** — Face Lab 패턴 라이브러리를 입술·헤어라인 패턴으로 확장
