## 1. 목적
- 지금 **수동으로** 만드는 쇼츠/콘텐츠 제작을 **버튼 한 번으로** 자동 생성.
- CLAUDE.md에 명시된 **최종 목표(Phase 3)** = 블로그·인스타 콘텐츠 자동 생성 웹앱.
- 1차 타깃 산출물: **인스타/유튜브 쇼츠** (성장 스토리 시리즈처럼).

## 2. 현재 → 목표
| | 현재 (수동) | 목표 (자동) |
|---|---|---|
| 주체 | 유나(Claude)가 손으로 단계별 도구 호출 | **서버 코드가 자동 오케스트레이션** |
| 흐름 | 타깃→시나리오→캐릭터→6컷→영상→편집→게시 | 동일 흐름을 **버튼 1회**로 |
| 소요 | 대화로 한 단계씩 (수십 분) | 자동 파이프라인 (대기 후 완성본) |

## 3. 핵심 통찰 — MCP를 그대로 쓴다
- 힉스필드는 별도 공개 REST API가 없지만, **MCP가 그 역할**을 한다.
- **우리 서버 코드가 MCP 클라이언트**가 되어 `generate_image`·`generate_video`를 직접 호출.
- 즉 *"나(Claude)"가 있던 자리에 백엔드 코드*가 들어간다. (지금 이 세션이 그 작동 증거)

```
지금 :  [ Claude ]        ──MCP──▶ [ 힉스필드 ]
웹앱 :  [ 우리 서버 코드 ] ──MCP──▶ [ 힉스필드 ]
```

## 4. 아키텍처 (방식 A · 추천)
```
┌─────────────┐     ┌────────────────────────────────────┐
│  웹 UI       │ ──▶ │  백엔드 오케스트레이터 (잡 큐)        │
│ (입력·진행·  │ ◀── │                                    │
│  결과 갤러리)│     │  ① Claude API   → 시나리오·컷 프롬프트·자막 카피 │
└─────────────┘     │  ② MCP 클라이언트 → 힉스필드 이미지·영상 (+폴링) │
                    │  ③ ffmpeg 워커  → 줌인·자막·CTA·concat │
                    │  ④ 스토리지     → 완성본·중간 컷       │
                    └────────────────────────────────────┘
```
- **두뇌(시나리오·카피)** = Claude API
- **그림·영상** = 힉스필드 MCP
- **편집** = 서버 ffmpeg (지금 쓰는 그 파이프라인 그대로)
- 생성이 오래 걸리므로 **비동기 잡 큐** + 진행상황 표시

> 대안 방식 B(Claude Agent SDK 경유): 지금 작업 방식을 통째로 자동화. 더 유연하나 비용↑·비결정적. → MVP는 방식 A 권장.

## 5. 기능 범위 (단계적)
- **MVP (v1) — 쇼츠 자동 생성기**
  1. 타깃/주제 선택(직장인·신부·부업맘 등) → 2. 시나리오 자동 → 3. 주인공 캐릭터 → 4. 기승전결 6컷 → 5. 하이브리드 영상(핵심컷 AI모션) → 6. 자막·CTA·편집 → 7. 완성본 + 갤러리 등록
- **v2** — 캐릭터 재사용(시리즈 일관성), 자막/음악 편집, 모집 카드 생성, 재생성 버튼
- **v3** — 블로그·인스타 글, 멀티 포맷, 예약 발행

## 6. 기술 스택 (후보)
| 영역 | 후보 | 비고 |
|---|---|---|
| 프론트 | Next.js (React) | 빠른 UI·진행상황 표시 |
| 백엔드 | Node.js(TypeScript) | MCP SDK가 TS 친화적, ffmpeg 연동 용이 |
| MCP 클라이언트 | `@modelcontextprotocol/sdk` | 힉스필드 직접 호출 |
| 영상 편집 | ffmpeg | 지금 쓰는 그대로 |
| DB | SQLite → Postgres | 작업·결과 기록 |
| 호스팅 | **결정 대기** | 모비딕 맥미니 인프라 vs 클라우드 |

## 7. 비용 (운영 · 실측 기반)
- **힉스필드**: 쇼츠 1편 ≈ **55~60 크레딧** (캐릭터 2안 + 6컷 + AI모션 2개 실측치)
  - Plus 보유 1,010 크레딧 → **약 17편** 분량
- **Claude API**: 시나리오·컷 프롬프트·자막 카피 → 편당 토큰 소량 = **편당 수십~수백 원 수준(미미)**
- **호스팅**: 백엔드+스토리지 → **맥미니 활용 시 추가비용 ≈ 0**, 클라우드면 월 소액
- → 변동비 핵심은 **힉스필드 크레딧**. 편당 크레딧을 더 줄일 여지(캐릭터 1안화, 컷 수 조정) 있음.

## 8. 로드맵 · 일정

## 9. 제작 원칙 (불변 · CLAUDE.md §4)
- **실제 시술 비포&애프터·수강생/원장 얼굴은 AI 생성 금지.**
- AI는 **캐릭터·배경·무드·연출**만. 실제 사진은 사람이 **업로드 슬롯**으로 넣는다.
- 웹앱 UI에도 이 경계를 명시(실사진 영역 ↔ AI 생성 영역 분리).
