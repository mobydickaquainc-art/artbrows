## 0. 개정 메모 (2026-06-02)

이미지·영상을 **힉스필드(Higgsfield) MCP 단일 통합**으로 확정(대표님 결정). 힉스필드 MCP 하나로 이미지(Nano Banana Pro·Soul 2.0 등)와 영상(Veo 3.1 등)을 모두 사용 → **구글 AI 스튜디오 직접 API는 사용하지 않음**. 나노바나나는 힉스필드를 통해 그대로 사용(한글 텍스트 카드 강점 유지).

## 1. 확정 도구

| 영역 | 도구 | 비고 |
|---|---|---|
| 기획·개발 | **Claude / Claude Code** | 기획·카피·코드 |
| 이미지 + 영상 | **힉스필드(Higgsfield) MCP** | 단일 통합. 한 연결·한 인증·한 청구 |
| 디자인·그래픽 | **Canva**(연결됨) + Claude HTML | 카드·소셜 그래픽=Canva(브랜드킷 활용) / 사이트·포털=Claude HTML |

- **이미지 기본 모델:** Nano Banana Pro (이미지 내 한글 텍스트 가독성 최강 → 모집 카드 적합). 보조: Soul 2.0 등.
- **영상 기본 모델:** Veo 3.1. 보조: Sora 2 · Kling 3.0 등.

## 2. 워크플로 (파이프라인)

```
기획(Claude/Claude Code)
   → [힉스필드 MCP] 이미지 생성(Nano Banana Pro)
      → [힉스필드 MCP] 영상화(Veo 3.1)
         → 검수
            → 발행(인스타)
```

- 이미지·영상을 한 도구로 처리 → 연결·인증·청구 단순화.
- 제작 원칙 유지: 실제 시술 비포&애프터·수강생 얼굴은 **AI 생성 금지** → 실제 사진. AI는 배경·디자인·무드컷·연출만.
