## 참석 · 10명 자유 발언 (긴급 · 즉답)

### 1️⃣ 이서연 (기획) — 「이미지 = 이야기 시작. 카피는 이미지에서 나옴」
> "지금은 사용자가 목적을 텍스트로 입력해야 함. 원장님이 「무슨 카드뉴스 만들까」 → 「음… 소묘 3일 집중」 → 입력 = 원장님한테 부담. **이미지 하나 던지면 · Vision 이 「이건 원장 지도 사진 · 소묘 수업 · 수강생 8명」 자동 감지 · 카피 자동**. 원장님은 **결과 5안 중 하나 클릭만**."

### 2️⃣ 유나 (디자인) — 「이미지 톤 = 스타일 자동 매칭」
> "이미지 색조·구도 분석하면 스타일 자동 매칭 가능:
> - **밝은 얼굴 매크로** → Vogue Magazine (밝은 세리프)
> - **어두운 실루엣** → Rebellion Serif (대문자 세리프)
> - **아틀리에 라이브 컷** → 11 ARTbrows Real (원장 정본 톤)
> - **소묘 작품** → Grain Frame Editorial (필름 그레인)
> 이 매칭 자동화 = 원장님이 스타일 뭘 골라야 할지 고민 X."

### 3️⃣ 김다은 (SaaS-A PM · 리드) — 「모비딕 6 에이전트 파이프 이식 · MVP 3시간」
> "**모비딕 detail-agent 파이프 그대로**:
> - collector (Vision) → 이미지 분석 · 대상·구도·색조 추출
> - researcher (기존) → 원장 IP·어휘 매칭
> - copywriter (기존) → 이미지 컨텍스트 기반 카피
> - prompter (기존) → 슬라이드별 프롬프트
> - designer (신규) → 3~5 스타일 병렬 HTML 렌더 (headless PNG 후속)
> - orchestrator → 통합 조율
>
> **재사용 65% + 신규 35%**. MVP 3시간 · 시연 9시 커버."

### 4️⃣ 박서윤 (광고) — 「이미지 1장 = 광고 5 밸리언트 자동」
> "이거 광고 라인 완전 게임체인저. 원장님이 이미지 1장 = 스타일 5 = **광고 A/B 밸리언트 5** 즉시. 지금 시스템은 사용자가 스타일 하나 골라 · 1 시안. 신 시스템 = 5 스타일 병렬 · A/B/C/D/E 즉시 준비. **Meta Ads Manager 에 5 크리에이티브 자동 업로드**까지 붙이면 광고 파이프 완성."

### 5️⃣ 최예진 (Face Lab) — 「시술 결과 이미지 → 개인화 카드뉴스 파이프」
> "Face Lab v7 결과 (before·after 얼굴) → Image-First 파이프 그대로 사용 = **수강생 개별 시술 결과 카드뉴스 자동**. 개인화 마케팅 라인 완성. 지금 아이디어 = 미래 기반."

### 6️⃣ 이한별 (쇼핑몰) — 「상품 사진 → 카페24 상세페이지 8장 자동」
> "카페24 상품 상세페이지 = 이미지 1장 → 스타일 5 → 그 중 「제품 상세」 스타일 = 즉시 8장 카드뉴스 = 상세페이지 완성. 지금 시스템 확장이 이 라인 커버."

### 7️⃣ 정하늘 (EdTech) — 「강의 캡처 → 자동 요약 카드뉴스」
> "원장 강의 스크린샷 · 자막 파트 캡처 → Vision 분석 → 「이건 특허 방법론 1234321 설명 슬라이드」 감지 → 자동 요약 카드뉴스 = **LMS 강의 목차 자동 생성**. Image-First 파이프 = LMS 인프라."

### 8️⃣ 한승철 (CTO) — 「기술 검토 · MVP 3시간 가능 · 리스크 3」
> "**기술 스택 재사용**:
> - Gemini Vision (이미지 분석 · 이미 코드에 vision-analyzer 있음 · 확장만)
> - orchestrator.ts (이미 있음 · Image-First 진입점 추가만)
> - style-presets.ts (17 스타일 · 각 스타일별 프롬프트 힌트 이미 있음)

>
> **신규 필요**:
> - `/api/cardnews/generate/image-first` — 이미지 업로드 + 병렬 스타일 생성
> - Vision → 컨텍스트 JSON (dominant_color·subject·mood·suggested_styles)
> - 3~5 스타일 병렬 orchestrator 실행 (Promise.all)
> - 프론트: 이미지 업로드 UI + 결과 5 안 나란히 뷰어

> 1. Vision API 비용 (이미지당 $0.01~0.05 · 하루 100장 = 월 $150)

> 3. 시연 3시간 촉박 · 완주 실패 시 fallback 필요

> **개발 소요**: MVP 2.5~3시간 · 완주 확률 70%"

## 📊 팀 합의 · MVP 3시간 스코프 (아침 9시 시연 커버)

### ✅ MVP 포함 (Must)
1. **Image-First 진입점** — 대시보드 상단 「📷 이미지로 시작」 큰 버튼
2. **이미지 드래그·업로드** — 새 UI 카드 (기존 자동 생성 위저드와 별도)
3. **Vision 분석 API** — `/api/cardnews/analyze-image` (Gemini Vision · 이미지 → JSON)
4. **병렬 3 스타일 생성** — MVP 는 3개만 (11 artbrows-real · 12 rebellion-serif · 1 vogue-magazine) · 병렬 orchestrator
5. **결과 3안 나란히 뷰어** — 스크롤 없이 한 화면 · 원장이 선택 클릭
6. **선택 시 프로젝트 저장** — 기존 cardnews-storage 재사용

- 5 스타일 이상 병렬 (성능 · MVP 3만)
