# 랜딩 + 상담 퍼널 초안

## 목적
- Phase 1 성과 기준: 카드 3종과 쇼츠 1편을 통해 상담 신청 가능성을 검증
- 랜딩 페이지와 상담 채널을 연결하여 최소 1개 이상의 잠재 고객 문의를 확보

## 핵심 흐름
1. 인스타 카드/쇼츠 노출
2. `상담 신청` CTA 클릭
3. 상담 채널 선택 페이지 진입
4. 간단한 문의/예약 정보 입력
5. 상담 안내 메시지 발송

## 목표 CTA
- 공식 CTA: **상담 신청**
- 결제 언급 금지
- 클릭 후에는 즉시 상담 채널로 이동하거나, 상담 신청 폼이 보이도록 처리

## 상담 채널 제안
- 1순위: `카카오톡 채널`(즉시 대화 + 문의 전환 용이)
- 2순위: `네이버 폼`(간편 설문형 예약, 추적 용이)
- 3순위: `대표 연락처`(예비 고객의 신뢰 요소)

> 실제 수급 상황에 따라 채널 하나만 먼저 열어도 무방합니다. 중요한 것은 `상담 신청` 클릭 후 연결이 끊기지 않는 것.

## 랜딩 페이지 구조
- 헤드: `극사실눈썹 창시자에게, 소수만 직접 배운다`
- 섹션 1: 왜 이 클래스인가?
  - 장미지 원장의 창시자 권위
  - 소수정예 직강 + 프리미엄 현장
- 섹션 2: 배움의 로드맵
  - 3단계 커리큘럼 요약
- 섹션 3: 상담 신청 안내
  - 현재 정원 제한 설명
  - 상담 채널 선택 버튼
- 섹션 4: 신뢰 요소
  - 실제 후기 또는 작업 사례 설치(자료 확보 시 반영)
  - 상담 신청이 가장 빠른 방법 안내
- 섹션 5: FAQ / 문의
  - 대표 문의 채널 및 상담 시간 안내

## 퍼널 전환 포인트
- 카드·쇼츠에서 CTA를 `상담 신청`으로 일관 유지
- 채널 선택 페이지에서 즉시 연결 가능한 옵션을 가장 먼저 노출
- 문의 폼은 최소 입력만 받음: 이름 · 관심 클래스 · 문의 내용
- `지금 상담 신청하면 마감 전 안내` 같은 긴급성 메시지 추가

## Phase 2 가보기 기준
- 카드 3종 + 쇼츠 1편을 실제 노출했을 때, 상담 CTA 클릭 흐름이 깨지지 않는지 확인
- 상담 채널 연결 시도 후 1건 이상의 문의 도착
- 랜딩 페이지에서 `상담 신청` 버튼이 자연스럽게 보이는지 검증

## 미결정 항목
- 실제 상담 채널 주소/링크(카톡 채널ID, 네이버 폼 URL, 전화번호)
- 랜딩 페이지에 들어갈 실제 후기·수강생 수
- 유료 광고 집행 여부 및 예산
