## 1️⃣ 이서연 · 기획·마케팅 — 「메시지가 무겁다. 후크 3초의 원칙」

> "저희 시안 5세트 다시 봤어요. **문학적이에요. 좋아요, 그런데 인스타에서 3초 안에 후크가 걸리지 않아요.** 「털 같은 눈썹」이라는 단어는 강해요. 그런데 그 단어가 첫 슬라이드에 안 나와요. 「20년 · 한 사람의 손끝」 같은 시적 헤드로 시작하니까 스와이프 안 하고 넘겨요."

### 개선안 A · 「후크-훅-훅」 3장 구조
- **1장 = 문제 제기 훅** (질문·통계·충격) — 예: "왜 660만원짜리 눈썹 수업이 매번 마감입니까?"
- **2장 = 답 예고** — 예: "8,000명이 선택한 이유. 하나."
- **3장 = 답 = 「털 같은 눈썹」** — 원장 원문·매크로
- **4~N장** = 근거·데이터·CTA
- **원칙**: 첫 3장 안에 「털 같은 눈썹」 어휘 등장 강제

### 개선안 B · **CTA 를 「상담 신청」 → 「지금 시작」·「자리 확인」** 로 다변화
- 「상담 신청」은 원장님 원칙 유지 · 다만 광고 밸리언트에서 「이번 15기 자리 3석 남음」 같은 긴급성 CTA 도 병행
- A/B 테스트로 CTR·상담 전환율 비교

### 리스크
- 후크형이 「극사실 브랜드 톤」과 상충 우려 → 「후크 세리프 톤 유지」로 절충 필요

### 개선안 A · Maison Noir + **딥 로즈 (핫핑크 계열 하나 추가)** 액센트
- 기존 Maison Noir 팔레트 유지 + `--mn-accent-rose: #E4577A` 신설 (기존 살구핑크 브랜드 정합)
- **강조 단어 1개만** 딥 로즈 (예: 「털 같은 눈썹」의 「털」)
- 골드 hairline 은 유지 · 다만 액센트 pop 이 눈에 걸리도록

### 개선안 B · **인물 컷 20~30% 크롭 확대** (얼굴 근접감)
- 지금 hero-portrait 는 얼굴이 이미지 30~40% 영역만 차지 · 인스타에서 존재감 약함
- 얼굴 65% 이상 크롭 · 눈썹이 화면에 가깝게 · 「손 끝 매크로」 강화
- Dior · Chanel Beauty 인스타 톱 3장이 다 얼굴 근접

### 개선안 C · **Reels 커버형 세로 카드** 신 kind 추가
- 지금은 정지 카드만 있음 · Reels 커버는 세로 9:16 + 큰 대문자 헤드 (0.5초에 이해)
- 카드뉴스 6장 세트 + Reels 커버 1장 자동 생성 = 세트 완성

### 리스크
- 컬러 팝은 원장님 재컨펌 필요 · Maison Noir 단일 톤 원칙 훼손 우려

## 3️⃣ 김다은 · SaaS A PM — 「시안 시스템은 되었다. 자동 게시 링크가 없다」

> "카드뉴스 편집기·자동 생성·미리보기 다 붙었어요. **그런데 결국 원장님이 인스타 앱에서 수동으로 올려요.** 원장님 손이 안 자유로우면 매주 자동 발송이 안 돌아요. 아무리 좋은 스타일이어도 게시가 안 되면 무용지물."

### 개선안 A · **자동 게시 파이프라인** — 카드뉴스 완성 → Meta Graph API 1클릭
- Meta Graph API 인스타그램 비즈니스 계정 연동 (카페24 결정 나면 함께)
- 카드뉴스 6장 세트 → 1클릭 「인스타 예약 게시」 (24시간 스케줄)
- 원장님 UX = 「미리보기 → 게시 시간 선택 → 승인」 3탭

### 개선안 B · **카드뉴스 → 홈페이지 랜딩** 자동 연결
- 카드뉴스 마지막 CTA 슬라이드 = QR 코드 or 짧은 URL (예: `artbrow.co.kr/c/15gi`)
- 홈페이지에 「이 카드뉴스 → 이 랜딩 페이지」 자동 매핑 · UTM 추적 · 상담 전환율 측정

### 리스크
- Meta Graph API = 인스타 비즈니스 계정 인증 필요 · 원장님 계정 인증 절차 필요 (2~5일)

## 4️⃣ 박서윤 · SaaS B PM — 「광고 밸리언트가 없다」

> "저는 광고 뿌리는 사람이에요. **광고는 밸리언트 A/B 최소 5개를 병렬로 뿌려야 CTR 이 나옵니다.** 지금은 시안 5세트 = 1개 광고 세트. 이걸로 광고 돌리면 첫 3일 CTR 데이터 부족해서 죽습니다."

### 개선안 A · **1 카드뉴스 = 5 광고 밸리언트 자동 생성**
- 스타일 12 Rebellion Serif 하나 잡고 → 카피만 5안 (긴급성·질문형·통계형·후기형·감성형)
- Gemini + OpenAI 병렬 생성 (기존 파이프라인 활용 · autoVariants 필드 확장)
- 광고 뿌린 후 3일간 CTR·ROAS 데이터로 승자 결정 → 나머지 스타일 자동 정지

### 개선안 B · **「내 계정」 학습으로 원장님 인스타 90일 분석**
- Meta Graph API 로 원장님 계정 최근 90일 게시물 분석
- 좋아요·저장·공유 top 5 게시물의 공통 DNA (헤드 어휘·이미지 컷·시간대) → 신 카드뉴스에 자동 반영
- 「원장님이 이미 잘 되는 톤」 을 데이터로 뽑아옴

### 개선안 C · **인스타 「Story-first」 5장 세트** 신 kind
- 카드뉴스 6장 = 피드용 · Story 5장 = 세로 9:16 · 스티커·투표·질문 상호작용
- Story 참여율 = 피드 CTR 의 3~5배 · 광고 예열용 최적

### 리스크
- Meta Graph API 승인 = 대기 5~10일 · 지금부터 신청해야 8월 말 오픈 맞춤

## 5️⃣ 최예진 · SaaS C PM — 「Face Lab 결과 → 개인화 카드뉴스」

> "이 카드뉴스는 「모두에게 같은 것」을 보여줘요. **개인화가 없어요.** Face Lab v7 이 있잖아요. 사용자가 얼굴 사진 올리면 「당신에게 어울리는 극사실눈썹 3형」 카드뉴스 6장 자동 생성해서 인스타 DM 보내는 게 훨씬 강력해요."

### 개선안 A · Face Lab v7 → **개인화 카드뉴스 자동 발송**
- 사용자가 홈페이지에서 얼굴 사진 업로드 → Face Lab 진단 → 결과 = 카드뉴스 6장 (그 사람의 얼굴 형태·추천 눈썹·창시자 브랜드)
- 인스타 DM or 카카오 자동 발송 · 인스타에서 「저장」 유도
- CTR·상담 전환 = 일반 광고 대비 5~10 배 (Perfect Corp 데이터)

### 개선안 B · **원장님 시술 전·후 3컷 자동 카드뉴스** (개인 케이스)
- 원장님이 시술 완료 후 사진 3장 (전·펜슬·후) 업로드 → 자동 카드뉴스 6장 생성 (오늘 케이스·근거·후기·CTA)
- 원장님 SOP 워크플로 : 시술 → 사진 3장 → 카드뉴스 자동 → 승인 → 게시 (5분)

### 리스크
- Face Lab v7 는 아직 미배포 · Phase 1 최소 3~4주 필요 · 8월 말 오픈에는 못 맞춤
- 의료광고법 §5.3 「진단」 표현 회피 필수 · 카피 검수 필요

> "저는 20년 개발하면서 봤어요. **화려한 신 기능은 늘 발산됩니다. 근본은 「돌아가는가」 입니다.** 지금 카드뉴스 17종은 이미 화려한데, 「원장님이 매주 1건 발송이 되는가?」 물으면 아니오예요."

### 개선안 A · **자동 게시 API 통합 우선** (스타일 신 개발 보류)

### 개선안 B · **비용·운영 시나리오 문서화**
