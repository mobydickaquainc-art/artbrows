## 1. 페르소나 — 「하영」

| 항목 | 내용 |
|---|---|
| **이름** | 하영 (28세) |
| **직업** | 헤어 디자이너 또는 메이크업 아티스트 (3~5년차) |
| **소속** | 동네 미용실 또는 강남권 헤어샵의 디자이너 직급 |
| **하루** | 오전 11시 출근 → 시술 → 마감 정리 → 밤 9~10시 퇴근. 화요일 정기 휴무 |
| **숨겨진 욕망** | "지금 직장 안에서 + 내 시그니처 전문 영역(눈썹) 하나 더 가져서, **단가와 고객 충성도를 올리고 싶다.** 나아가 내 가게의 메인 메뉴가 될 수도 있다." |
| **고민** | ① 헤어·메이크업은 「유행 따라잡기」 피로 누적 ② 시그니처 메뉴가 없으면 가격경쟁에 시달림 ③ 결국 내 가게로 가는 길이 막막 ④ 자격증·과정 많지만 「창시자 직강」급은 드뭄 |
| **강점** | 손기술 · 미적 감각 · 고객 응대 · **이미 뷰티 시장 안에 있어 진입 장벽이 가장 낮음** · 동료·사장님 네트워크 |
| **선호 SNS** | 인스타·유튜브 (뷰티 디자이너·원장 콘텐츠 다수 팔로우) |
| **결정 동기** | 「창시자 직강」 + 「3단계 커리큘럼」 + 「소수정예 = 다른 디자이너와 차별화」 + 「내 가게에 메뉴 하나 더」 |

### 1-1. 하영의 ARTbrows 접점
1. 인스타에서 STORY · 02 직장인편(지우) 또는 모집 카드 「창시자 직강」 노출 → **「이미 손이 좋은 나라면 더 빠르다」** 자각
2. 카드 「차별점 — 1위의 기준 + 실전 감각」 보며 「창시자한테 직접 배우면 시그니처 만들 수 있다」 확신
3. 카드 「커리큘럼 3단계」가 미용 자격증·심화 과정과 닮아 익숙
4. 동료 디자이너에게 「이거 진짜 좋다」 입소문 가능 → 추가 모객 자산

> 시리즈 안에서 **하영(미용 종사자)** 은 **「가장 가까운 곳에서 오는 수강생」** — 다른 6편은 「새 영역 진입」이지만, 07은 「**같은 손에 + 1**」.

## 6. 시리즈 운영 — 동종업계 시너지

미용 종사자편은 **「가장 빠른 전환」** 페르소나가 될 가능성:

| 활용안 | 설명 |
|---|---|
| **미용실·뷰티숍 시드** | 인스타 광고를 미용 종사자 타겟팅 → 가장 결제 가까운 잠재 수강생 |
| **동료 입소문** | 한 명이 등록하면 같은 매장 디자이너에게 입소문 — 추가 모객 자산 |
| **블로그 칼럼** | "헤어 디자이너가 눈썹을 배우면 생기는 일 — 단가·고객 충성도" |
| **하이라이트 추가** | 「미용 종사자」 하이라이트 — 동종업계 영구 노출 |
| **상담 채널 분기** | 「미용 종사자 상담」 라벨로 별도 응대 흐름 검토 |

> 시리즈 7편 = 일반 잠재고객 6편 + **전환 직결 1편** 으로 균형. 다음 회차부터는 다시 「인생 단계」 페르소나로 돌아갈지, 「직군 시리즈」로 분기할지 결정 대기.
