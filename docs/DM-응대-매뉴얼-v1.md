# 인스타 DM 응대 매뉴얼 v1

> **카카오 채널이 열리기 전까지** ARTbrows 인스타그램(@artbrows.korea) DM으로 들어오는 상담 문의에 즉시 응대할 수 있는 5종 템플릿.
> 작성일: 2026-06-22 · 담당 AI 직원: 이서연(기획·마케팅) · 회의 2안 채택본
> 운영 원칙은 [인스타-그리드-운영가이드.md](인스타-그리드-운영가이드.md) §0 참고.

---

## 0. 운영 원칙 (먼저 한 번에)

1. **응답 시간 목표 = 1시간 이내**. 자동응답 1차 + 수동 응답 2차 구조.
2. **결제 표현 금지** — 항상 「상담 신청」 또는 「상담 예약」 으로 한정.
3. **임의로 가격·일정·정원 수정 금지**. 변경 필요 시 대표님 컨펌 후.
4. **AI 후기·시술 사진 사용 금지** — 실제 자료 수령 후만.
5. **DM은 영구 보관**. 응대 종료 후 캡처 1장씩 저장 (운영 일지 자료).
6. **마지막 한 줄은 항상 「상담은 프로필 링크 → DM 또는 추후 카카오 채널」**.

> 카카오 채널 오픈 후에는 본 매뉴얼 v2로 마이그레이션 (모든 안내 끝에 「카카오 채널 친구 추가」 한 줄 추가).

## 1. 템플릿 1 · 첫 인사 (자동응답 1차)

> 인스타 비즈니스 계정 → 설정 → 메시지 → **빠른 답장** 기능에 등록. 누구든 DM 보내면 즉시 발송.

```
안녕하세요! ARTbrows · 장미지 눈썹 연구소입니다 💛

한국 반영구 1위 아카데미, 극사실눈썹 창시자에게 직접 배우시는
프리미엄 소수정예 과정에 관심 주셔서 감사드립니다.

문의 주신 내용은 운영진이 영업일 기준 1~24시간 안에
1:1로 답변드리고 있어요. 잠시만 기다려 주세요 :)

· 모집 콘텐츠는 프로필 피드에서
· 시리즈 쇼츠는 릴스 탭에서
· 더 자세한 안내는 답장 메시지에서 이어드립니다.

— ARTbrows Team
```

**키워드 트리거 (인스타 자동응답 빠른 답장 ID)**
- `안녕하세요` / `상담` / `문의` / `궁금` → 위 메시지 자동 발송

## 2. 템플릿 2 · 일정 문의 응답

> 「언제 시작해요?」 「수강 기간 얼마나 걸려요?」 류 질문에 사용.

```
안녕하세요, [성함] 님!

ARTbrows 과정 일정 안내드립니다.

▣ 다음 수강 시작 — 🟡 [대표님 컨펌 후 입력 · 예: 2026-07 차]
▣ 총 수강 기간 — 🟡 [대표님 컨펌 후 입력 · 예: 3단계 약 N주]
▣ 주 N회 · 회당 N시간 — 🟡 [대표님 컨펌 후 입력]
▣ 정원 — 소수정예 [N]명 모집 중

· 자세한 일정·요일 조율은 「상담 예약」 후 1:1로 잡아드리고 있어요.
· 추후 카카오 채널이 열리면 그쪽에서도 동일하게 안내드립니다.

→ 다음 단계: 「상담 예약」 원하시면 편한 시간 알려주세요.
```

**🟡 자료 필요 항목 (대표님 직접 입력)**
- 다음 차수 시작일
- 총 수강 기간 (3단계별 주차)
- 주 회당 시간
- 정원 N명

---

## 3. 템플릿 3 · 가격 문의 응답

> 「수강료 얼마예요?」 「분할 가능해요?」 류 질문에 사용.

```
안녕하세요, [성함] 님!

ARTbrows 수강료 안내드립니다.

▣ 정규 과정 수강료 — 69만원
▣ 평생 수강 — 추가 비용 없이 차후 수강까지 평생 재참여 가능
▣ 납부 방식 — 🟡 [대표님 컨펌 후 입력 · 예: 일시납 / 2회 분할]
▣ 환불 정책 — 🟡 [대표님 컨펌 후 입력]

「많이」가 아니라 「깊이」를 위한 선택이에요.
실력으로 「장미지 원장의 기준」을 그대로 받으시는 자리라서
가격보다는 「누구에게 배우느냐」에 가치를 두시는 분들이 오십니다.

→ 다음 단계: 1:1 상담에서 더 자세히 안내드릴게요.
```

**🟡 자료 필요 항목**
- 납부 방식 (일시납·분할 여부·할부 조건)
- 환불 정책 (정확한 환불 가능 기간·차감 조건)
- 수강료 변동 정책 (다음 차수까지 동결 여부)

## 4. 템플릿 4 · 정원 문의 응답

> 「자리 남았어요?」 「언제 마감이에요?」 류 질문에 사용.

```
안녕하세요, [성함] 님!

ARTbrows 소수정예 모집 현황입니다.

▣ 다음 차수 정원 — 🟡 [대표님 컨펌 · 예: N명]
▣ 현재 마감 여유 — 🟡 [대표님 매주 갱신 · 예: 정원 절반 마감 / 마감 임박]
▣ 모집 마감일 — 🟡 [대표님 컨펌 · 예: 7월 N일]
▣ 다음 차수 — 🟡 [대표님 컨펌]

· 「많이」가 아니라 「깊이」를 위한 선택. 정원이 줄어드는 속도가 빨라요.
· 망설이시면 다음 차수 알림 신청 받아드립니다.

→ 다음 단계: 자리 확정은 「상담 예약 → 일정 협의 → 등록」 순서입니다.
```

**🟡 자료 필요 항목**
- 차수별 정원 (N명)
- 현재 마감 여유 (매주 대표님이 직접 갱신)
- 모집 마감일
- 다음 차수 (탈락 시 우선 안내 여부)

---

## 5. 템플릿 5 · 상담 예약 (전환 클로징)

> 위 4종 응답 후 「예약 잡아주세요」 또는 「언제 상담 가능해요?」 류 질문에 사용.

```
안녕하세요, [성함] 님! 상담 예약 안내드립니다.

▣ 상담 방식 — 1:1 (전화 · 줌 · 방문 중 선택)
▣ 소요 시간 — 약 30분
▣ 위치 (방문 시) — 🟡 [대표님 컨펌 · 예: 강남구 봉은사로 N길, 선릉/봉은사]
▣ 운영 시간 — 🟡 [대표님 컨펌 · 예: 평일 N시 ~ N시 / 주말 별도]

▣ 예약 절차
1) 편하신 일시 2~3개 알려주세요 (요일·시간)
2) ARTbrows에서 가능 시간 매칭 → 확정
3) 상담 30분 → 등록 결심하시면 후속 일정 즉시 잡아드립니다

▣ 준비물 (편의 사항)
- 본인 사진 1~2장 (현재 눈썹 라인 확인용 · 선택)
- 궁금하신 질문 메모

추후 카카오 채널이 열리면 그쪽으로 자동 안내드리고,
지금 단계에서는 인스타 DM이 메인 상담 창구입니다.

· 상담 후 부담스러우면 언제든 「취소」 가능해요. 결제 강요 없습니다.

→ 다음 단계: 편하신 일시 알려 주세요!
```

**🟡 자료 필요 항목**
- 방문 위치 (정확한 주소 + 교통 안내)
- 운영 시간 (평일·주말)
- 상담 가용 시간대 (대표님 / 장미지 원장님 일정)

## 6. 시나리오 분기 — 자주 묻는 질문 응답 한 줄

| 질문 | 응답 핵심 |
|---|---|
| 「초보인데 가능해요?」 | "네, 다수가 비전공·초보부터 시작합니다. 기초부터 손에 익을 때까지 1:1로 봐드려요." |
| 「자격증 발급되나요?」 | 🟡 [대표님 컨펌 — 자격증·수료증 발급 여부] |
| 「취업 연계 있나요?」 | 🟡 [대표님 컨펌 — 협력 샵·취업 연계 정책] |
| 「장미지 원장님이 직접 강의해요?」 | "네, 창시자 직강 클래스 그대로 진행합니다. 보조 강사 위주 학원과의 가장 큰 차이입니다." |
| 「실습 시간 많아요?」 | "극사실 드로잉·실습 비중이 가장 큽니다. 이론보다 손이 익는 시간이 중심." |
| 「외국인도 수강 가능해요?」 | 🟡 [대표님 컨펌 — 다국어 지원·언어 정책] |
| 「온라인 가능해요?」 | 🟡 [대표님 컨펌 — 온라인·하이브리드 운영 여부] |
| 「견본 시술 사진 볼 수 있어요?」 | 🟡 [원장님 자료 수령 후 — 현재는 「실제 시술 사진은 자료 정리 중, 곧 안내드립니다」 안내] |

## 7. 응대 절대 금지 패턴

| 금지 | 사유 |
|---|---|
| AI 합성 후기·시술 사진 전송 | 허위광고 위험 (CLAUDE.md §4) |
| 가격 즉흥 할인 ("이번 주만 50%") | 브랜드 권위 훼손 + 다른 등록자 신뢰 문제 |
| 「지금 결제하면」 같은 즉결 압박 | CTA 원칙 위반 — 항상 「상담 신청」으로 |
| 환불 정책 임의 약속 | 분쟁 위험 — 🟡 자료 대기 시점에는 「상담 시 안내」로 우회 |
| 정원 임의 늘리기 | 「소수정예」 핵심 가치 훼손 |
| K1 카톡방 링크 즉시 노출 | K1은 **수강생 전용 락인 채널** — 등록 결심 후만 안내 |

## 8. 응대 KPI (D+7 / D+14 / D+30 검토)

| 지표 | D+7 목표 | D+14 목표 | D+30 목표 |
|---|---|---|---|
| 1차 자동응답 노출 | 5건 | 20건 | 80건 |
| 2차 수동 응답 평균 시간 | 24시간 이내 | 12시간 이내 | 1시간 이내 |
| 상담 예약 전환 | 1건 | 5건 | 20건 |
| 실제 상담 진행 | 1건 | 3건 | 10건 |
| 등록 전환 | 0~1건 | 1~2건 | 3건 이상 |

**측정 도구:** 인스타 인사이트 + DM 폴더 「상담」 라벨 + 별도 스프레드시트 (대표님 운영 일지)

## 9. 카카오 채널 오픈 시 v2 마이그레이션

카카오 채널 개설되면 본 매뉴얼 v2로 업데이트:

1. 모든 응답 끝에 **「카카오 채널 친구 추가 → 알림톡 받기」** 한 줄 추가
2. 자동응답을 카카오 채널 챗봇과 인스타 DM **양쪽 동기화**
3. 상담 예약 시 카카오 채널의 「예약 폼」 활용
4. 등록자에게는 **K1 수강생 카톡방** 별도 초대 (등록 결심 후)
5. 인스타 프로필 링크를 카카오 채널 URL로 교체
