# R1 도메인 셋업 가이드 — eyebrows-main.staris.cloud

> 작성: 2026-06-15 · 한승철 (CTO)
> 적용 시점: Next.js dev 가 안정화된 후 (R3 끝나면 실 배포)

## 도메인 발급 흐름

```
가비아 staris.cloud (이미 보유)
    ↓ CNAME 추가
eyebrows-main.staris.cloud
    ↓ 가리킴
배포 호스트 (Vercel 또는 맥미니+Tailscale)
    ↓ Next.js 빌드물 서비스
프로덕션 사이트 라이브
```

## 가비아 CNAME 추가 절차 (대표님 5분)

1. **https://www.gabia.com** 로그인
2. 상단 **My가비아** → 좌측 **DNS 관리**
3. `staris.cloud` 선택 → **DNS 정보** → **DNS 설정**
4. 우측 **레코드 수정** 클릭
5. 새 레코드 추가:
   - **타입:** `CNAME`
   - **호스트:** `eyebrows-main`
   - **값/위치:** (배포 방식에 따라 다름 — 아래 §2 참조)
   - **TTL:** `600`
6. **저장** → DNS 전파 5~30분 대기

## §2. 배포 호스트별 CNAME 값

### 옵션 A — Vercel (가장 빠름 · 추천)

1. https://vercel.com 가입 → GitHub 으로 로그인 권장
2. **Add New** → **Project**
3. Repository import 또는 로컬 폴더 업로드 (`app-next/` 만)
4. Framework Preset: Next.js 자동 인식
5. Environment Variables 추가:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`
   - `SUPABASE_SECRET_KEY`
6. Deploy 클릭 → 빌드 ~1분
7. 배포된 URL 받음 (예: `eyebrows-main-xxx.vercel.app`)
8. Vercel Dashboard → **Project Settings → Domains** → `eyebrows-main.staris.cloud` 추가
9. Vercel 이 알려주는 CNAME 값을 **가비아 CNAME** 에 넣음 (보통 `cname.vercel-dns.com`)
10. HTTPS 인증서 자동 발급 (대기 5분)

### 옵션 B — 맥미니 + Tailscale (운영 안정 후)

1. 맥미니 구매 후 `~/.claude/docs/mobydick-standard.md` 따라 셋업
2. Tailscale 가입 → 맥미니 + 도메인 등록 PC 모두 연결
3. 맥미니에 Node.js 20+ · pm2 · nginx 설치
4. `app-next/` 폴더를 맥미니에 동기화
5. `npm run build && npm run start` 또는 `pm2 start npm -- start`
6. nginx reverse proxy 로 `eyebrows-main.staris.cloud` 트래픽을 localhost:3000 로
7. Tailscale Funnel 또는 Cloudflare Tunnel 로 외부 노출
8. 가비아 CNAME 값 = Tailscale Magic DNS (예: `eyebrows-mac.tail-xxxx.ts.net`)
