## 1. 페르소나 — 「민지」

| 항목 | 내용 |
|---|---|
| **이름** | 민지 (23세) |
| **상황** | 미대 4학년 / 갓 졸업 — 비주얼아트·일러스트레이션 전공 |
| **거주** | 부모님 댁 또는 학교 인근 원룸, 작은 작업실(스튜디오) 보유 |
| **하루** | 작업·졸업전시 준비·아르바이트, 진로 고민 사이를 오감 |
| **숨겨진 욕망** | "전공을 살리면서, 30대에 내 가게/내 작업실을 가질 수 있는 길을 미리 만들고 싶다." |
| **고민** | ① 작품 활동만으로 생계 어려움 ② 일반 회사 취업은 성에 안 참 ③ 부모님 기대 vs 본인 의지 |
| **강점** | 손재주 · 미적 감각 · 디테일 · 색감·구도 감 · SNS 친숙 |
| **선호 SNS** | 인스타·핀터레스트·유튜브 (작가·창업 콘텐츠 팔로우 다수) |
| **결정 동기** | 「창시자 직강」 + 「3단계 커리큘럼」 + 「소수정예 직강이 전공자의 미적 감각과 시너지」 |

### 1-1. 민지의 ARTbrows 접점
1. 인스타에서 STORY · 02 직장인편(지우) 보고 "나도 미리 준비할 수 있겠다" 진입
2. 카드 「차별점 — 1위의 기준 + 실전 감각」을 보며 진짜 직업 자산으로 인식
3. 카드 「커리큘럼 3단계」가 미술 전공자의 그림 훈련과 연결돼 익숙함
4. 상담 신청 → 졸업 전후 등록 → **미대생편 본인이 됨**

> 시리즈 안에서 **미대생(민지) → 직장인(지우) → 워킹맘(수아) → 시니어(선영)** 라는 한국 여성의 인생 곡선이 자연스럽게 묶임. 「ARTbrows는 어느 단계에서도 새 시작이 된다」 메시지.

## 3. 시나리오 — 5컷 (총 24~26초)

### 컷 1 (0~5초) · 「기」 — 작업실 오후
- **비주얼:** 학교 작업실, 졸업 작품(캔버스 회화 또는 일러스트 보드) 옆에 앉아 진로 고민하는 민지. 책상에는 붓·물감·노트·노트북. 표정은 살짝 막막함.
- **자막:** "**졸업이 다가오는 어느 날**"

### 컷 2 (5~12초) · 「승」 — 화구 옆 눈썹 드로잉
- **비주얼:** 자기 작업실. 회화 화구와 함께 눈썹 드로잉 노트가 책상에 놓여 있고, 민지는 펜으로 정성스럽게 한 줄 한 줄 그림. 햇살이 손등에.
- **자막:** "**전공 너머, 새로운 한 발**"

### 컷 3 (12~18초) · 「전」 — 완성의 떨림
- **비주얼:** 완성된 눈썹 패드를 들어 환한 미소. 뒤에는 졸업 작품과 화구가 함께 보임 — **「예술의 손」과 「직업의 길」이 한 화면에**.
- **자막:** "**예술의 손이, 직업이 되다**"

### 컷 4 (18~22초) · 「전 2」 — 부모님 또는 친구에게 자랑
- **비주얼:** 어머니/친구에게 패드와 졸업작품 함께 보여주며 자랑스럽게 웃는 장면.
- **자막:** "**재능에 길이 더해지면, 직업이 됩니다**"
