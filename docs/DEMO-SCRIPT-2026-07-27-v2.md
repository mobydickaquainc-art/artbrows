## 1. **완전 새로 만들기** (Pattern A · 8분)

**진입**: 대시보드 → 「📸 이미지로 시작 A · 자동 생성」

### Step 1 · 이미지 던지기 (1분)
[http://localhost:3000/cardnews/from-images](http://localhost:3000/cardnews/from-images)

**시연 흐름**:
1. 「클릭 or 파일 드래그」 영역에 원장님 실 이미지 **1~3장** 드래그 (또는 자산 인벤토리에서 클릭 선택 · 49장 미리 로드됨)
2. 「어떤 용도인가요?」 → **「모집」** 클릭
3. 「인스타 규격」 → **「세로 (4:5)」** (기본)
4. 「슬라이드 개수」 → **「AI 자동」** 또는 **「6장」**
5. **「다음 → AI 분석」** 클릭

**대사**:
> 「보시는 것처럼 이미지 1장만 던져도 됩니다. AI 가 내용을 이해하고 어떤 방향으로 카드뉴스를 만들지 스스로 제안해요.」

### Step 2 · 방향 추천 (2분)

**대기 시간**: 10~20초 · Gemini Vision 3.1 Pro 가 각 이미지 분석

**보여줄 것**:
- 이미지별 인식 결과 카드 (subject · tone · notes)
- AI rationale (한 줄 판단 이유)
- **방향 옵션 3~4개** — 각 카드에 라벨/설명/FIT 점수/추천 kind 시퀀스

**대사**:
> 「AI 가 4가지 방향을 제안했어요. 원장님이 마음에 드는 걸 클릭.」

→ **「모집·15기 이지클래스」** 방향 클릭

### Step 3 · **4안 양산 · 원장님 선택** (5분) — 🌟 **핵심 시연**

**대기 시간**: 20~40초 · **4 안 병렬 생성** (💎 Gemini 안정 + 💠 Gemini 실험 + 🎯 OpenAI 안정 + 🎨 OpenAI 실험)

**대사** (기다리는 동안):
> 「지금 4개 AI 가 동시에 각자 6장씩 총 24장을 만들고 있습니다. Gemini 3.1 Pro 최신 2안 (안정·실험) + OpenAI GPT-5.1 2안 (안정·실험). 실패해도 다른 안이 살아 있어서 시연이 멈추지 않아요.」

**완료 시 보이는 것**:
- 2×2 grid **4개 카드** 나란히 · 각 카드 상단에 라벨 (💎 Gemini · 안정 등)
- 각 카드 안에 **6장 세로 스크롤 미리보기**
- 각 카드 하단에 **「✅ 이 안으로 확정」** 골드 버튼

**포인트 강조**:
- 「안정」 = 원장님 정본 톤 (「털 같은 눈썹」 등 어록 유지)
- 「실험」 = 후크 강한 헤드라인 · 리듬 있는 표현 (인스타 스와이프 유도)
- 두 모델 * 두 톤 = **선택 폭 4배** · 원장님이 마음에 드는 것만 저장

**시연 액션**:
1. 4개 카드 훑기 (5초씩)
2. 하나 골라 「✅ 이 안으로 확정」 클릭
3. 자동으로 편집기 이동

### 2.1 스타일 프리셋 원클릭 시연 (3분)

**대사**:
> 「원장님이 이 화면에서 하실 일은 딱 하나 — 마음에 드는 스타일 프리셋을 클릭. 6종 있습니다.」

**시연 흐름**:
1. 중앙 미리보기에서 오버레이 하나 클릭 → 골드 하이라이트
2. 우측 상단 **스타일 프리셋 바** 에서 각각 클릭해 즉시 변화 보여주기:
   - **원장 실톤 볼드** (07-24 원장 직접 배포본 · 갈색 박스 + 프리텐다드)
   - **Vogue 대헤드** (Cormorant 세리프 · 아이보리 · 투명 검정)
   - **골드 시그니처** (나눔펜 필기 · 골드 · 배경 없음)
   - **명조 인용** (나눔명조 · 아이보리)
   - **임팩트 선언** (Black Han Sans · 검정 pill)
   - **화이트 라벨** (고딕 · 블랙 텍스트 · 화이트 박스)
3. 각 프리셋 클릭할 때마다 미리보기 즉시 변경 → 원장님이 「이거!」 하는 순간이 임팩트 포인트

### 2.2 문장 교체 · Gemini Vision 시연 (4분) — 🌟 **가장 인상적**

**대사**:
> 「이번엔 반대로 · 사진에 이미 새겨진 문장을 다른 문장으로 바꿔야 하는 상황. AI 가 원본 스타일을 그대로 카피해 옵니다.」

**시연 흐름**:
1. 상단 툴바 **「🎯 문장 교체」** 클릭 (핑크 그라디언트로 활성)
2. 미리보기 위에 「교체할 문장 영역을 마우스로 드래그」 오버레이 등장
3. **문장 영역을 마우스로 드래그** → 골드 점선 사각 박스
4. mouseUp = **Gemini Vision 3.1 Pro** 가 해당 영역 분석 (2~5초)
5. 확정 모달 팝업:
   - 원본 문장 (예: 「어느 눈썹이 진짜일까요?」)
   - 감지 스타일 (폰트 · 굵기 · 크기 · 정렬 · 글자색 · 배경) · 라벨로 시각화
   - **새 문장 입력창** (원본이 기본값)
6. 새 문장 입력 (예: 「진짜 눈썹은 시술이 아니라 예술입니다」) → **「✅ 이 자리에 배치」**
7. 오버레이가 원본 자리에 · 원본 스타일 그대로 · 새 문장으로 배치됨
8. 우측 인스펙터가 자동으로 그 오버레이 활성 → 위치/색 미세 조정 가능

**대사** (확정 모달 나올 때):
> 「Gemini 가 원본 텍스트의 폰트·색·크기·배경을 그대로 카피했습니다. 원장님은 문장만 새로 입력하면 되고, 배치 후에도 우측에서 자유롭게 미세 조정할 수 있어요.」

### 2.3 AI 카피 팔레트 (2분)

**대사**:
> 「원장님이 새 문장을 매번 생각하기 힘드시니 · AI 가 미리 여러 후보를 준비해 뒀습니다.」

**시연 흐름**:
