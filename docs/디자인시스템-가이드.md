# ARTbrows 디자인 시스템 가이드

> Phase 1 모집 콘텐츠(카드·쇼츠 썸네일·랜딩)의 비주얼 톤을 통일하기 위한 가이드.
> 작성일: 2026-06-06 · 담당 AI 직원: 유나(그래픽·비주얼)

---

## 0. 목적

인스타그램 그리드와 유튜브 쇼츠 채널에 카드·쇼츠가 섞여 노출될 때 **한 브랜드의 시리즈**로 보이도록 시각 톤을 통일합니다.

**현재 톤 불일치 (실측)**

1. 모집 카드 = 살구핑크 진한 배경 + 핫핑크 강조
2. 쇼츠 주인공 일러스트 = 크림 베이지 + 강조 약함
3. 카드는 1:1 정사각, 쇼츠 인물은 세로 → 인스타 그리드용 1:1 컷이 없음

## 1. 컬러 팔레트 (고정)

| 토큰 | HEX | 용도 |
|---|---|---|
| `--apricot` | `#FBEAE2` | 메인 배경 (살구핑크) |
| `--apricot-2` | `#FFF5EE` | 보조 배경 (밝은 살구) |
| `--cream` | `#FFFBF5` | 카드/오버레이 베이스 |
| `--ink` | `#3A2A26` | 본문 글자 |
| `--muted` | `#9A6A5E` | 보조 문구 |
| `--hotpink` | `#FF6F84` | 메인 강조 (CTA·시리즈 칩) |
| `--coral` | `#FF7A66` | 보조 강조 |
| `--line` | `#EAD2C8` | 구분선 |

**원칙:** 쇼츠 인물 일러스트의 배경을 살구핑크(#FBEAE2)로 통일하거나, 인물을 살구핑크 프레임 위에 합성한다. 단순 크림 베이지 단색 배경은 사용 금지.

## 4. 시리즈 정체성

각 시리즈는 같은 디자인 시스템 위에서 **시리즈 라벨**과 **헤드라인 톤**으로 구분합니다.

| 시리즈 | 시리즈 라벨 | 주인공 | 헤드 톤 |
|---|---|---|---|
| 코믹 도비편 | `EPISODE · COMIC` | 도비 + 그녀 | 유머·반전 |
| 성장기편 | `STORY · 01` | 하은 | 잔잔한 공감 |
| 직장인편 | `STORY · 02` | 지우 | 도전·전환 |
| 신부편 | `STORY · 03` | 예린 | 설렘·완성 |

> 시리즈 라벨은 **흰 글씨 + 핫핑크 배경**의 라운드 칩으로 고정.

## 5. 운영 규칙

1. **새 시리즈 추가 시** 라벨에 `STORY · 04` 처럼 순번을 잇는다.
2. **인물 일러스트 재생성 시** 프롬프트에 `soft watercolor portrait on warm apricot pink background, ARTbrows brand`를 포함한다.
3. **카드 헤드라인**과 **쇼츠 헤드라인**이 짝을 이루도록: 카드는 후킹·설명형, 쇼츠는 스토리·감정형.
4. **CTA**는 항상 `상담 신청`. 결제/등록 표현 금지.
5. 인스타 그리드 정렬 시 카드 1:1과 쇼츠 1:1 썸네일이 **번갈아** 배치되어도 톤이 끊기지 않아야 한다.
