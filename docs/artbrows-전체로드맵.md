# ARTbrows 전체 로드맵 — 모든 솔루션 + 광고 플랫폼

> **목적:** "장미지 원장(극사실눈썹 창시자)의 브랜드 마케팅 — 모든 솔루션 개발 및 광고 플랫폼"이라는 큰 그림을, 하네스 공법(**기획 → 플랜 → 스케줄 → 개발**)에 맞춰 단계별로 정리한 문서입니다.
> **사용법:** 세션을 시작할 때 `CLAUDE.md` → `docs/PROGRESS.md` → 이 문서 순으로 읽고 현재 단계를 파악합니다.
> **원칙:** 개발(실행) 단계의 모든 결정은 대표님께 먼저 확인합니다. 정해지지 않은 항목은 본문에 **🟡 결정 대기**로 표시했습니다. 일정·범위는 모두 **제안**이며 확정 전까지 임의 진행하지 않습니다.

## 2. 단계별 상세

### Phase 0 — 기반 정비 (현재 위치)

**목표:** 다음 작업을 막힘없이 시작할 수 있도록 도구·자료·기록을 정돈.

**핵심 작업**

- 산출물 복구: PROGRESS.md엔 완료로 적혀 있으나 폴더가 비어 있는 항목(페르소나, 기획·마케팅안, 도구·워크플로 확정안, 상세페이지 2종, 파이프라인 도식) 재생성 여부 결정·복구.
- 도구 셋업: 힉스필드 API 플랜 확인 + 가입, Nano Banana Pro API 키 발급 + 소액 선불 충전.
- 기록 현행화: 실제 폴더 상태에 맞게 PROGRESS.md 갱신(완료).

**산출물:** 복구된 기획 문서 세트, 발급된 API 키, 현행화된 PROGRESS.md.

**🟡 결정 대기**

- 누락 산출물을 (a) 전부 복구할지 (b) 최신 버전만 새로 만들지 (c) 지금은 건너뛰고 Phase 1부터 만들면서 채울지.
- 힉스필드 API 최저 플랜(Plus? Studio?) — 가입 전 `higgsfield.ai/pricing`에서 "API access" 표기 플랜 확인 필요.

---

### Phase 1 — 인스타 모집 콘텐츠 (단기 · 즉시 산출물)

**목표:** 프리미엄 소수정예 수강생 모집용 콘텐츠를 **수동으로** 안정적으로 제작. 도구의 한글·톤 품질을 실제로 검증.

**핵심 작업**

- 모집 카드 1장 시안 프롬프트 작성 → Nano Banana Pro로 생성 → 톤(살구핑크/크림화이트/핫핑크·코랄, 프리미엄+친근) 검증.
- 검증되면 모집 카드 세트(예: 후킹 / 커리큘럼 / 차별점 / 가격·혜택 / 상담 신청 CTA)로 확장.
- 대표 카드 → 힉스필드(Veo 3.1) 쇼츠 1편 제작으로 이미지→영상 파이프라인 1회 관통.

**산출물:** 모집 카드 세트, 쇼츠 1편, 검증된 프롬프트 템플릿.

**제작 원칙(고정)**

- 실제 시술 비포&애프터·수강생 얼굴은 **AI 생성 금지**(허위광고 위험) → 실제 사진 사용.
- AI는 배경·디자인·무드컷·카드 그래픽·연출에만 사용.

**🟡 결정 대기**

- 첫 카드 주제 1개(예: "극사실눈썹 창시자 직강" 후킹컷부터?).
- 카드 세트 구성·장수.
- 실제 사진(시술 사례·원장 사진) 제공 가능 여부 및 사용 범위.

---

### Phase 2 — 광고 플랫폼 & 모집 퍼널 (중기)

**목표:** 만든 콘텐츠를 타깃에게 노출하고 **"상담 신청"** 전환까지 연결하는 시스템 구축.

**핵심 작업(제안)**

- 모집 상세페이지(랜딩) 완성 — 기록상 2종(기본 + 럭셔리 에디토리얼)이 있었으나 폴더 누락 → 복구/재작성 후 상담 신청 폼 연결.
- 유기적 인스타 운영 정례화(업로드 주기·콘텐츠 캘린더).
- 유료 광고(메타/인스타 광고) 운영 여부·예산 검토.
- 전환 측정: 상담 신청 링크/폼 → 유입·전환 추적.

**산출물:** 상담 신청까지 이어지는 랜딩, 콘텐츠 캘린더, (선택) 광고 운영안.

**🟡 결정 대기**

- **"광고 플랫폼" 범위 확정:** ①유료 광고 운영 / ②콘텐츠 노출·퍼널 시스템 / ③둘 다 — 어디까지로 볼지.
- 상담 신청 채널(카톡 채널/네이버 폼/자체 폼 등).
- 유료 광고 집행 여부·월 예산.
- 실제 후기·수강생 수 등 상세페이지에 넣을 신뢰 자료.

---

### Phase 3 — 콘텐츠 자동화 웹앱 (장기 · 최종 목표)

**목표:** Phase 1~2에서 손으로 검증된 제작 과정을 **블로그/인스타 콘텐츠 자동 생성 웹앱**으로 자동화.

**핵심 작업(개요)**

- 입력(주제·톤·소재) → 카드/쇼츠/블로그 글 자동 생성 → 검수 → 발행 흐름 설계.
- Phase 1에서 검증된 프롬프트 템플릿을 그대로 엔진화.

**산출물:** 콘텐츠 자동 생성 웹앱(MVP → 고도화).

**🟡 결정 대기**

- 웹앱 기술 스택(미정) — Phase 3 진입 시 대표님과 함께 결정.
- 자동화 범위(어디까지 자동, 어디부터 사람 검수).
- 추가 AI 직원 페르소나(그래픽/영상/PM 등) 채용 여부.

## 4. 결정 대기 항목 모음 (대표님 확인 요청)

가장 먼저 확인이 필요한 순서로 정리했습니다.

1. **누락 산출물 처리** — 전부 복구 / 최신만 재작성 / 만들면서 채우기 중 선택.
2. **첫 콘텐츠 시작점** — Phase 1 첫 카드 주제 1개.
3. **실제 사진 자료** — 시술 사례·원장 사진 제공 가능 여부(AI 금지 영역이라 필수).
4. **"광고 플랫폼" 범위** — 유료 광고까지 포함할지, 퍼널 시스템까지인지.
5. **도구 가입 정보** — 힉스필드 API 플랜, Nano Banana 키 발급 진행 상황.
6. **웹앱 기술 스택** — (Phase 3 진입 시) 함께 결정.
7. **추가 AI 직원** — 그래픽/영상/PM 페르소나 채용 여부.
