# 시그니처 마네킹 캐러셀 — 운영가이드 v1 (2026-06-24)

## 📌 한 줄 요약
**ARTbrows 첫 3D 마케팅 자산.** 「장미지 시그니처 마네킹 헤드」 GLB 1개에서 파생된 6장 인스타 캐러셀. 텍스트는 후킹·CTA 카드 2장에 집중, 마네킹 4컷은 사진의 힘 그대로.

## 1. 콘셉트
> **"조명이 바뀌어도, 시그니처는 한 줄로 남습니다."**

- ARTbrows의 새 카테고리 「**Signature Series**」 첫 작품
- 메시지: "한 사람의 눈썹이 어떤 무드·환경에서도 같은 시그니처를 유지하는 것" = ARTbrows 극사실 시술의 본질
- 톤: **럭셔리 미니멀 + 살구톤 + 명조** (기존 STORY 시리즈와 분기되는 새 톤)
- 마네킹 = 「사람의 얼굴은 AI 생성 금지」 정책 ([[visual-direction-hyperreal]]) 과 충돌 없음. 마네킹은 제품 디스플레이.

## 5. 운영 톤 매뉴얼

### 해야 할 것
- 사진 4컷에는 텍스트 오버레이 **금지** — 사진의 힘 보존
- 후킹·CTA만 텍스트, 톤 통일 (살구톤 + 명조 + 핫핑크 칩)
- 캡션 끝에 `@artbrows.korea` 와 「상담 신청 — 프로필 링크」 반드시
- 카카오 채널 결정 후엔 「카톡 상담」 옵션도 추가

### 하지 말 것
- 「당신의 얼굴」 합성 / AI 얼굴 생성 / 가짜 비포애프터 → [[visual-direction-hyperreal]] 정책 위반
- 마네킹을 「실제 시술 결과물」로 묘사 — 마네킹은 ARTbrows **시그니처 디스플레이 표상**, 시술 결과가 아님

## 8-B. 릴스 영상 — Chapter Reel (2026-06-24)

**5초 인스타 릴스 표준. 1080×1920 H.264 + AAC 128k · 1MB.**

| 항목 | 값 |
|---|---|
| 파일 | `assets/시리즈-시그니처마네킹/릴스-360회전-5초.mp4` |
| 길이 | 5.0초 (회전 1바퀴 2.5s × 2 loop) |
| 해상도 | 1080×1920 (9:16 인스타 릴스 표준) |
| 코덱 | H.264 (CRF 19) + AAC 128kbps |
| 크기 | 1.0MB |
| BGM | 신부편 재활용 (afade in/out 0.5s) |

**자막 시퀀스:**
- 0.4~2.3초: "어떤 조명에서도" (white, top) + "같은 한 줄" (#FF6F84, large)
- 2.8~5.0초: "당신의 한 줄을 찾으세요" (white) + "@artbrows.korea" (#FF6F84) + "상담 신청" (white on pink box)

**제작 파이프라인 (재활용 가능):**
```bash
# 1. PNG 시퀀스 → mp4 (회전 1회 2.5초)
ffmpeg -framerate 24 -i frame_%04d.png -c:v libx264 -pix_fmt yuv420p -crf 18 rotate-once.mp4

# 2. stream_loop로 2회 반복 (5초) + 자막 burn-in + BGM merge
ffmpeg -stream_loop 1 -i rotate-once.mp4 -i bgm.m4a \
  -filter_complex "[0:v]drawtext=fontfile='C\:/Windows/Fonts/malgunbd.ttf':text='...':...,[1:a]afade=t=in:st=0:d=0.5,afade=t=out:st=4.5:d=0.5[a]" \
  -map "[v]" -map "[a]" -t 5 -c:v libx264 -pix_fmt yuv420p -crf 19 -c:a aac signature-rotation-reel.mp4
```
