# 카카오톡 채널 챗봇 · 상담 시나리오 v0.1
> 2026-07-27 초안 · 대표님 확인용
> 채택 후 Kakao i Open Builder 시나리오 등록 + 우리 skill 서버 개발 착수

---

## 0. 전제 조건

- **채널**: 장미지 ARTbrows 카카오 채널 (URL 대기)
- **병행 유지**: K1 오픈채팅 (무료 강의방 · 브로드캐스트) + 카카오 채널 (1:1 상담 · 챗봇)
- **자동 저장**: 응답 → Supabase leads + Notion DB + 대표님 알림톡
- **폴백**: 챗봇 이해 못 하면 → 원장님/스태프에게 직접 연결

## 1. 진입 시나리오 (Welcome)

**트리거**: 사용자가 채널 추가 or "안녕하세요" 발화

```
챗봇:
  안녕하세요, 장미지 ARTbrows 입니다 💛
  극사실눈썹 창시자 장미지 원장의 아카데미·시술 문의를 도와드릴게요.

  어떤 도움이 필요하세요?

  [🎓 수강 상담 (창업반·이지반·극사실)]
  [💄 시술 상담 (선릉·삼성 본원)]
  [📅 강의 일정·가격 확인]
  [💬 원장님과 직접 상담]
```

## 2. 트랙 A · 🎓 수강 상담

### 2-1. 관심 강의 선택

```
챗봇:
  어떤 강의에 관심 있으세요?

  [창업반 15기 · 890만 (8월 개강)]
  [이지반 15기 · 69만 (토·일·월)]
  [극사실 특화 · 169만]
  [잘 모르겠어요 · 추천받기]
```

### 2-2. 이름 수집

```
챗봇:
  성함이 어떻게 되세요? (실명 or 닉네임)

사용자: "홍길동"
```

### 2-3. 연락처 수집

```
챗봇:
  연락처 남겨주세요. (원장님이 직접 답 주십니다)

사용자: "010-1234-5678"

챗봇 검증:
  ✅ 010-xxxx-xxxx 형식 확인
  ❌ 형식 오류 → "연락처를 다시 확인해 주세요"
```

### 2-4. 상담 방문 가능 시간

```
챗봇:
  언제 상담 가능하세요?

  [평일 오전 (10~13시)]
  [평일 오후 (14~18시)]
  [평일 저녁 (19~21시)]
  [주말]
  [무관 · 원장님 편한 시간]
```

### 2-5. 사전 질문 (선택)

```
챗봇:
  마지막으로 · 원장님께 미리 여쭤보고 싶은 것 있으세요?
  없으시면 [건너뛰기] 눌러주세요.

  [건너뛰기]
  [텍스트 자유 입력]
```

### 2-6. 접수 완료

```
챗봇:
  ✅ 접수 완료!

  성함: 홍길동
  연락처: 010-1234-5678
  관심: 창업반 15기 · 890만
  상담 가능: 평일 오후

  원장님이 24시간 안 답 드립니다. 감사합니다 💛

  📌 무료 강의방 카톡 K1 참여도 추천드려요
  → [K1 무료 강의방 참여]

  다른 궁금한 점 있으시면 언제든 말씀해주세요.
```

**→ skill webhook 발사 · Supabase leads + Notion append + 대표님 알림톡**

## 7. Skill Webhook 스펙 (개발자용)

### 7-1. 요청 (카카오 → 우리 서버)

```
POST /api/webhook/kakao-channel/skill
Content-Type: application/json

{
  "intent": { "id": "consult_academy_submit", "name": "수강상담접수" },
  "userRequest": {
    "utterance": "홍길동",
    "user": { "id": "kakao_user_id_xxxxx" }
  },
  "action": {
    "params": {
      "track": "academy",           // 'academy' | 'procedure' | 'info' | 'live'
      "interest": "startup_890",    // 'startup_890' | 'easy_69' | 'hyperreal_169' | 'brow' | 'lip' | ...
      "name": "홍길동",
      "phone": "010-1234-5678",
      "visitTime": "weekday_pm",    // 'weekday_am' | 'weekday_pm' | 'weekday_evening' | 'weekend' | 'any'
      "location": "seonleung",      // 'seonleung' | 'samseong' | 'any' (시술만)
      "note": "재직자입니다"          // optional 자유 텍스트
    }
  }
}
```

### 7-2. 응답 (우리 서버 → 카카오, 3초 이내 필수)

```
{
  "version": "2.0",
  "template": {
    "outputs": [
      {
        "simpleText": {
          "text": "✅ 접수 완료! 원장님이 24시간 안 답 드립니다 💛"
        }
      }
    ],
    "quickReplies": [
      { "label": "K1 무료 강의방 참여", "action": "webLink", "webLinkUrl": "https://open.kakao.com/o/gWeAkSzi" },
      { "label": "처음으로", "action": "message", "messageText": "안녕하세요" }
    ]
  }
}
```

### 7-3. 우리 서버 처리 (병렬)

```
1. Supabase leads INSERT
   INSERT INTO leads (source, kakao_user_id, name, phone, track, interest,
                      visit_time, location, note, created_at)
   VALUES ('kakao_channel', ...)

2. Notion databases append (원장님 워크스페이스)
   POST https://api.notion.com/v1/pages
   { parent: { database_id: "..." }, properties: { ... } }

3. 대표님 친구톡 알림 (알리고 or 비즈고)
   "신규 상담 접수: 홍길동 · 창업반 890 · 010-xxxx"

4. Kakao Skill 응답 반환 (3초 이내)
```

## 8. Notion DB 스키마 (제안)

**Database 이름**: `ARTbrows 상담 리드`

| 컬럼 | 타입 | 설명 |
|---|---|---|
| 이름 | Title | 홍길동 |
| 연락처 | Phone | 010-1234-5678 |
| 트랙 | Select | 수강 · 시술 · 정보 · 라이브 |
| 관심 | Select | 창업반 890 · 이지반 69 · 극사실 169 · 눈썹 · 아이라인 · 입술 · 헤어라인 · 잔흔복구 |
| 방문 가능 | Select | 평일 오전 · 오후 · 저녁 · 주말 · 무관 |
| 지점 | Select | 선릉 · 삼성 · 무관 (시술만) |
| 메모 | Text | 자유 입력 |
| 소스 | Select | 카톡 채널 · K1 · 인스타 · 홈피 · 전화 |
| 카카오 유저 ID | Text | 챗봇 재접속 시 이력 매칭용 |
| 상담 상태 | Select | 신규 · 답변완료 · 방문예약 · 등록완료 · 취소 |
| 접수일시 | Date | 자동 |
| 담당자 | Person | 원장님 or 스태프 |
| 이력 링크 | URL | admin/leads/{id} 딥링크 |

## 9. 대표님 확인 필요 항목
