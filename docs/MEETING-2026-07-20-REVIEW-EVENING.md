## 1. 이서연 (기획팀장) 자유 발언

> **긍정**:
> 오늘 하루 3연회의 + 실물 12건 = 놀라운 진도. 특히 커리큘럼이 「단과 4 + 창업반 660 + 강사반 + 재수강 990」 3단 매출 구조로 명료해진 게 최대 수확. 홈피가 명품 톤으로 정착됐고 「극사실 4대 카테고리 우산」이 원장님 정체성과 결합된 것도 큰 진전.

> **우려**:
> 원장님 노하우가 아직 코드/문서로 안 들어옴. 「털 같은 눈썹」 원문만으론 부족. **AI 숙제검사 앱의 핵심은 원장님 30년 패턴 라이브러리** — 이게 없으면 앱 자체가 껍데기. 원장님 직접 인터뷰·시술 영상·클레임 사례 데이터 수집이 다음 병목.

> **개선 제안**:
> - 커리큘럼 카드 웹페이지 반영 (지금 홈피에 4단과 명확히 표시 안 됨)
> - 재수강 990 옵션은 홈피에 표기해야 창업반 660 지원 유도 (원장님 승인 대기)
> - 다음 회의 = 원장님 노하우 데이터 수집 세션 (2h 인터뷰)

## 2. 유나 (그래픽·비주얼 디자이너) 자유 발언

> **긍정**:
> Maison Noir 팔레트 (로즈 브론즈 다크) 정착된 것이 브랜드 통일성 큰 도움. 「극사실 4대 카테고리」 카드도 시각 정체성 강화. 광고 영상 v3 -real 톤이 원장님 「털 같은 눈썹」 철학과 정확히 일치.

> **우려**:
> 실물 사진이 여전히 부족. 원장님 최근 사진 = **명품 톤 촬영 미완료** (결정 대기). 지금 홈피 사용 이미지는 모두 기존 자산 재활용. 신규 이미지 없이 극사실 카테고리 확장하면 콘텐츠 공백 심화.

> **개선 제안**:
> - 원장님 명품 톤 사진 촬영 = **다음 주 확정** (연구소 or 스튜디오)
> - 시술 실제 결과 사진 = 원장님 아이패드/폰에 있는 것 백업 & 정리 (콘텐츠 소스)
> - 극사실 4대 카테고리 나머지 3개 (아이라인·입술·헤어라인) 컨셉 사진 확보 or Higgsfield 생성 (원장님 프롬프트 정본 활용 · 크레딧 최대 30장 = 30 크레딧)

## 3. 정하늘 (EdTech 풀스택 · 신규 채용 첫날) 자유 발언

> **긍정**:
> 첫날부터 스코프 명확해서 좋음. AI LMS 앱 스코프 (재학생·창업생·B2B) + 게이미피케이션 + AI 시술 디자인 도구 = 향후 6개월 로드맵 명료. PWA로 확정된 것도 개발 부담 감소 (네이티브 X).

> **우려**:
> **AI 시술 디자인 도구 (얼굴 사진 → 눈썹 추천)** 가 스코프 안에 있지만 데이터 학습 방식이 아직 미정. 원장님 30년 패턴 라이브러리를 어떻게 코드로 만들 것인가가 진짜 문제. Gemini Vision 만으로는 정확도 부족.

> **개선 제안**:
> - Phase 1 = LMS 코어 (강의·숙제·평가 · AI 피드백 기본) 먼저 · AI 디자인 도구는 Phase 3+
> - Phase 1 스코프 = 7~10일 · **원장님 노하우 수집 완료 후 착수** (없으면 껍데기)
> - PWA 기술 스택: Next.js 16 + Vercel + Prisma + Postgres OR 모비딕 방식 파일 기반? — 결정 필요

## 4. 한승철 (풀스택 개발) 자유 발언

> **긍정**:
> Supabase 완전 제거 → 파일 기반 (모비딕 방식) 이전이 큰 부담 덜어줌. DNS 소멸 이슈 재발 위험 0. 카드뉴스 다양화 코드도 컴파일 에러 0 · 안정적.

> **우려**:
> 카드뉴스 design UI 배포됐지만 **실전 테스트 미완**. 사용자가 실제로 편집해봤을 때 UX 병목 있을 것 (특히 이미지 pool 선택 · 지금은 텍스트 드롭다운). 광고 영상 v2/v3 파일이 늘어나면서 브랜드 자산 관리 원칙 필요 (v1·v2·v3·real·bright 등 명명 표준).

> **개선 제안**:
> - 카드뉴스 design UI = 이미지 pool에 **썸네일 그리드 pick** 추가 (텍스트 드롭다운은 UX 나쁨)
> - 브랜드 자산 명명 규칙 문서 = `docs/BRAND-ASSET-NAMING.md` 신설
> - 홈피 아카데미 하위 페이지 (커리큘럼·일정·강사·후기·FAQ) = **다음 우선순위** (원장님 요구)
> - Supabase 스텁이 완전 null인지 재확인 (혹시 남은 참조가 있을지)

## 5. 김다은 (SaaS-A · 홈페이지·강의 PM) 자유 발언

> **긍정**:
> 커리큘럼 확정으로 SaaS-A 스코프가 「학원 홈피 + LMS 앱」 로 정리됨. 홈피는 이미 배포 · LMS는 기획 완료. 매출 축 = 창업반 660 매달 5~10명 신규 유입 목표도 KPI로 잘 정리.

> **우려**:
> 홈피 방문자 → 창업반 660 결제까지의 funnel 이 안 그려져 있음. 「시술 상담 · 교육 상담」 CTA 2개 있지만 → 상담 폼 → 실 결제까지 몇 단계? conversion rate 측정 미비.

> **개선 제안**:
> - 창업반 660 결제 페이지 (또는 상담 → 카톡 연결 → 결제 안내) funnel 설계
> - **funnel 대시보드** = `/admin/funnel` 신규 · 홈피 방문 → 상담 → 결제 % 표시
> - 인스타 → 홈피 유입 UTM 추적 (기존 홈피에 UTM 파라미터 파싱 코드 필요)

> **개선 제안**:
