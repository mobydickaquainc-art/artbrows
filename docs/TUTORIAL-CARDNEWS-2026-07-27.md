## 1. 3 가지 시작 방식

대시보드 상단에 3개 버튼:

| 버튼 | 언제 | 소요 |
|---|---|---|
| **🪄 자동 생성** | 이미지 없이 텍스트만으로 · 스타일 프리셋 기반 6~10장 자동 | 30초 |
| **📸 이미지로 시작 (A · 자동 생성)** | 이미지 1~12장 던지고 → AI 방향 추천 → **4안 병렬 양산 → 원장님 선택** | 60~90초 |
| **🔄 기존 카드뉴스 재편집 (B)** | 이미 만든 인스타 카드뉴스 여러 장 → OCR + AI 카피 팔레트 → 편집기에서 재배치 | 40~90초 |

**추천 흐름**:
- 신규 콘텐츠 = **A (이미지로 시작 · 4안 양산)**
- 기존 인스타 리뉴얼 = **B (재편집)**
- 급하게 텍스트만 = **자동 생성**

## 2. Pattern A · 이미지로 시작 (신규 콘텐츠)

### 2.1 Step 1 — 이미지 던지기

1. 대시보드 → **「📸 이미지로 시작 (A · 자동 생성)」**
2. 「클릭 or 파일 드래그」 영역에 이미지 **1~12장** 업로드
3. **자산 인벤토리** 에서도 선택 가능 (원장·아틀리에 15장 · 인물·시술 20장 · 매크로 14장)
4. **용도** 선택: 모집 · 리뷰 · 방법론 · 아틀리에 · 자유
5. **인스타 규격**: 정사각 / 세로 (권장) / 스토리
6. **슬라이드 개수**: AI 자동 · 4/5/6/7/8/10장
7. **「다음 → AI 분석」** 클릭

### 2.2 Step 2 — AI 방향 추천

- **Gemini Vision 3.1 Pro** 가 각 이미지 분석 (10~20초)
- 이미지별 인식 결과 (subject · tone · notes) 확인
- **방향 옵션 3~4개** 카드로 표시 · 각 카드 클릭하면 다음 단계

### 2.3 Step 3 — 4안 양산 · 선택 (핵심)

방향 선택 시 자동 실행:
- **💎 Gemini · 안정** (temperature 0.55 · 정본 톤)
- **💠 Gemini · 실험** (temperature 1.05 · 대담 톤)
- **🎯 OpenAI · 안정**
- **🎨 OpenAI · 실험**

**대기 20~40초** → 4개 카드 2×2 그리드로 나란히 미리보기

**행동**:
1. 4개 카드 훑어보기 (각 카드 안에 6장 세로 스크롤)
2. 마음에 드는 안 하나 골라 **「✅ 이 안으로 확정」** 클릭
3. 자동으로 편집기 이동 · 나머지 3안 자동 폐기

**Tip**: 4안 다 마음에 안 들면 하단 **「🔄 4안 다시 양산」** (또 20~40초)

## 3. Pattern B · 리뉴얼 (기존 카드뉴스 재편집)

### 3.1 업로드

1. 대시보드 → **「🔄 기존 카드뉴스 재편집 (B)」**
2. **프로젝트 제목** 입력 (선택 · 예: 「극사실소묘 3일 집중 · 8월 15기 리뉴얼」)
3. 「여기로 카드뉴스 이미지들을 드래그하세요」 에 **1~20장** 이미지 드래그
4. 각 이미지 아래 **↑ ↓ ×** 로 순서 조정
5. **적용 스타일** 선택 (5종 + Custom):
   - 01 ARTbrows Style ★ (원장 07-24 배포본 정본 · **기본값**)
   - 02 Rebellion Serif (Vogue 진화형)
   - 03 Grain Frame Editorial (Kinfolk 감성)
   - 04 Vertical Column Story (NYT 3단 · 저장률 2배)
   - 05 Silhouette Reveal (Dior 미스터리 훅)
   - 06 Custom (자유 서술)
6. **「🤖 AI 카피 자동 생성」** 체크 여부:
   - **체크 O**: 스타일 톤에 맞게 원본 텍스트를 AI 가 재작성
   - **체크 X**: 원본 텍스트 그대로 팔레트에 저장
7. **「N장 재편집·라이브러리 편입」** 클릭

### 3.2 진행 · 완료

- **모래시계 오버레이**: 경과 · 예상 남은 · 총 이미지 3 카드 · 4단계 순환 (📤 → 🔍 → ✍️ → 💾)
- 완료 시 뷰어로 자동 이동
- 각 슬라이드 = **원본 이미지 그대로** · 상단 편집기 진입으로 팔레트 활용

## 4. 편집기 (3열 상시 노출)

**진입**: 대시보드 → 프로젝트 행의 **「편집」** 클릭 (또는 신규/리뉴얼 완료 시 자동)

### 4.1 좌 · 슬라이드 목록 (240px)

- **N ·`kind`** 라벨 (예: 「01 · image-with-overlay」)
- **↑ ↓** 순서 이동 · **×** 삭제
- 하단 **「+ 슬라이드 추가」**

### 4.2 중 · 큰 미리보기 (flex)

- 실제 크기 미리보기 (aspect 4:5 · 최대 460px)
- **오버레이 클릭** = 우측 인스펙터 선택 상태 활성 (골드 하이라이트)
- **빈 영역 클릭** = 선택 해제

### 4.3 우 · 편집 인스펙터 (380px · 4 섹션 상시 노출)

**섹션 1 · 🎨 스타일 프리셋 6종** — 오버레이 선택 후 한 클릭에 폰트+색+배경+굵기+정렬 세팅:

| 프리셋 | 용도 |
|---|---|
| **원장 실톤 볼드** | 07-24 원장 직접 배포본 (프리텐다드 + 갈색 박스) |
| **Vogue 대헤드** | Cormorant 세리프 대문자 임팩트 |
| **골드 시그니처** | 나눔펜 필기체 · 골드 · 배경 없음 |
| **명조 인용** | 나눔명조 · 아이보리 · 투명 검정 |
| **임팩트 선언** | Black Han Sans · 검정 pill · 짧은 슬로건 |
| **화이트 라벨** | 고딕 · 블랙 텍스트 · 화이트 박스 |

**섹션 2 · ✏️ 선택 오버레이 인스펙터** — 선택된 오버레이 즉시 편집:
- 텍스트 (여러 줄 가능)
- **X · Y · 크기 슬라이더** (0~100% · 미세 조정)
- **폰트 6종** (고딕 · 명조 · Cormorant · Playfair · 임팩트 · 필기)
- **굵기 4단** (L · M · B · Bl)
- **정렬 3종** (⇤ ⇔ ⇥)
- **글자색 8 스와치 + 커스텀 컬러 피커**
- **배경 6종** (없음 · 투명검정 · 투명갈색 · 투명골드 · 검정pill · 화이트박스)

**섹션 3 · 🎨 AI 카피 팔레트 (접이식)** — 리뉴얼 시 자동 채워지는 카피 후보:
- 각 항목의 텍스트 편집 가능
- **「원본」** 버튼: 원본 이미지의 위치·색·폰트 그대로 문장만 대체
- **「기본」** 버튼: role 기반 프리셋 위치 (상단/중앙/하단)

**섹션 4 · 📌 오버레이 목록 칩** — 슬라이드에 배치된 모든 오버레이:
- 칩 클릭 = 인스펙터 활성
- **「+ 헤드라인」** · **「+ 본문」** 빈 오버레이 추가

## 5. 🎯 문장 교체 (Gemini Vision · 스타일 카피)

**언제**: 이미지에 이미 새겨진 문장을 다른 문장으로 바꾸고 싶을 때 (리뉴얼 특화 기능)

**흐름**:
1. 편집기 상단 툴바 **「🎯 문장 교체」** 클릭 (핑크 그라디언트로 활성)
2. 미리보기 위 안내 배너 「교체할 문장 영역을 마우스로 드래그」
3. **문장 영역을 마우스로 드래그** → 골드 점선 사각 박스 실시간 표시
4. **mouseUp** = Gemini Vision 3.1 Pro 가 해당 영역 분석 (2~5초)
5. **확정 모달** 등장:
   - 📷 원본 문장 (감지 결과)
   - 감지 스타일 라벨 (폰트 · 굵기 · 크기 · 정렬 · 글자색 · 배경)
   - ✏️ **새 문장 입력창** (원본이 기본값 · 자유 편집)
6. **「✅ 이 자리에 배치」** 클릭 → 원본 스타일 그대로 · 새 문장으로 · 드래그 bbox 위치에 오버레이 추가
7. 우측 인스펙터가 그 오버레이 자동 활성 → 위치 · 색 미세 조정

**Tip**:
- 감지 문장이 원본이면 그대로 두고 저장 = 「스타일 카피만」 완료
- 다른 오버레이도 순차적으로 교체 가능 (매번 「🎯 문장 교체」 → 드래그)

## 6. 저장 · 미리보기 · 삭제

- **저장**: 상단 「저장」 클릭 (dirty ● 표시 → ✓ 저장됨)
- **미리보기**: 「미리보기 ↗」 → 뷰어 창 새로 열기 · 인스타 캐러셀 형태
- **프로젝트 삭제**: 편집기 상단 「🗑 삭제」 (완전 삭제 · 되돌릴 수 없음) · 또는 대시보드 각 행의 「삭제」
- **슬라이드 삭제**: 편집기 좌측 목록에서 슬라이드 카드의 **×**
- **오버레이 삭제**: 우측 인스펙터의 **× 삭제** 또는 오버레이 목록 칩 재클릭

## 7. 자주 겪는 문제

| 증상 | 원인 · 해결 |
|---|---|
| 편집기에서 스타일 프리셋 · 팔레트 안 보임 | 슬라이드 kind 가 `image-with-overlay` 여야 함. 리뉴얼로 새로 만든 프로젝트로 다시 시도 |
| 폰트가 이상하게 보임 | 브라우저 폰트 캐시 — **Ctrl+Shift+R** 강제 새로고침 |
| 「🎯 문장 교체」 버튼 안 뜸 | image-with-overlay 슬라이드일 때만 표시 |
| Gemini API 429 · 502 | 자동 폴백 (3.1 Pro → 3.0 → 3 Flash → 2.5) · 그래도 실패 시 20~30초 후 재시도 |
| 4안 중 일부 실패 | 성공한 안만 클릭 가능 · 다른 안은 회색 처리 · 정상 |
| dev 서버 죽음 | `cd app-next && npm run dev` |
