JANGMIJI ATELIER · 영상 자동 번역

원장님 PC 1-클릭 설치

25GB 이상의 긴 강의 영상을 원장님 PC 가 알아서 처리합니다. 영상을 던지면 음성 인식 → 한국어 번역까지 자동, 끝나면 알림이 갑니다. 시청은 어디서든 가능합니다.

⬇ INSTALL.bat 다운로드 (1.5KB)

다운로드 → 더블 클릭 한 번이면 설치 완료 (자동 20분 정도)

STEP 01

다운로드한 INSTALL.bat 더블 클릭

검은 창이 뜨면서 Python · ffmpeg · 영상 처리 도구를 자동으로 설치합니다.
중간에 「관리자 권한 허용?」 묻는 창이 뜨면 예 클릭해 주세요. (총 15~20분)

  • Python 3.12 (영상 처리 엔진)
  • ffmpeg (오디오 추출)
  • faster-whisper (음성 인식)
  • OpenAI 클라이언트 (한국어 번역)
  • 폴더 감시기 (자동 처리)
STEP 02

API 키 받기 (대표님께 요청)

설치 끝나면 %USERPROFILE%\jangmiji-translate\.env 파일이 만들어집니다.
이 파일을 메모장으로 열어서 다음 두 줄에 값을 채우세요:

  • OPENAI_API_KEY=sk-proj-... (대표님께 받기)
  • SUPABASE_SECRET_KEY=sb_secret_... (대표님께 받기)

※ 키는 카톡으로 보내드리겠습니다. 저장 후 메모장 닫으면 끝입니다.

STEP 03

바탕화면 「영상 번역 시작」 더블 클릭

설치 완료되면 바탕화면에 영상 번역 시작.bat 아이콘이 생깁니다. 더블 클릭하면 검은 창이 뜨고 영상 폴더를 감시하기 시작합니다.
이 창이 떠 있는 동안 자동 처리가 작동합니다. (창 닫으면 멈춤 — 다시 더블 클릭하면 재시작)

STEP 04

영상을 폴더에 던지기

%USERPROFILE%\jangmiji-translate\_inbox\ 폴더에 영상 파일을 복사·이동하면 끝.
자동으로 음성 인식 → 한국어 번역 → Supabase 클라우드에 결과 업로드.

  • 2분 영상: 약 2분 처리
  • 30분 영상: 약 20~30분 처리
  • 3시간 영상: 약 1.5~2시간 처리
  • 25GB 영상: 약 2~4시간 처리

※ 영상은 컴퓨터에 두고 처리 — 인터넷으로 옮길 필요 없음

STEP 05

결과 시청

처리가 끝나면 https://jangmiji.staris.cloud/translate-zh.html 페이지에서 「최근 번역된 영상」 목록에 표시됩니다.
클릭하면 영상 + 한국어 자막이 자동 스크롤됩니다. 시청은 PC, 핸드폰, 태블릿 어디서든 OK.

설치가 잘 안 될 경우 — 대표님께 한 마디만 알려주세요. 회사 PC 에서 대신 처리해드립니다.
이 경우 영상만 카카오·메일·USB 등으로 보내주시면 끝. 시스템 자체는 동일하게 작동합니다 (시청 페이지도 동일).
