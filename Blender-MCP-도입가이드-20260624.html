Blender MCP 도입 가이드 — Claude Code 가 「말로」 3D 제어

대표님 요청 (06/24): "MCP 로 연동 가능하면 제일 좋겠다. 클로드코드에서 제어 가능한 퀄리티 뛰어난 3D model 구현".
Blender MCP = Claude Code ↔ Blender 양방향 통신. 「큐브 만들어 줘」, 「이 GLB 의 눈썹 부분 0.2mm 굵게」 처럼 자연어로 3D 제어 가능.

  • 「이 GLB 의 눈썹 영역 0.2mm 더 굵게」 — Claude 가 Blender Python 호출 → 메쉬 vertex 변경 → 새 GLB 저장 → 자동 _site 게시
  • 「장미지 원장 가상 아바타에 시술 후 5년 잔주름 시뮬」 — Blender 의 face wrinkle generator + Claude 제어
  • 「PolyHaven 의 스튜디오 조명 HDR 로 5장 캐릭터 자동 리렌더」 — Blender Cycles 자동 렌더 → 더 사실주의
  • 「Hyper3D Rodin 으로 「장미지 원장 시그니처 마네킹 헤드」 생성」 — Claude → Blender MCP → Hyper3D → 즉시 결과
  • 「5 캐릭터에 시술 전/후 표정 변화 (Blendshape) 자동 적용」 — 한 번 셋업 → 5장 모두 자동

C6 단계 설치 — 30 분 안에 완료

Blender 4.x 다운로드 + 설치

blender.org/download 에서 Windows MSI 다운로드 → 더블 클릭 설치 (기본 옵션 OK).

설치 후 PowerShell 에서 확인:

blender --version
# Blender 4.x.x 표시되면 OK
⚠️ PATH 에 자동 추가 안 되면 시스템 환경변수에 C:\Program Files\Blender Foundation\Blender 4.x 수동 추가

uv 패키지 매니저 설치

PowerShell (관리자) 에서:

winget install astral-sh.uv
# 또는 pip
pip install uv

설치 확인:

uv --version
# uv 0.x.x

Blender Add-on 설치 (addon.py)

1. github.com/ahujasid/blender-mcp/blob/main/addon.py → Raw 클릭 → 다른 이름으로 저장 → addon.py

2. Blender 실행 → Edit → Preferences → Add-ons → Install... → addon.py 선택

3. 검색창에 「MCP」 입력 → 「Interface: Blender MCP」 체크박스 활성화

4. 우측 N 키 패널에 「BlenderMCP」 탭 생김 → 「Connect to MCP Server」 클릭

★ Blender 안 우측 N 키 (사이드 패널) 못 보이면 → 3D 뷰포트 클릭 후 N 키 누름

Claude Code (또는 Desktop) MCP 설정 추가

Claude Code 사용 시 — ~/.claude.json 또는 프로젝트 .mcp.json:

{
  "mcpServers": {
    "blender": {
      "command": "uvx",
      "args": ["blender-mcp"]
    }
  }
}

Claude Desktop 사용 시 — Windows: %APPDATA%\Claude\claude_desktop_config.json:

{
  "mcpServers": {
    "blender": {
      "command": "uvx",
      "args": ["blender-mcp"]
    }
  }
}
★ 설정 후 Claude Code/Desktop 재시작 필수. 시작 시 자동으로 uvx blender-mcp 가 실행됨 (Blender 가 켜져 있고 Connect 상태여야 작동)

F문제 해결 (자주 발생 이슈)

  • 1. uvx blender-mcp 실행 안 됨 — uv PATH 미설정. PowerShell 재시작 또는 시스템 환경 변수에 %LOCALAPPDATA%\Programs\Astral\uv\bin 추가
  • 2. Blender 의 「Connect to MCP Server」 버튼 없음 — Add-on 활성화 안 됨. Edit → Preferences → Add-ons 검색창에 「MCP」 체크 확인
  • 3. Claude Code 가 blender 서버 못 찾음 — 설정 파일 위치 잘못. Windows 의 정확한 경로 = %APPDATA%\Claude\claude_desktop_config.json · Claude Code = ~/.claude.json 또는 프로젝트 .mcp.json
  • 4. Blender 가 응답 안 함 — Blender 가 꺼져 있거나 Connect 끊김. Blender 재실행 + Connect 다시 클릭
  • 5. 한글 파일 경로 오류 — Blender Python 의 한글 path 인코딩 이슈. ASCII 사본 임시 폴더 사용 권장 (메모리 [[edge-headless-screenshot]] 와 같은 패턴)
  • 6. PolyHaven / Sketchfab 자산 다운로드 안 됨 — 방화벽/프록시 차단. polyhaven.com 화이트리스트
  • 7. Cycles 렌더 매우 느림 — GPU 미설정. Edit → Preferences → System → CUDA/OptiX 활성화 (NVIDIA GPU 있을 때)
